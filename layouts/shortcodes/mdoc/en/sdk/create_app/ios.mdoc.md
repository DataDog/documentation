1. Navigate to [**Digital Experience** > **Add an Application**](https://app.datadoghq.com/rum/application/create).
2. Select `iOS` as the application type and enter an application name to generate a unique application ID and client token.
3. To instrument your web views, click the **Instrument your webviews** toggle. For more information, see [Web View Tracking](/real_user_monitoring/ios/web_view_tracking/).
