### Monitoring AWS Lambda functions
Data Streams Monitoring supports AWS Lambda functions that use Amazon SQS, Amazon SNS, Amazon EventBridge, or Amazon Kinesis. Context is injected and extracted automatically. Lambda support requires the Datadog Lambda Extension v100 or later and a minimum Lambda layer or tracer version for your runtime. For requirements and setup instructions, see [Data Streams Monitoring for AWS Lambda][7301].
