Views are tracked in renderer processes by the Browser SDK. See [Track Navigation for the Browser SDK][1].

Main process events are not attached to a view. To identify the process that generated an event, use the `execution_context` attributes. For example, `@execution_context.type:main-process` shows only events generated by the main process. See [Data Collected][2].
