To enable RUM, select {% ui %}Enable RUM{% /ui %} in the Datadog section of your {% ui %}Project Settings{% /ui %} in Unity and set your {% ui %}RUM Application ID{% /ui %}. RUM starts when the SDK initializes. No further code is needed.

To track scenes as views automatically, also select {% ui %}Enable Automatic Scene Tracking{% /ui %}. See [Track Navigation][1].
