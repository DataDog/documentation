To enable feature flag data collection for your iOS application, set up [RUM iOS monitoring][1] with iOS RUM SDK version 1.16.0 or later.

If you use Datadog Feature Flags (`DatadogFlags`), flag evaluations are reported to RUM automatically. For other feature flag providers, see [Set up a feature flag integration](#set-up-a-feature-flag-integration).
