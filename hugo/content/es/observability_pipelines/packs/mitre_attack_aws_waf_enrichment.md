## Descripción general {#overview}

{{< img src="observability_pipelines/packs/mitre_attack_aws_waf_enrichment.png" alt="El paquete MITRE ATT&CK AWS WAF Enrichment pack" style="width:25%;" >}}

Este paquete etiqueta los registros de AWS WAF con tácticas y técnicas de MITRE ATT&CK.

Lo que hace este paquete:

- Etiqueta eventos con técnicas de MITRE
- Mapea exploits, fuerza bruta y eventos de bots
- Marca eventos como relevantes para la seguridad
