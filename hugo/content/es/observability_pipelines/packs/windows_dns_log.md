## Descripción general {#overview}

{{< img src="observability_pipelines/packs/windows_dns_log.png" alt="El paquete de registro de DNS de Windows" style="width:25%;" >}}

El registro analítico del servidor DNS de Windows cubre consultas, transferencias de zona y actualizaciones dinámicas.

Lo que hace este paquete:

- Analiza los campos de consulta
- Marca las transferencias de zona
- Muestrea las consultas de rutina
