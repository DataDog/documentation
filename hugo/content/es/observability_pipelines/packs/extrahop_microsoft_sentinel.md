## Descripción general {#overview}

{{< img src="observability_pipelines/packs/extrahop_microsoft_sentinel.png" alt="El paquete ExtraHop - Microsoft Sentinel" style="width:25%;" >}}

Este paquete etiqueta las detecciones de red de ExtraHop Reveal(x) con la gravedad y las direcciones IP para la ingesta en Microsoft Sentinel.

Lo que hace este paquete:

- Etiqueta la gravedad del riesgo
- Extrae las direcciones IP de los infractores y las víctimas
- Descarta el ruido de bajo riesgo
