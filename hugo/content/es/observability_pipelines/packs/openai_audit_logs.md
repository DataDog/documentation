## Descripción general {#overview}

{{< img src="observability_pipelines/packs/openai_audit_logs.png" alt="El paquete OpenAI - Audit Logs" style="width:25%;" >}}

Este paquete marca inicios de sesión fallidos, nuevas claves de API y cambios de privilegios de los registros de auditoría de la organización de OpenAI.

Lo que hace este paquete:

- Marca inicios de sesión fallidos
- Marca nuevas claves de API
- Marca cambios de roles
