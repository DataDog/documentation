## Descripción general {#overview}

{{< img src="observability_pipelines/packs/mitre_attack_windows_enrichment.png" alt="El paquete MITRE ATT&CK Windows Enrichment" style="width:25%;" >}}

Este paquete etiqueta los registros de eventos de Windows con tácticas y técnicas de MITRE ATT&CK.

Lo que hace este paquete:

- Etiqueta eventos con técnicas de MITRE
- Asigna inicios de sesión, cambios de cuenta y eventos de ejecución
- Marca eventos como relevantes para la seguridad
