Cree, guarde y comparta gráficos de Product Analytics según sea necesario para respaldar el análisis de usuario y productos. 

## Cree un gráfico {#create-a-chart}

Explore el comportamiento del usuario o visualice las métricas del producto creando un gráfico desde cero, o comenzando desde una plantilla preconstruida.

Para crear un gráfico desde cero, en la barra lateral de Product Analytics, seleccione {{< ui >}}Create New{{< /ui >}}, luego seleccione un tipo de gráfico. 

{{< img src="product_analytics/chart_basics/chart_basics_create.png" alt="Barra lateral de Product Analytics que muestra el botón Create New y la lista de tipos de gráficos para seleccionar." style="width:50%;" >}}

Para crear un gráfico a partir de una plantilla, desde la página {{< ui >}}Charts{{< /ui >}} de Product Analytics, haga clic en {{< ui >}}Explore all templates{{< /ui >}}. 

{{< img src="product_analytics/chart_basics/chart_basics_template.png" alt="Página de gráficos que muestra la sección Start with a Chart Template y el enlace Explore all templates." style="width:100%;" >}}

## Guarde o comparta un gráfico {#save-or-share-a-chart}

Guarde un gráfico para realizar un seguimiento de las métricas clave del producto a lo largo del tiempo, o compártalo para que su equipo pueda actuar sobre las mismas perspectivas.

{{< img src="product_analytics/chart_basics/chart_basics.png" alt="Editor de gráficos con llamadas numeradas para el campo de nombre del gráfico y los botones Share y Save." style="width:100%;" >}}

1. Haga clic en el nombre del gráfico para cambiarle el nombre.

2. Haga clic en {{< ui >}}Save{{< /ui >}} para guardar el gráfico en la página {{< ui >}}Charts{{< /ui >}}. Utilice el menú desplegable para guardar el gráfico en un dashboard o notebook. 

   Haga clic en {{< ui >}}Share{{< /ui >}} para copiar el gráfico al portapapeles. Utilice el menú desplegable para exportar el gráfico como PNG, o para exportar los datos del gráfico a CSV, si está disponible.
