## Descripción general {#overview}

Datadog Cloud SIEM (Security Information and Event Management) es un sistema de análisis y correlación de datos de seguridad. Permite que todo su equipo de operaciones de seguridad vea, detecte, investigue y responda a problemas de seguridad. Aprovechando la plataforma escalable de Datadog, Cloud SIEM ingiere telemetría de sistemas en la nube y locales mediante el Datadog Agent e integraciones basadas en API.

Una respuesta de seguridad eficaz requiere velocidad, contexto, perspectiva y automatización. Cloud SIEM analiza continuamente los datos entrantes para detectar amenazas, generar señales de seguridad procesables y correlacionarlas entre múltiples fuentes. Esto permite que su equipo investigue incidencias y responda rápidamente.

Para mantener a su equipo al tanto de los ataques más recientes, Datadog también cuenta con un equipo de investigadores de amenazas que analizan petabytes de telemetría en sistemas en la nube y locales para identificar amenazas emergentes y comportamientos de atacantes. Consulte [Datadog Security Labs][1] para leer artículos sobre sus investigaciones recientes.

### Seguridad y observabilidad {#security-and-observability}

Cloud SIEM integra telemetría tanto de la nube como local directamente en los flujos de trabajo de seguridad para acelerar la investigación y la respuesta. Y con una plataforma compartida que reúne a los equipos de DevOps y Seguridad, las organizaciones pueden eliminar los silos y responder a las amenazas de manera colaborativa y eficiente.

### Control de costos flexible para datos de seguridad {#flexible-cost-control-for-security-data}

A medida que su organización crece, controlar el costo de ingesta de los registros de seguridad sin comprometer la visibilidad es fundamental. Cloud SIEM está integrado con Datadog Log Management para que pueda elegir la capacidad de retención y consulta adecuada para sus registros de seguridad. Esta flexibilidad le ayuda a equilibrar la eficiencia de costos con sus necesidades de detección de amenazas.

Almacene registros utilizando una de las opciones disponibles:
- [Standard indexing][6] para registros que necesitan ser consultados frecuentemente con la mayor capacidad de cómputo.
- [Flex Logs][7] para registros que necesitan ser retenidos a largo plazo, pero que a veces requieren ser consultados con urgencia.
- [Log Archives][8] para registros que se consultan con poca frecuencia y necesitan ser almacenados a largo plazo.

### Incorporación guiada de datos de seguridad {#guided-security-data-onboarding}

Los [Content Packs][9] de Cloud SIEM son un conjunto seleccionado de integraciones de Datadog diseñadas para equipos de seguridad. Cada paquete de contenido tiene instrucciones sobre cómo configurar la integración y qué incluye, como reglas de detección, paneles interactivos listos para usar, analizadores y flujos de trabajo de SOAR. Los paquetes de contenido destacan información procesable específica para cada integración para ayudarle a investigar problemas de seguridad.

### Monitoreo del estado del paquete de contenido {#content-pack-health-monitoring}

Después de activar un paquete de contenido, este le brinda el estado de salud de la integración y proporciona pasos de solución de problemas si algo sale mal, para que pueda volver a estar operativo lo más rápido posible.

### Búsqueda y análisis de registros {#log-search-and-analysis}

Cree búsquedas en el Log Explorer utilizando facetas o haciendo clic directamente en los campos de los registros. O utilice Bits AI y la búsqueda en lenguaje natural para encontrar eventos de seguridad importantes. Con funciones integradas de agrupación y búsqueda en tabla, así como análisis de patrones y visualizaciones, los equipos de seguridad pueden obtener información de seguridad a partir de sus datos. Consulte [Log Explorer][11] y [Log Search Syntax][10] para obtener más información.

## Comience {#get-started}

Si aún no tiene una cuenta de Datadog, regístrese para una [prueba gratuita][2]. Después de iniciar sesión en su cuenta de Datadog:

1. Navegue a [Cloud SIEM][12].
1. Haga clic en {{< ui >}}Enable Cloud SIEM{{< /ui >}}.
1. Siga los pasos de incorporación.

Consulte la [Guía de introducción][4] para obtener instrucciones de configuración más detalladas.

## Página de descripción general de Cloud SIEM {#cloud-siem-overview-page}

Navegue a [Cloud SIEM Overview page][3]. Utilice esta página para ver información de seguridad clave y actuar sobre flujos de trabajo comunes para analistas de seguridad, ingenieros de seguridad y detección, y gerentes del Centro de Operaciones de Seguridad (SOC). Desde la página de descripción general, puede:
- Acceda a señales importantes, incidencias abiertas y entidades de alto riesgo.
- Complete las tareas de incorporación y revise el estado de los paquetes de contenido.
- Vea e investigue las principales señales por geografía o proveedor de servicios de Internet (ISP).
- Analice las señales y reglas por tácticas de MITRE ATT&CK.
- Realizar un seguimiento del rendimiento de la detección (tiempo medio de detección (MTTD), tasas de falsos positivos).
- Lea las últimas investigaciones y notas de la versión de [Security Labs][1].

Haga clic en {{< ui >}}Customize Page{{< /ui >}} para reordenar u ocultar módulos para que pueda ver lo que es importante para usted.

Obtenga más información sobre cada sección de la página de descripción general de Cloud SIEM a continuación.

### Rendimiento de las reglas de detección {#detection-rules-performance}

{{< img src="security/security_monitoring/landing/07_detection_rule_performance.png" alt="" style="width:100%;" >}}

#### KPIs de MTTD para Cloud SIEM {#mttd-kpis-for-cloud-siem}

Vea el Tiempo Medio de Detección (MTTD) en todas las señales. Los mosaicos a continuación muestran el MTTD para señales críticas, altas y medias. Haga clic en un mosaico para visualizar las señales con esa gravedad en el Explorador de señales.

#### Actividad de señales {#signal-activity}

Visualice las tendencias de las señales durante el período de tiempo seleccionado. Seleccione las casillas de verificación de gravedad en la parte inferior del gráfico de barras para acotar el contexto según la gravedad, lo cual puede ser útil para identificar picos o caídas inusuales.
