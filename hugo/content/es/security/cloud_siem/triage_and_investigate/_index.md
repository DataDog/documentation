## Descripción general {#overview}

Cloud SIEM ofrece herramientas integradas para agilizar las investigaciones de Security después de que se genera una señal de Security. Estas herramientas lo guían a través del siguiente flujo de trabajo de investigación cuando se activa una señal de Security:

- Evaluación de amenazas
- Comprensión del contexto
- Determinación del impacto

Comience con [Investigate Security Signals][1] para clasificar e investigar señales utilizando el explorador de señales. Filtre por gravedad, entidad o marco temporal para evaluar rápidamente qué activó las detecciones y decidir qué señales requieren atención inmediata.

Para un enfoque más centrado en la entidad, [Entity Risks][2] consolida las señales de SIEM, los hallazgos de Cloud Security y los riesgos de identidad en perfiles de entidad unificados que representan a usuarios o activos junto con un modelo de puntuación de riesgo basado en opiniones.

Para obtener una comprensión amplia de cómo se mueve un actor a través de su ecosistema, la interfaz gráfica [Investigator][3] mapea las conexiones entre entidades y actividades a lo largo del tiempo.
