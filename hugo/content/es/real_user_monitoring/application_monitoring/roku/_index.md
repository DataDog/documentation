## Descripción general {#overview}

Datadog Real User Monitoring (RUM) le permite visualizar y analizar el rendimiento en tiempo real y los recorridos de los usuarios individuales de su aplicación.

## Comience a hacer un seguimiento de aplicaciones de Roku {#start-monitoring-roku-applications}

Para comenzar con RUM para Roku, cree una aplicación y configure el SDK de Roku.
