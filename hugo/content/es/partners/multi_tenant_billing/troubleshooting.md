title: Solución de problemas
---
## La creación de la Trial Org falla o devuelve un error {#trial-org-creation-fails-or-returns-an-error}

Envíe el {{< ui >}}Trial Org Provisioning{{< /ui >}}formulario nuevamente. Si el error persiste, comuníquese con [partner-support@datadoghq.com][1] con el nombre y la región de la Trial Org que falló.

## Una organización de clientes no aparece bajo una Admin Org {#a-customer-org-isnt-appearing-under-an-admin-org}

Una organización de clientes se conecta a la Admin Org del socio automáticamente cuando su contrato incluye la asociación y está activa. Si falta la organización de clientes, comuníquese con [partner-support@datadoghq.com][1] para obtener asistencia.

## La página de Aprovisionamiento de Trial Org no está disponible {#the-trial-org-provisioning-page-isnt-available}

Esta capacidad debe estar habilitada en la Admin Org. Comuníquese con [partner-support@datadoghq.com][1] para que se habilite.

## Un socio no es invitado a una nueva Admin Org {#a-partner-isnt-invited-to-a-new-admin-org}

Si un socio no es invitado después de que se crea una Admin Org, comuníquese con [partner-support@datadoghq.com][1].

## Más ayuda {#further-help}

Para cualquier problema no cubierto anteriormente, comuníquese con [partner-support@datadoghq.com][1]. Incluya el ID o nombre de la Admin Org y, cuando sea relevante, el ID de la Trial Org o el ID de la organización de clientes.

[1]: mailto:partner-support@datadoghq.com
