## Présentation {#overview}

{{< img src="observability_pipelines/packs/mitre_attack_cloudtrail_enrichment.png" alt="Le pack d'enrichissement MITRE ATT&CK CloudTrail" style="width:25%;" >}}

Ce pack étiquette les logs CloudTrail avec les tactiques et techniques MITRE ATT&CK.

Ce que fait ce pack :

- Étiquette les événements avec des techniques MITRE.
- Associe les connexions, les modifications IAM et les événements d'exécution
- Signale les événements comme pertinents pour la sécurité
