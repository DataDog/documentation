## Présentation {#overview}

{{< img src="observability_pipelines/packs/palo_alto_microsoft_sentinel.png" alt="Le pack Palo Alto Networks - Microsoft Sentinel." style="width:25%;" >}}

Ce pack mappe les journaux PAN-OS vers le schéma CommonSecurityLog dans Microsoft Sentinel.

Ce que fait ce pack :

- Mappe les journaux de trafic PAN-OS vers CommonSecurityLog.
- Remappe les journaux de menace, de configuration et de système vers CommonSecurityLog.
- Normalise les champs de trafic, de menace et de système pour l'ingestion dans Sentinel.
