## Présentation {#overview}

{{< img src="observability_pipelines/packs/windows_dns_log.png" alt="Le Windows DNS Log pack" style="width:25%;" >}}

Le Windows DNS Server analytic log couvre les requêtes, les transferts de zone et les mises à jour dynamiques.

Ce que fait ce pack :

- Analyse les champs de requête
- Signale les transferts de zone
- Échantillonne les requêtes de routine
