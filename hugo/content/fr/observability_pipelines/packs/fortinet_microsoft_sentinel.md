## Présentation {#overview}

{{< img src="observability_pipelines/packs/fortinet_microsoft_sentinel.png" alt="Le pack Fortinet - Microsoft Sentinel" style="width:25%;" >}}

Ce pack mappe les journaux FortiGate vers le schéma CommonSecurityLog dans Microsoft Sentinel.

Ce que fait ce pack :

- Mappe les journaux de trafic FortiGate vers CommonSecurityLog
- Remappe les événements UTM, IPS, VPN et auth vers CommonSecurityLog
