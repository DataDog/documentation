## Présentation {#overview}

{{< img src="observability_pipelines/packs/google_secops_palo_alto_firewall.png" alt="Le pack Google SecOps - Palo Alto Firewall" style="width:25%;" >}}

Ce pack remappe les journaux PAN-OS vers le schéma UDM dans Google Security Operations.

Ce que fait ce pack :

- Remappe tous les types de logs PAN-OS vers UDM
- Définit le type d'événement et l'action pour chaque journal
- Remappe les champs principal, cible et réseau
