## Présentation {#overview}

{{< img src="observability_pipelines/packs/aws_config.png" alt="Le pack AWS Config" style="width:25%;" >}}

AWS Config surveille et enregistre les modifications de configuration des ressources.

Ce que fait ce pack :

- Conserve uniquement les événements de changement de conformité
- Supprime les livraisons d'instantanés de configuration
- Marque les ressources non conformes
