## Présentation {#overview}

{{< img src="observability_pipelines/packs/orca_security.png" alt="Le pack Orca Security" style="width:25%;" >}}

Ce pack normalise les résultats cloud d'Orca Security pour le routage vers SIEM et data lake.

Ce que fait ce pack :

- Supprime les résultats informatifs
- Échantillonne les résultats de faible gravité à 10%
- Normalise les champs de gravité, d'asset et de cloud
