## Présentation {#overview}

{{< img src="observability_pipelines/packs/mitre_attack_windows_enrichment.png" alt="Le pack d'enrichissement Windows MITRE ATT&CK" style="width:25%;" >}}

Ce pack marque les journaux d’événements Windows avec les tactiques et techniques MITRE ATT&CK.

Ce que fait ce pack :

- Marque les événements avec des techniques MITRE.
- Mappe les ouvertures de session, les modifications de compte et les événements d'exécution
- Signale les événements comme pertinents pour la sécurité.
