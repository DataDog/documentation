## Présentation {#overview}

{{< img src="observability_pipelines/packs/google_secops_aws_vpc.png" alt="Le pack Google SecOps - AWS VPC" style="width:25%;" >}}

Ce pack mappe les enregistrements de flux AWS VPC vers le schéma UDM dans Google Security Operations.

Ce que fait ce pack :

- Mappe les flux VPC vers l'UDM
- Définit l'action à partir du verdict de flux VPC
- Mappe les adresses IP, les octets et la ressource VPC
