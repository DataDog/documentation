## Présentation {#overview}

{{< img src="observability_pipelines/packs/exabeam_windows.png" alt="Le pack Exabeam - Windows" style="width:25%;" >}}

Ce pack traite les journaux d'événements Windows envoyés à Exabeam et filtre selon les codes utilisés par les analyseurs Exabeam, tout en conservant le XML brut intact pour le parsing.

Ce que fait ce pack :

- Conserve le XML brut intact
- Conserve les journaux Sysmon et PowerShell
- Supprime les codes Security inutilisés
