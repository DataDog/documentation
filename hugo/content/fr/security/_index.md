## Présentation {#overview}

Apportez vitesse et évolutivité à vos opérations de sécurité en production. Datadog Security offre une détection des menaces en temps réel et des audits de configuration continus sur les applications, les hosts, les conteneurs et l'infrastructure cloud. Couplé à la plateforme d'observabilité Datadog plus large, Datadog Security apporte une intégration sans précédent entre la sécurité et les opérations, alignée sur les objectifs communs de votre organisation.

Datadog Security inclut : 
- [Cloud SIEM](#cloud-siem)
- [Code Security](#code-security)
- [Cloud Security](#cloud-security)
- [App and API Protection](#app-and-api-protection)
- [AI Guard](#ai-guard)
- [Workload Protection](#workload-protection)
- [Sensitive Data Scanner](#sensitive-data-scanner)
 
Pour en savoir plus, consultez la [30-second Product Guided Tour][14].

## Cloud SIEM {#cloud-siem}

[Cloud SIEM][4] (Security Information and Event Management) détecte en temps réel les menaces pesant sur votre application et votre infrastructure, comme une attaque ciblée, une adresse IP communiquant avec vos systèmes qui correspond à une liste de renseignements sur les menaces, ou une configuration non sécurisée. Cloud SIEM est alimenté par [Datadog Log Management][5]. En combinant ces domaines, vous pouvez [automatiser la remédiation des menaces détectées par Datadog Cloud SIEM][6] afin d'accélérer votre workflow de réponse aux menaces. Consultez la [Guided Tour](https://www.datadoghq.com/guided-tour/security/cloud-siem/) dédiée pour en savoir plus.

## Code Security {#code-security}

[Code Security][20] analyse votre code propriétaire et les bibliothèques open source utilisées dans vos applications, à la fois dans vos dépôts et dans vos services en cours d'exécution, offrant une visibilité de bout en bout, du développement à la production. Il englobe les capacités suivantes :

- [Static Code Analysis (SAST)][27] pour identifier les problèmes de sécurité et de qualité dans votre code propriétaire
- [Software Composition Analysis (SCA)][28] pour identifier les dépendances open source dans vos dépôts et vos services
- [Runtime Code Analysis (IAST)][29] pour identifier les vulnérabilités dans le code propriétaire au sein de vos services
- [Secret Scanning][30] pour identifier et valider les secrets divulgués (en préversion)

Grâce aux intégrations IDE, aux commentaires sur les demandes de fusion et aux portes CI/CD, Code Security aide les équipes à mettre en œuvre le DevSecOps dans toute l'organisation :
- **Développeurs :** détection précoce des vulnérabilités, améliorations de la qualité du code, développement plus rapide car les développeurs passent moins de temps à déboguer et à corriger.
- **Administrateurs de sécurité :** posture de sécurité renforcée, gestion améliorée des correctifs en réponse aux alertes précoces de vulnérabilité et surveillance de la conformité.
- **Ingénieurs de fiabilité de site (SRE) :** checks de sécurité automatisés tout au long du workflow CI/CD, conformité de sécurité et résilience du système. SAST réduit la charge manuelle pour les SRE et garantit que chaque version est minutieusement testée pour détecter les vulnérabilités.

## Cloud Security {#cloud-security}

[Cloud Security][10] offre une détection des menaces en temps réel et des audits de configuration continus sur l'ensemble de votre infrastructure cloud, le tout dans une vue unifiée pour une collaboration transparente et une remédiation plus rapide. Grâce aux données d'observabilité, les équipes de sécurité peuvent déterminer l'impact d'une menace en retraçant le flux d'attaque complet et identifier le propriétaire de la ressource où une vulnérabilité a été déclenchée.

Cloud Security inclut [Workload Protection][12], [Misconfigurations][11], [Identity Risks][15] et [Vulnerabilities][16]. Pour en savoir plus, consultez la [Guided Tour][13] dédiée.

{{< img src="security/csm/csm_overview_3.png" alt="La boîte de réception de sécurité sur la vue d'ensemble de Cloud Security affiche une liste des problèmes de sécurité classés par priorité" width="100%">}}

Pour commencer avec Datadog Security, accédez à la page [{{< ui >}}Security{{< /ui >}} > {{< ui >}}Setup{{< /ui >}}][9] dans Datadog, qui contient des informations détaillées pour une configuration unique ou multiple, ou suivez les sections de mise en route ci-dessous pour en savoir plus sur chaque domaine de la plateforme.

##  App and API Protection {#app-and-api-protection}

Datadog [App and API Protection (AAP)][1] offre une visibilité sur les attaques au niveau des applications qui visent à exploiter les vulnérabilités au niveau du code, telles que la falsification de requête côté serveur (SSRF), l'injection SQL, Log4Shell et le cross-site scripting (XSS) réfléchi. AAP s'appuie sur [Datadog APM][2], le [Datadog Agent][3] et des règles de détection intégrées à l'application pour détecter les menaces dans votre environnement applicatif. Consultez la [Guided Tour](https://www.datadoghq.com/guided-tour/security/application-security-management/) du produit pour en voir plus.

{{< img src="/security/application_security/app-sec-landing-page.png" alt="Un panneau de signalement de sécurité dans Datadog, qui affiche les flux d'attaque et les graphes de flammes" width="75%">}}

## AI Guard {#ai-guard}

[AI Guard][35] inspecte, bloque et régit le comportement de l'IA en temps réel. Il s'intègre directement à votre application ou agent d'IA pour protéger contre les attaques par injection de prompt, le jailbreaking et l'exfiltration de données sensibles, en utilisant Prompt Protection, Tool Protection et Sensitive Data Protection. Ces protections fonctionnent pour tout modèle d'IA cible, y compris OpenAI, Anthropic, Bedrock, VertexAI et Azure.

{{< img src="security/ai_guard/ai_guard_detection_rules_1.png" alt="AI Guard Detection Rules Explorer" width="100%">}}

## Workload Protection {#workload-protection}

[Workload Protection][26] surveille l'activité des fichiers, du réseau et des processus dans votre environnement pour détecter les menaces en temps réel sur votre infrastructure. En tant que partie intégrante de la plateforme Datadog, vous pouvez combiner la détection des menaces en temps réel de Workload Protection avec des métriques, des logs, des traces et d'autres télémétries pour avoir une vue complète du contexte entourant une attaque potentielle sur vos charges de travail.

- Bloquez les menaces de manière proactive avec [Automated response][31].
- Gérez les [règles de détection][32] prêtes à l'emploi et personnalisées.
- Configurez des [notifications][33] en temps réel.
- Enquêtez sur les [signaux de sécurité][34] et remédiez-y.

## Sensitive Data Scanner {#sensitive-data-scanner}

[Sensitive Data Scanner][24] peut aider à prévenir les fuites de données sensibles et à limiter les risques de non-conformité en découvrant, classant et, éventuellement, en masquant les données sensibles. Il peut analyser vos données de télémétrie à la recherche de données sensibles, telles que les logs d'application, les spans APM, les événements RUM et les événements issus d'Event Management. Il peut également analyser vos ressources de stockage cloud à la recherche d'informations sensibles. 

Une fois que vous avez [configuré Sensitive Data Scanner][25], utilisez la page {{< ui >}}Findings{{< /ui >}} pour afficher les détails des données sensibles identifiées, afin de trier, enquêter et remédier aux résultats.
