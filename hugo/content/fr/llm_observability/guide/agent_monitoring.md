## Présentation {#overview}

Agent Observability vous permet de surveiller, dépanner et améliorer vos applications agentiques. Avec le SDK Agent Observability pour Python, vous pouvez surveiller la santé et la qualité de vos systèmes single- ou multi-agentic construits sur [OpenAI Agents SDK][1], [LangGraph][2] ou [CrewAI][3].

Pour vos applications agentiques, Agent Observability vous permet de :

- Surveillez le taux d'erreur, l'accumulation de latence ou le coût 
- Visualisez les décisions des agents, telles que les outils utilisés ou l'agent auquel une tâche a été transférée
- Tracez et dépannez les requêtes de bout en bout des exécutions d'agents
