## La création de l'organisation d'essai échoue ou renvoie une erreur {#trial-org-creation-fails-or-returns-an-error}

Soumettez à nouveau le {{< ui >}}Trial Org Provisioning{{< /ui >}}formulaire. Si l'erreur persiste, contactez [partner-support@datadoghq.com][1] en indiquant le nom et la région de l'organisation d'essai qui a échoué.

## Une organisation cliente n'apparaît pas sous une organisation Admin {#a-customer-org-isnt-appearing-under-an-admin-org}

Une organisation cliente se connecte automatiquement à l'organisation Admin du partenaire lorsque son contrat inclut le partenariat et est actif. Si une organisation cliente est absente, contactez [partner-support@datadoghq.com][1] pour obtenir de l'aide.

## La page de provisionnement de l'organisation d'essai n'est pas disponible {#the-trial-org-provisioning-page-isnt-available}

Cette fonctionnalité doit être activée sur l'organisation Admin. Contactez [partner-support@datadoghq.com][1] pour l'activer.

## Un partenaire n'est pas invité à une nouvelle organisation Admin {#a-partner-isnt-invited-to-a-new-admin-org}

Si un partenaire n'est pas invité après la création d'une organisation Admin, contactez [partner-support@datadoghq.com][1].

## Aide supplémentaire {#further-help}

Pour tout problème non couvert ci-dessus, contactez [partner-support@datadoghq.com][1]. Incluez l'ID ou le nom de l'organisation Admin et, le cas échéant, l'ID de l'organisation d'essai ou l'ID de l'organisation cliente.

[1]: mailto:partner-support@datadoghq.com
