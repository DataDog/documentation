## Présentation {#overview}

Datadog Real User Monitoring (RUM) vous permet de visualiser et d'analyser les performances en temps réel et les parcours des utilisateurs de votre application.

## Commencez à surveiller les applications Roku {#start-monitoring-roku-applications}

Pour commencer avec RUM pour Roku, créez une application et configurez le SDK Roku.
