Utilisez les graphiques Product Analytics pour visualiser les parcours des utilisateurs de bout en bout afin de découvrir les différentes manières dont ils naviguent dans votre application. Vous pouvez extraire des données pour identifier les points de friction dans le parcours utilisateur, mesurer le succès des modifications de l'interface utilisateur et éclairer les décisions de conception. 

## Décider quel graphique utiliser {#deciding-which-chart-to-use}

### Funnel {#funnel}

Les graphiques [Funnel][2] vous aident à comprendre la conversion de bout en bout d'un unique workflow essentiel. Vous pouvez afficher les détails dans le panneau latéral pour comprendre pourquoi les taux de conversion sont ce qu'ils sont.
Par exemple, vous pouvez déterminer s'il y a eu un problème de performance qui a causé l'abandon des utilisateurs. Les clients rencontrent-ils une erreur survenue lors d'une version récente ? Regardez le Session Replay d'un utilisateur qui a converti ou abandonné pour voir exactement ce qui s'est passé.

{{< img src="/product_analytics/funnel_chart.png" alt="Comprenez les conversions de bout en bout avec Funnel Analysis.">}}

### Journey Paths {#journey-paths}

Les diagrammes [Journey Paths][5] vous permettent de voir les chemins les plus courants que les utilisateurs empruntent entre des événements sélectionnés, y compris les événements de vue et d'action, pour les utilisateurs ayant converti et ceux ayant abandonné.

{{< img src="product_analytics/journeys/journey_paths/pana_journey_paths_conversion_chart_2.png" alt="Un graphique de parcours utilisateur rendu montrant les principaux chemins empruntés par les utilisateurs entre deux vues." style="width:100%;" >}}

### Pathways {#pathways}

Les diagrammes [Pathways][3] vous permettent de visualiser tous les parcours utilisateur dans votre application afin d'identifier les contributions les plus importantes à un flux.

{{< img src="/product_analytics/journeys/pathways/pathways_chart.png" alt="Le diagramme Pathways par défaut pour une application." style="width:90%;" >}}

### Retention {#retention}

Les graphiques [Retention][4] visualisent la fréquence à laquelle les utilisateurs reviennent avec succès sur une page ou effectuent une action. Cette mesure offre un aperçu de la satisfaction globale des utilisateurs vis-à-vis de votre application. 

{{< img src="/product_analytics/retention/retention_chart.png" alt="Un exemple de graphique Retention Analysis." style="width:90%;" >}}

### Analytics {#analytics}

[Analytics][1] vous permet d'explorer la manière dont votre produit est utilisé. Vous pouvez analyser les sessions, les événements et les profils d'utilisateurs, puis ventiler, comparer et visualiser les données dans divers types de graphiques.

{{< img src="/product_analytics/analytics/analytics_chart.png" alt="Un exemple de graphique analytique." style="width:90%;" >}}
