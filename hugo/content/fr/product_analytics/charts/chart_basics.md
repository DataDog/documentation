Créez, enregistrez et partagez des Product Analytics charts selon vos besoins pour faciliter l'analyse des utilisateurs et des produits. 

## Créer un graphique {#create-a-chart}

Explorez le comportement des utilisateurs ou visualisez les métriques de produit en créant un graphique à partir de zéro, ou en partant d'un modèle prédéfini.

Pour créer un graphique à partir de zéro, dans la barre latérale Product Analytics, sélectionnez {{< ui >}}Create New{{< /ui >}}, puis sélectionnez un type de graphique. 

{{< img src="product_analytics/chart_basics/chart_basics_create.png" alt="Product Analytics sidebar montrant le bouton Create New et la liste des types de graphiques parmi lesquels choisir." style="width:50%;" >}}

Pour créer un graphique à partir d'un modèle, depuis la page de Product Analytics {{< ui >}}Charts{{< /ui >}}, cliquez sur {{< ui >}}Explore all templates{{< /ui >}}. 

{{< img src="product_analytics/chart_basics/chart_basics_template.png" alt="Page des graphiques montrant la section 'Start with a Chart Template' et le lien Explore all templates." style="width:100%;" >}}

## Enregistrer ou partager un graphique {#save-or-share-a-chart}

Enregistrez un graphique pour suivre les métriques clés du produit au fil du temps, ou partagez-le afin que votre équipe puisse agir sur la base des mêmes aperçus.

{{< img src="product_analytics/chart_basics/chart_basics.png" alt="Éditeur de graphique avec des légendes numérotées pour le champ du nom du graphique et les boutons 'Share' et 'Save'." style="width:100%;" >}}

1. Cliquez sur le nom du graphique pour le renommer.

2. Cliquez sur {{< ui >}}Save{{< /ui >}} pour enregistrer le graphique sur la page {{< ui >}}Charts{{< /ui >}}. Utilisez le menu déroulant pour enregistrer le graphique dans un dashboard ou un notebook. 

   Cliquez sur {{< ui >}}Share{{< /ui >}} pour copier le graphique dans votre presse-papiers. Utilisez le menu déroulant pour exporter le graphique au format PNG, ou pour exporter les données du graphique au format CSV, si disponible.
