## Overview

The [Datadog Learning Center][1] offers free, self-paced courses with hands-on labs. Courses are listed alphabetically, and each entry links to the course page and names the Learning Center collections that include it. For curated sequences of courses, see [Learning Center Learning Paths][2].

## Courses

- [Advanced Log Configuration][3]: Learn to fix common log collection issues, such as multi-line logs, log parsing, and filtering. Collections: Logs.
- [APM Monitors and Alerting][4]: Learn to create and modify effective APM monitors and alerts so your systems are properly monitored and the correct teams notified when something goes wrong. Collections: APM, Monitors and Alerting.
- [APM Rate Limiting and Retention][5]: Control APM trace retention and rate limiting for your applications. Add ingestion and retention filters, create metrics from traces, and monitor trace usage to better manage your APM data. Collections: APM, Governance.
- [Automate Threat Investigation and Remediation with Security Workflows][6]: Automate security investigation and remediation tasks with Datadog Workflow Automation and Cloud SIEM. Create security workflows using Cloud SIEM Content Packs and SOAR blueprints. Automate threat remediation in AWS using security workflows. Collections: AWS, Security.
- [Automating Meaningful Actions with Datadog Workflow Automation][7]: Learn how to automate security responses and operational remediation using Datadog Workflow Automation, from fixing cloud misconfigurations to rolling back faulty deployments and maintaining tag hygiene. Collections: Actions and Remediations.
- [Block Application Attacks with Application & API Protection][8]: Block application-level attacks using App & API Protection. Thwart attackers by blocking malicious IP addresses and users directly from security signals within the Datadog UI. Use the In-App WAF to block attack tools and suspicious traffic. After taking this course, you can defend your applications using Datadog. Collections: Security.
- [Build and Manage Log Pipelines][9]: Build a custom log pipeline to extract attributes and assign log statuses. Use the Pipeline Scanner to check how logs are processed, and learn how Standard Attributes normalize attribute names across sources. Collections: Logs.
- [Build Self-Serve Apps with App Builder for Third-Party Integrations][10]: Learn how to build an App Builder app that interacts with GitHub. Use tables, modals, and forms to create issues, list pull requests (PRs), and post comments on the PRs—all from your app. Collections: Actions and Remediations.
- [Collect custom data with RUM for JavaScript web applications][11]: Learn how to use Datadog Real User Monitoring (RUM) to collect custom data from your JavaScript web applications. Collections: Digital Experience, RUM.
- [Configure and manage the APM SDK for your applications][12]: Configure and manage the APM SDK for your applications. Apply recommended practices and build confidence when adding APM to your applications. Collections: APM.
- [Configure AWS Lambda for Serverless Monitoring with Datadog][13]: Learn to integrate Datadog Lambda Extension into serverless applications, analyze function performance using Serverless View and APM, and diagnose issues like cold starts and bottlenecks in AWS Lambda functions. Collections: AWS, Configure and Develop.
- [Configure Cloud SIEM for AWS][14]: Secure your cloud environments with Datadog Cloud SIEM. Enable Cloud SIEM, ingest cloud audit logs, and install a Content Pack. The lab and examples in this course feature AWS. The concepts are applicable to multiple cloud providers. Collections: AWS, Configure and Develop, Security.
- [Configure Log Collection for a Containerized Application][15]: Learn how to set up logging and log ingestion for an app that is built with Ruby and Python services in a Docker environment. The concepts are applicable to other languages, frameworks, and environments. Collections: Configure and Develop, Logs.
- [Configure Real User Monitoring (RUM) for JavaScript web applications][16]: Learn about the different configuration options when setting up Datadog RUM on your JavaScript web applications. Collections: Configure and Develop, Digital Experience, RUM.
- [Configuring Single Step Instrumentation on Kubernetes][17]: Accelerate APM instrumentation time of your application in Kubernetes without editing code. Collections: APM, Configure and Develop, Kubernetes.
- [Create an Agent Integration][18]: This course guides you through the development process for a sample Datadog integration, presenting the associated tooling along with the coding and configuration steps, all with a view to helping you start building your own integrations. Collections: Configure and Develop.
- [Create Custom Metrics with DogStatsD][19]: Learn how to use DogStatsD to send custom metrics to Datadog. Collections: Metrics.
- [Create Custom Metrics with OTel][20]: Inspect custom metrics from your OTel applications, add new metrics, and examine tradeoffs in their types and attributes. Collections: Metrics, OpenTelemetry.
- [Create Custom Spans and Span Tags with APM][21]: Learn how to create custom spans, create tags for those spans, and create measures from tags to surface data and troubleshoot issues with Datadog APM. Collections: APM.
- [Customize Alert Monitor Notifications][22]: Craft dynamic and descriptive notification messages for alert monitors using conditional, tag, and template variables. In the hands-on lab, you gain practical experience by drafting and testing notification messages so they are clear and actionable. Collections: Monitors and Alerting.
- [Datadog API: Automation and Infrastructure as Code][23]: In this course, you take a hands-on tour of the Datadog API and its capabilities. You also learn a variety of ways to communicate with the Datadog API, with an emphasis on automated methods. Collections: Configure and Develop.
- [Datadog Quick Start][24]: Explore data and insights in Dashboards, Logs, Catalog, and Monitors for a live application environment. Become confident finding your way around Datadog features you use every day. Collections: Getting Started.
- [Debugging Logs Pipelines][25]: Identify the signs of problems in your log pipelines. Use the Pipeline Scanner to locate where processed logs have been modified. Locate and correct patterns defined in Grok Processors to make sure your logs are parsed correctly. Collections: Logs.
- [Define User Behavior with Labeled Actions in Product Analytics][26]: Learn how to define meaningful user behavior with Labeled Actions in Product Analytics. Collections: Product Analytics.
- [Detect and Block Leaked Secrets with Datadog][27]: Detect and block leaked secrets before they reach production. Scan your repositories with Datadog Code Security (Secret Scanning), use live validation to confirm whether a leaked credential is still active, remediate the secret, and establish automated quality gates that block merges introducing new secrets. Collections: Security.
- [Detect and Investigate Threats with Cloud SIEM][28]: Secure your cloud environments with Datadog Cloud SIEM and cloud provider Content Packs. Explore out-of-the-box threat detection rules. Investigate incoming threats using security signals, Signals Explorer, and Cloud SIEM Investigator. Collections: AWS, Security.
- [Detect and Remediate IaC Misconfigurations with Datadog][29]: Detect and fix Infrastructure as Code misconfigurations before they reach production. Scan Terraform, Kubernetes manifests, and CI/CD pipeline definitions with Datadog Code Security (IaC Security), triage findings in context, remediate misconfigurations, tune the ruleset in configuration as code, and write a custom rule in Rego. Collections: Security.
- [Detect Host and Container Compromises with Workload Protection][30]: Monitor file, network, process, and kernel activity with Workload Protection. Detect and investigate intrusions and running malware in real-time. Secure containerized and host-based workloads. Collections: AWS, Security.
- [Detect Web Application Attacks with Application & API Protection][31]: Detect attacks against a vulnerable web application using Application & API Protection in Datadog. Create a custom detection rule to enhance your defenses. Collections: Security.
- [Diagnose Code Performance Issues with Continuous Profiler][32]: Investigate and improve application code performance in production with Datadog Continuous Profiler. Collections: APM.
- [Diagnosing Application Bugs with Datadog APM][33]: Use several features of the Datadog APM product to identify bugs within application code. Using insights gained from APM, fix those bugs and verify your fixes have made a difference in stability and performance. Collections: APM.
- [Discovering Graph Widgets][34]: In this course, you learn how to create, configure, and use Datadog dashboard graph widgets. You track the metrics and performance of a web application and discover how to present important data using these popular widget types. Collections: Dashboards and Notebooks.
- [Discovering Table, List, SLO, and Architecture Widgets][35]: In this course, you learn how to create, configure, and use Datadog dashboard table, list, SLO, and architecture widgets. You track the metrics and performance of a web application and discover how to present important data using these popular widget types. Collections: Dashboards and Notebooks.
- [Dive Deeper into Log Queries and Aggregations][36]: Create visualizations for counts and statistics of log attributes. Build multiple queries and formulas simultaneously. Use functions to transform data in visualizations. Aggregate logs based on patterns and transactions (related sequences of events). Collections: Logs.
- [Enable and Manage Workload Protection][37]: Enable Datadog Workload Protection. Manage security agent rules and detection rules in Datadog. Collections: AWS, Security.
- [Enhance Log Querying and Analytics with Reference Tables, Subqueries, and Calculated Fields][38]: Combine metadata with your logs using Reference Tables. Filter one set of logs against another set of logs using Subqueries. Create new fields using existing tags and attributes at query time using Calculated Fields. Collections: Logs.
- [Find and Fix Code Vulnerabilities with Datadog Static Code Analysis (SAST)][39]: Find and fix vulnerabilities in your first-party code with Datadog Static Code Analysis (SAST). Triage findings, assess exploitability, and block insecure code from merging. Collections: Security.
- [Find and Remediate Vulnerable Cloud Resources with Cloud Security Misconfigurations][40]: Secure your cloud environments with Datadog Cloud Security Misconfigurations. Enable continuous misconfiguration scanning across your entire cloud infrastructure. Detect, prioritize, and remediate insecure cloud resources in multiple cloud providers. Collections: AWS, Google Cloud, Security.
- [Getting Started with Agent Observability][41]: Learn to build, instrument, and monitor AI-powered applications using Datadog's Agent Observability. This course covers integrating Large Language Models into applications, implementing comprehensive observability, and troubleshooting performance issues. You work hands-on with a chatbot application, learning to track costs, monitor performance, and maintain quality in production LLM applications. Collections: AI Observability, Getting Started.
- [Getting Started with APM Metrics and Traces][42]: Get started with APM metrics and traces in Datadog. Monitor service health and performance with Application Performance Monitoring (APM). Explore traces to understand requests and interactions between services. Track key metrics to understand trends that impact system behavior and user experience. Collections: APM, Getting Started.
- [Getting Started with App Builder][43]: Learn the basics of App Builder by creating an app using a blueprint. Set up a connection, add actions and components, and explore how App Builder helps teams take action directly from Datadog. Collections: Actions and Remediations, Getting Started.
- [Getting Started with DDSQL Editor][44]: Query and join metrics, logs, and traces across sources using Datadog's DDSQL Editor. Collections: Dashboards and Notebooks.
- [Getting Started with Incident Management][45]: Learn how to manage incidents using Datadog Incident Management. This course teaches you how to set up Incident Management, detect and declare incidents, and guide your team through resolution. Collections: Getting Started, Service Management.
- [Getting Started with Infrastructure and Cloud Network Monitoring (CNM)][46]: Diagnose and resolve network and infrastructure issues efficiently using Datadog's Infrastructure and Cloud Network Monitoring (CNM). Learn how to monitor hosts, visualize metrics, track network traffic, and set alerts to improve performance and reduce downtime. Collections: Getting Started.
- [Getting Started with Integrations][47]: Learn how Datadog's 800+ integrations collect and report data from an expansive list of outside tools, platforms, programming languages, and more. Collections: Configure and Develop, Getting Started.
- [Getting Started with Kubernetes Observability][48]: Explore Datadog's observability capabilities for Kubernetes by navigating built-in dashboards, then using metrics and events to diagnose performance issues in real-time. Collections: Kubernetes.
- [Getting Started with Log Explorer][49]: Query logs from all of your log sources. Investigate log details. Build visualizations with Fields Aggregations. Create Saved Views. Add facets and measures. Collections: Getting Started, Logs.
- [Getting Started with Metrics][50]: Explore metric types, origins, and their role in monitoring. Practice querying, aggregating, and visualizing metrics to effectively track systems over time, establish baselines, identify patterns, and more. Collections: Getting Started, Metrics.
- [Getting Started with Monitors][51]: Create, configure, and use Datadog Monitors to stay ahead of issues. Explore various monitor types and examine the monitor status page to detect issues early and keep systems running smoothly. Collections: Getting Started, Monitors and Alerting.
- [Getting Started with Notebooks][52]: In this course, you learn how to use Datadog Notebooks to investigate incidents, document findings, and collaborate with your team. You combine logs, metrics, and SLO data to identify root causes and create shareable investigation documentation. Collections: Dashboards and Notebooks, Getting Started.
- [Getting Started with Observability in Google Cloud with Datadog][53]: Install Datadog's Google Cloud integration and configure log collection with Google Cloud Dataflow using Terraform. Install the Datadog Agent on a Compute Engine VM instance. Validate that metrics, logs, and traces are flowing from Google Cloud to Datadog. Collections: Configure and Develop, Getting Started, Google Cloud.
- [Getting Started with Observability Pipelines][54]: Collect, filter, and modify logs within your own infrastructure using Observability Pipelines. Install and configure OP workers in Kubernetes, route logs from the Datadog Agent, and apply processors to filter, enrich, and redact log data. Collections: Logs.
- [Getting Started with Product Analytics][55]: Learn how to use Product Analytics in Datadog. Collections: Product Analytics.
- [Getting Started with Service Level Objectives (SLOs)][56]: In this course, you deepen your understanding of service level objectives (SLOs) and gain hands-on experience using them to solve issues in a web application. This builds on the concepts covered in the Understanding SLOs course. Collections: Getting Started, Service Management.
- [Getting Started with Synthetic Monitoring & Browser Testing][57]: Simulate user sessions to proactively test and monitor application frontends from different locations, browsers, and devices using Datadog Synthetic Monitoring. Collections: Digital Experience, Getting Started.
- [Getting Started with Test Optimization][58]: Accelerate your CI pipelines by implementing Datadog Test Optimization. Set up test monitoring, identify flaky tests, and use Test Impact Analysis to run only the tests that matter. Gain hands-on experience with flaky test management and intelligent test selection. Collections: Getting Started, Software Delivery.
- [Getting Started with the Datadog Agent on Amazon EC2][59]: Install the Datadog Agent on EC2 instances using two different methods, SSH and AWS Systems Manager, and compare the tradeoffs between them. Use Fleet Automation to view Agent status, push configuration changes, and upgrade Agents across your fleet. Collections: AWS.
- [Getting Started with the Datadog AWS Integration][60]: Connect your AWS account to Datadog and explore the out-of-the-box visibility the Datadog AWS integration provides. Install the integration using CloudFormation, navigate the Resource Catalog and OOTB dashboards to understand your AWS infrastructure at a glance. Collections: AWS, Getting Started.
- [Getting Started with the Datadog Azure Integration][61]: Configure the Datadog Azure integration with a Microsoft Entra ID app registration to collect metrics and resource inventory. Explore out-of-the-box dashboards, the Resource Catalog, and Cloudcraft, then build a custom Azure dashboard with Bits Chat. Collections: Azure, Getting Started.
- [Getting Started with Universal Service Monitoring (USM)][62]: Automatically detect, map, manage, and monitor services in your environment with Datadog's Universal Service Monitoring and Catalog, with no code-level instrumentation required. Collections: Configure and Develop, Getting Started.
- [Intro to Real User Monitoring (RUM)][63]: How does your user experience impact operational success? Use data from real end-users to track UX, performance, deployments, and errors—all while gaining visibility into precisely how users interact with your apps. Collections: Digital Experience, RUM.
- [Introduction to Cloud SIEM][64]: In this course, you learn the fundamentals about how to use Cloud SIEM in Datadog to detect different types of security threats and attacks. Collections: AWS, Google Cloud, Security.
- [Introduction to Dashboards][65]: This course demonstrates how to use the fundamental tools of the Dashboard product. You explore widgets, Integration Dashboards, and template variables. Along the way, you learn about the importance of creating a well-constructed and understandable Dashboard. Collections: Dashboards and Notebooks.
- [Introduction to Observability][66]: What is observability? Answer this question before you start using the Datadog platform. This introductory course covers the three pillars of observability and prepares you to move on to the Datadog Foundation training. Collections: Getting Started.
- [Introduction to OpenTelemetry with Datadog][67]: Configure your OpenTelemetry (OTel) instrumented system so that you can explore OTel collected metrics, traces, and logs all in Datadog. Collections: OpenTelemetry.
- [Investigate with Agent Observability][68]: Investigate AI application issues using metrics and traces. Move from high-level dashboard metrics to individual traces to identify the root cause of latency problems, silent pipeline failures, and quality issues hiding behind successful operational metrics. Collections: AI Observability.
- [Log Analytics with Notebooks][69]: Take your Datadog Notebooks skills to the next level with log analytics techniques. This intermediate course teaches you to use reference tables, transformation cells, SQL queries, and visualizations to investigate suspicious IP activity and analyze high-value transaction data. Collections: Dashboards and Notebooks.
- [Manage and Monitor Indexed Log Volumes][70]: Control and track retention and volumes of indexed logs to maintain costs using Indexes with Exclusion Filters, Logs Monitors, and the Log Management - Estimated Usage dashboard. Learn about Flex Logs vs Standard Indexing. Collections: Governance, Logs.
- [Managing Services with Catalog][71]: Understand Datadog Catalog, part of the Internal Developer Portal (IDP). Create and modify entity metadata with the UI, YAML, the Catalog API, and Terraform. Collections: Service Management.
- [Metrics Governance in Datadog][72]: Learn how to monitor, investigate, and optimize custom metrics usage in Datadog. Respond to a metrics usage alert, identify high-cardinality tags, apply Metrics without Limits, identify unused metrics, and implement governance safeguards. Collections: Governance, Metrics.
- [Monitor a Kafka Pipeline with Data Streams Monitoring][73]: Using DSM, you identify parts of a Kafka pipeline that is experiencing high latency by using the list and map views, measuring end-to-end latency, and setting up monitors to alert you when the pipeline's performance falls below expectations. Collections: APM.
- [Monitoring a Kubernetes Cluster: Installing the Agent][74]: To monitor your Kubernetes cluster with Datadog, you must install the Datadog Agent. This course walks you through the most common ways of installing Cluster Agents and node Agents on Kubernetes: the Helm chart and The Datadog Operator. Collections: Kubernetes.
- [Monitoring a Kubernetes Cluster: The Control Plane][75]: This course walks you through monitoring the control plane of a Kubernetes cluster with Datadog. It focuses on troubleshooting configuration issues, identifying useful dashboards and views in Datadog, and identifying cluster health issues. Collections: Kubernetes.
- [Monitoring a Kubernetes Cluster: Troubleshooting Workloads][76]: This course presents hands-on scenarios in which you use Datadog to identify, fix, and monitor common Kubernetes workload issues. Collections: Kubernetes.
- [Monitoring a Postgres Database with Datadog DBM][77]: Identify inefficiencies and optimize your database. View query metrics, explain plans, and visualizations from all of your databases in a single place. Collections: APM.
- [Optimize Request Latency with Profiling Timeline][78]: Pinpoint causes of poor request latency using Timeline in Continuous Profiler. View the distribution of thread activity and runtime activity over every request for full visibility into multithreaded applications. Collections: APM.
- [Optimizing Frontend Performance with RUM Browser Monitoring][79]: In this course, you learn how Datadog RUM Browser monitoring can help you find frontend performance issues before a customer complains, help you see what real users experienced on your site, and give you the data you need to pinpoint and address issues. Collections: Digital Experience, RUM.
- [Process Logs Out of the Box with Integration Pipelines][80]: Structure and enrich ingested logs from common sources using out-of-the-box and modified Integration Pipelines. Collections: Logs.
- [Progressive Delivery on Kubernetes][81]: Learn to deploy Kubernetes services safely using progressive delivery strategies, APM Deployment Tracking, and AI-powered autoremediation. Collections: Kubernetes.
- [Remediating Issues with Workflow Automation][82]: Automate redundant, time-sensitive processes. Create workflows from scratch or using blueprints. Configure actions to automate tasks and communicate with teams and third-party services. Collections: Actions and Remediations.
- [RUM Retention Filters][83]: Control your RUM session retention volume while maintaining visibility into valuable sessions. Create retention filters, understand how RUM events are evaluated against retention filters, and learn how to troubleshoot retention filter configurations. Collections: Digital Experience, Governance, RUM.
- [Sample Traces from OTel][84]: Configure tail-based sampling in an OTel Collector gateway to reduce trace volume while preserving errors, slow traces, and full-fidelity service metrics. Collections: OpenTelemetry.
- [Send AWS Logs to Datadog][85]: Learn to centralize AWS logs in Datadog. Configure Amazon Data Firehose, Lambda Forwarder, Datadog Agent, Lambda Extension, and Fluent Bit to collect logs from VPC, CloudTrail, ALB, EC2, Lambda, and ECS Fargate services. Collections: AWS.
- [Synthetic Tests in a CI/CD Pipeline][86]: In this course, you learn how to incorporate Datadog's synthetic tests into a CI/CD pipeline to help you catch bugs in code before deployment. Collections: Digital Experience.
- [Tagging Best Practices][87]: This course gives an overview of tagging concepts in Datadog, introducing the main use cases for tagging and providing recommendations for best practices. Collections: Getting Started.
- [The Agent on a Host][88]: Introduction to running the Datadog Agent on a host. Hands-on activities walk you through running and configuring the Agent to collect events, metrics, and logs from other services. Collections: Configure and Develop.
- [The Agent on Docker][89]: Introduction to running the Datadog Agent in a container. Hands-on activities walk you through running and configuring the Agent container to collect metrics and logs from other services. Collections: Configure and Develop.
- [Tracing AI Applications][90]: Learn to build, instrument, and monitor AI-powered applications using Datadog's Agent Observability. This course covers integrating Large Language Models into applications, implementing comprehensive observability, and troubleshooting performance issues. You work hands-on with a chatbot application, learning to track costs, monitor performance, and maintain quality in production AI applications. Collections: AI Observability.
- [Track Logs for Alerting and Investigations][91]: Set up alerts for logs using Log Monitors. Investigate error logs using Error Tracking. Create metrics from logs using Generate Metrics. Visualize log data in Dashboards alongside related data and insights. Collections: Logs.
- [Tracking errors with RUM for JavaScript Web Applications][92]: Learn how to use the error tracking features of Datadog Real User Monitoring (RUM) on your JavaScript web applications. Collections: Digital Experience, RUM.
- [Troubleshooting APM Instrumentation on a Host][93]: This course provides hands-on experience in troubleshooting Datadog APM for applications running on the same host as the Datadog Agent. Collections: APM.
- [Understanding OpenTelemetry][94]: Discover the fundamentals of OpenTelemetry (OTel), an open source standard for telemetry data collection. This course provides an overview of OTel's capabilities and benefits, preparing you for integrating observability into your applications. Collections: OpenTelemetry.
- [Understanding Service Level Objectives (SLOs)][95]: In this course, you learn how to create, configure, and apply service level objectives (SLOs) in Datadog to monitor the health and performance of your services. SLOs are critical for defining the expected reliability of your applications. Collections: Getting Started, Service Management.
- [Using Datadog Notebooks for Centralized Reporting][96]: In this lab, you learn how to use Datadog and the Datadog API to build a notebook that holds, over a 5-day span, both metric data and software release notes for an application. Collections: Dashboards and Notebooks.
- [Using the Datadog Distribution of OpenTelemetry Collector][97]: Combine your OpenTelemetry (OTel) configuration with the Datadog Agent to have OTel flexibility alongside advanced Datadog functionality. Collections: OpenTelemetry.
- [Write Custom Cloud SIEM Detection Rules][98]: Create custom detection rules for Datadog Cloud SIEM. Write detection rule queries using key log attributes and create notification rules to automatically alert stakeholders. Write suppression queries and manage detection rules as code. Collections: AWS, Security.
