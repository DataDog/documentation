## Overview

Bits Chat saves your conversations so you can return to them later. In [Bits Chat][1], your previous chats are listed under {{< ui >}}Recent{{< /ui >}}.

To manage a chat, hover over it under {{< ui >}}Recent{{< /ui >}}, click the {{< ui >}}...{{< /ui >}} (more actions) icon, and select one of the following:

- {{< ui >}}Rename{{< /ui >}}: Change the title of the chat.
- {{< ui >}}Share{{< /ui >}}: Share the chat with others in your organization. See [Share a chat](#share-a-chat).
- {{< ui >}}Delete{{< /ui >}}: Permanently delete the chat. Deleting a chat cannot be undone.

## Share a chat

By default, chats are private: only you can view them. To share a chat with others in your organization:

1. Under {{< ui >}}Recent{{< /ui >}}, hover over the chat, click the {{< ui >}}...{{< /ui >}} icon, and select {{< ui >}}Share{{< /ui >}}.
2. In the {{< ui >}}Share Chat{{< /ui >}} dialog, select {{< ui >}}Shared Chat{{< /ui >}}.
3. Click {{< ui >}}Copy Link{{< /ui >}} and send the link to your teammates.

Anyone in your organization with the link can view all current and future messages in the chat. Shared chats are read-only for other users: they cannot send messages, approve pending actions, share, or delete the chat.

<div class="alert alert-warning">A shared chat includes the data Bits Chat retrieved using your permissions. Before you share a chat, make sure it does not contain data that others in your organization should not see.</div>

Shared links expire automatically. The expiration date appears in the {{< ui >}}Share Chat{{< /ui >}} dialog.

### Stop sharing a chat

To stop sharing a chat, open the {{< ui >}}Share Chat{{< /ui >}} dialog and select {{< ui >}}Private Chat{{< /ui >}}. Anyone who previously had access can no longer view the chat.
