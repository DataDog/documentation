## Overview

Bits Chat saves your conversations so you can come back to them later. To see your past chats, open the {{< ui >}}History{{< /ui >}} list in [Bits Chat][1], or click {{< img src="bits_ai/icons/clock_historical.svg" inline="true" style="width:16px;" alt="History icon" >}} (the {{< ui >}}History{{< /ui >}} icon) in the Bits Chat panel.

## Manage a chat

Click {{< ui >}}...{{< /ui >}} next to a chat in {{< ui >}}History{{< /ui >}}, or in the header of an open chat, then select:

- {{< ui >}}Rename{{< /ui >}}: Change the chat title.
- {{< ui >}}Share{{< /ui >}}: Share the chat with your organization.
- {{< ui >}}Delete{{< /ui >}}: Delete the chat. This cannot be undone.

## Share a chat

Chats are private by default. To share one:

1. Click {{< ui >}}...{{< /ui >}} and select {{< ui >}}Share{{< /ui >}}.
2. Select {{< ui >}}Shared Chat{{< /ui >}}.
3. Click {{< ui >}}Copy Link{{< /ui >}} and send the link.

Anyone in your organization with the link can view the chat, including future messages. Only you can send messages in it.

<div class="alert alert-warning">Shared chats show data that Bits Chat retrieved with your permissions. Check the chat before you share it.</div>

Shared links expire automatically. The expiration date appears in the {{< ui >}}Share Chat{{< /ui >}} dialog.

To stop sharing, open the {{< ui >}}Share Chat{{< /ui >}} dialog and select {{< ui >}}Private Chat{{< /ui >}}. The link stops working for everyone else.
