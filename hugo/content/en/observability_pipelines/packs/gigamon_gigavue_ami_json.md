## Overview

{{< img src="observability_pipelines/packs/gigamon_gigavue_ami_json.png" alt="The Gigamon GigaVUE AMI JSON pack" style="width:25%;" >}}

Gigamon AMI captures application traffic metadata from GigaVUE in JSON.

What this pack does:

- Parses JSON logs into structured fields
- Extracts byte, packet, and record metrics
- Normalizes flow metadata
