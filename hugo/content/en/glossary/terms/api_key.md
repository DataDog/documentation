title: API key
---
An API key is unique to your organization. The Datadog Agent, integrations, and data submission pipelines use API keys to send metrics, traces, logs, and events to Datadog. API keys do not authenticate users or applications. To access the Datadog API programmatically, use an application key instead. For more information, see the <a href="/account_management/api-app-keys/#api-keys">API and Application Keys documentation</a>.
