title: application key
---
An application key gives access to the Datadog API to read data, manage resources, and perform administrative actions. Application keys are associated with the user or service account that created them and, by default, inherit those permissions. You can further restrict an application key with scopes. For more information, see the <a href="/account_management/api-app-keys/#application-keys">API and Application Keys documentation</a>.
