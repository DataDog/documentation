데이터셋, 오프라인 실험, 플레이그라운드를 통해 LLM 애플리케이션을 반복적으로 개선하세요. 저장된 입력값을 기준으로 프롬프트와 모델 변경 사항을 테스트하고, 배포하기 전에 결과를 비교하세요. 배포 후에는 Online Experiments를 사용하여 변경 사항이 실제 트래픽에 미치는 영향을 측정하세요.
