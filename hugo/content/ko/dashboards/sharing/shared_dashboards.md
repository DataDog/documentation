## 개요 {#overview}


Datadog의 공유 대시보드를 사용하면 외부 사용자나 로그인을 원하지 않는 사용자가 대시보드를 볼 수 있습니다. 각각 고유한 구성 옵션 세트를 가진 여러 공유 대시보드를 생성할 수 있습니다.

대시보드를 공유하려면 대시보드 페이지 오른쪽 상단에서 {{< ui >}}Share{{< /ui >}}를 클릭한 다음 {{< ui >}}Share dashboard{{< /ui >}}를 클릭하세요. 기존 공유 대시보드를 조회하거나 편집하려면 {{< ui >}}Share{{< /ui >}}를 클릭한 다음 {{< ui >}}Manage shared dashboards{{< /ui >}}를 클릭하세요.

{{< img src="/dashboards/sharing/shared_dashboards/manage_modal.png" alt="공유 대시보드 관리 모달 예시" style="width:90%;" >}}

조직 내 모든 공유 대시보드와 해당 공개 액세스 설정은 [공유 대시보드 페이지][2]에 나열되어 있습니다. [공개 공유 설정 페이지][3]에서 특정 공유 유형 비활성화 또는 초대 최대 액세스 기간 설정과 같은 추가 보안 구성을 추가할 수도 있습니다.

**참고**: 공유 대시보드 기능이 비활성화되면 대시보드에 더 이상 공개적으로 액세스할 수 없습니다. 그러나 해당 구성은 계속해서 조회 및 편집할 수 있습니다. 이 기능은 개별 대시보드의 {{< ui >}}Active{{< /ui >}} 또는 {{< ui >}}Paused{{< /ui >}} 상태와 관계없이 독립적으로 작동하며, {{< ui >}}Active{{< /ui >}} 공유 대시보드 조차 공개적으로 액세스할 수 없게 됩니다.

공유 대시보드는 약 60초마다 새로 고쳐지며, 이 [새로 고침 빈도][1]는 사용자 지정할 수 없습니다.

공유 대시보드의 조회자는 [작성자의 권한][4]에 따라 대시보드에 표시된 모든 텔레메트리 데이터를 볼 수 있습니다. 민감하거나 기밀인 데이터가 노출되지 않도록 공유하기 전에 대시보드 콘텐츠를 검토하세요.

## 공유 상태{#share-states}

공유 대시보드는 다음 두 가지 공유 상태 중 하나일 수 있습니다.

{{< ui >}}Active{{< /ui >}}
: 공유 대시보드에 특정 URL이 할당되며 대시보드에 액세스하도록 구성된 조회자가 사용할 수 있습니다.

{{< ui >}}Paused{{< /ui >}}
: 조회자가 초대받은 경우라도 공유 대시보드에 액세스할 수 없습니다. 그러나 공유 대시보드 URL은 대시보드에 계속 연결되어 있으며, 대시보드가 {{< ui >}}Active{{< /ui >}}로 재설정되면 이전 액세스 권한이 복원됩니다.

대시보드의 **공유를 해제**하면 공유 URL이 제거되고 모든 공유 구성 설정이 삭제되어 모든 링크가 유효하지 않게 됩니다. 대시보드를 다시 공유할 때 이전 공유 URL이나 설정은 유지되지 않습니다.

## 초대 전용 공유 대시보드 {#invite-only-shared-dashboards}

초대 전용 대시보드를 사용하면 개별 이메일 주소나 특정 이메일 도메인과 대시보드를 공유할 수 있습니다.

하나 이상의 이메일 주소에 대시보드를 공유하려면 다음 단계를 따르세요.

1. 공유하려는 대시보드 오른쪽 상단 모서리에 있는 {{< ui >}}Share{{< /ui >}} 옵션을 클릭합니다.
2. {{< ui >}}Share Dashboard{{< /ui >}}를 선택합니다.
3. {{< ui >}}Invite only{{< /ui >}}를 선택합니다.
4. 원하는 시간, 변수 및 색상 옵션을 구성합니다. 자세한 내용은 [구성 옵션](#configuration-options)을 참조하세요.
5. 액세스 권한을 부여할 이메일 또는 이메일 도메인을 추가하고 각 초대에 대한 만료일을 설정합니다. 도메인을 추가하여 공개 액세스를 방지하고 해당 도메인 주소를 가진 모든 사용자만 대시보드에 액세스하도록 제한합니다.
6. {{< ui >}}Share Dashboard{{< /ui >}}를 클릭하여 공유 URL을 생성하고 특정 초대 대상자에게 액세스 링크를 이메일로 보냅니다. 이메일은 특정 이메일 주소로만 전송됩니다. 이메일 도메인의 경우 이메일이 전송되지 않으므로 대시보드 링크를 수동으로 배포해야 합니다.

**참고**: 초대된 이메일은 만료일 오전 12:00(현지 시간)에 액세스 권한을 잃게 됩니다.

기본적으로 초대장은 만료되지 않습니다. 특정 시간이 지난 후 초대장이 만료되도록 하려면 조직 관리자가 [Organization Settings > Public Sharing][3]에서 최대 액세스 기간을 켤 수 있습니다. 이 설정이 활성화되면 초대장이 유효하게 유지되는 최대 일수를 지정할 수 있습니다.

만료일 없는 초대장을 허용하려면 최대 액세스 기간을 끄세요. API를 통해 이 설정을 구성하는 경우 값을 `null`로 설정하세요. UI에서 최대 액세스 기간을 `0`으로 설정하면 설정이 꺼지고 값이 `null`로 설정됩니다.

**참고**: 최대 액세스 기간은 정확한 타임스탬프를 기준으로 적용됩니다. 예를 들어, 최대 액세스 기간이 1일인 경우 1월 1일 오전 11시에 생성된 초대는 1월 2일 오전 11시까지 만료되어야 합니다.

### 초대 전용 공유 대시보드 액세스 {#access-an-invite-only-shared-dashboard}

공유 대시보드에 초대된 사람에게는 제한된 시간 동안만 유효한 액세스 링크가 포함된 이메일이 전송됩니다. 이메일 수신자가 공유 대시보드에 액세스하려면 1시간 이내에 링크를 클릭해야 합니다.

{{< img src="/dashboards/sharing/shared_dashboards/invite_only_dashboard_link.png" alt="비공개 대시보드 액세스 링크가 포함된 이메일 초대 예시." style="width:90%;" >}}

링크를 클릭한 후 초대받은 사람은 동일한 컴퓨터와 브라우저에서 30일 동안 공유 대시보드에 액세스할 수 있으며, 그 이후에는 액세스 권한을 갱신해야 합니다. 유효한 수신자 자격을 유지하고 대시보드가 활성 상태인 한 액세스 권한을 계속 갱신할 수 있습니다.

#### 새 액세스 링크 받기 {#get-a-new-access-link}

유효한 수신자는 공유자의 승인 없이 언제든지 새 액세스 링크를 요청할 수 있습니다. 활성 액세스 권한 없이 공유 대시보드를 방문하면 이메일 주소를 입력하여 새 액세스 링크를 받으라는 메시지가 표시됩니다. 유효한 수신자만 이 이메일을 받을 수 있습니다.

### 초대 전용 공유 대시보드에 대한 액세스 권한 취소 {#revoke-access-to-an-invite-only-shared-dashboard}

공유 대시보드에 대한 액세스 권한을 취소하려면 수신자 목록에서 원하는 이메일 주소를 제거하고 변경 사항을 저장하세요. 이렇게 제거된 수신자는 더 이상 액세스 권한이 없으며 새 액세스 링크를 요청할 수도 없습니다.

**참고**: 초대 전용 대시보드를 공유한 사용자는 유효한 수신자로 유지되며 제거할 수 없습니다.

## 공개 공유 대시보드 {#public-shared-dashboards}

공개 대시보드를 사용하면 사용자는 링크를 통해 인터넷상의 누구에게나 공유 대시보드를 공개할 수 있습니다.

공개 대시보드를 공유하려면 다음 단계를 따르세요.

1. 공유하려는 대시보드 오른쪽 상단 모서리에 있는 {{< ui >}}Share{{< /ui >}} 옵션을 클릭합니다.
2. {{< ui >}}Share Dashboard{{< /ui >}}를 선택합니다.
3. {{< ui >}}Select a Share Type{{< /ui >}} 단계에서 {{< ui >}}Public{{< /ui >}} 옵션을 선택하고 대시보드 링크가 있는 사람은 누구나 대시보드에 액세스할 수 있다는 점을 이해했음을 확인합니다.
4. {{< ui >}}Configure Dashboard{{< /ui >}} 단계에서 원하는 시간, 변수 및 색상 옵션을 구성합니다.
5. {{< ui >}}Share Dashboard{{< /ui >}}를 클릭하여 공유 URL을 생성합니다.

기본적으로 공개 대시보드는 1년 동안 액세스할 수 있으며, 그 이후에는 만료되어 {{< ui >}}Paused{{< /ui >}} 상태로 전환됩니다. {{< ui >}}Select a Share Type{{< /ui >}} 단계에서 만료일을 끄거나 조정할 수 있습니다.

## 임베드된 공유 대시보드 {#embedded-shared-dashboards}

iFrame을 사용하여 공유 대시보드를 웹사이트에 임베드할 수 있습니다. 임베드된 대시보드에는 기본형과 보안형의 두 가지 유형이 있습니다.

### 기본 임베드{#basic-embed}

기본 임베드 대시보드는 허용 목록에 있는 요청 참조자를 기반으로 액세스를 제한합니다. 이 기능은 Safari 웹 브라우저에서 지원되지 않습니다.

HTTP 요청의 참조자 헤더는 유효성 검사를 위해 허용 목록 항목과 대조됩니다. 대부분의 경우 브라우저 콘솔에 `window.location.origin`을 입력하면 예상되는 참조자가 표시됩니다. 단, 브라우저 헤더에 특별한 조작(예: 브라우저 개인정보 보호 설정)이 있는 경우 실제 네트워크 요청을 확인해야 합니다.

기본 임베드 대시보드를 공유하려면 다음 단계를 따르세요.

1. 대시보드 오른쪽 상단에서 {{< ui >}}Share{{< /ui >}}를 클릭합니다.
2. {{< ui >}}Share Dashboard{{< /ui >}}를 선택합니다.
3. {{< ui >}}Select a Share Type{{< /ui >}} 단계에서 {{< ui >}}Embed{{< /ui >}} 옵션을 선택합니다.
4. {{< ui >}}Configure Dashboard{{< /ui >}} 단계에서 원하는 시간, 변수 및 색상 옵션을 구성합니다.
5. 허용 목록에 추가할 참조자를 추가합니다.
6. {{< ui >}}Share Dashboard{{< /ui >}}를 클릭하여 공유 URL을 생성합니다.

### 보안 임베드{#secure-embed}

보안 임베드 대시보드는 참조자 허용 목록에 의존하는 대신 백엔드에서 생성된 토큰을 사용하여 각 페이지 로드를 인증합니다. 애플리케이션 서버가 자격 증명을 보유하고 세션당 고유한 iFrame URL을 생성하므로 자격 증명이 브라우저에 노출되지 않습니다. 보안 임베드는 Safari를 포함하여 타사 쿠키를 차단하는 브라우저에서 작동합니다.

설정 지침은 [보안 임베드 대시보드][6]를 참조하세요.

## 구성 옵션{#configuration-options}

{{< img src="/dashboards/sharing/shared_dashboards/configure_shared_dashboard.png" alt="대시보드를 공유하기 위한 구성 섹션입니다. 기본 시간 범위는 지난 1시간으로 설정되어 있고 조회자가 이 시간 범위를 변경할 수 있으며, 기본 테마는 라이트 테마로 지정되어 있습니다." style="width:90%;" >}}

{{< ui >}}Configure Dashboard{{< /ui >}} 단계에서 공유 대시보드를 변경하세요.

**참고**: 공유 대시보드에 대한 구성 변경 사항이 모든 조회자에게 적용되기까지 최대 5분이 소요될 수 있습니다. 변경 사항이 즉시 표시되지 않으면 몇 분 정도 기다린 후 대시보드를 새로 고침하세요.

{{< ui >}}Published Name{{< /ui >}}
: 게시된 이름은 공유 대시보드에서 대시보드 제목을 대체합니다. 이 이름은 공유 대시보드 목록 페이지에 공유 대시보드가 나열될 때 표시되는 이름이기도 합니다.

{{< ui >}}Default Timeframe{{< /ui >}}
: 공유 대시보드 조회자를 위한 기본 시간 범위를 설정합니다. "조회자가 시간 범위를 변경하도록 허용"이 꺼져 있으면 이 시간 범위만 사용할 수 있습니다. 이 옵션을 켜면 조회자에게 고정된 시간 범위 옵션 세트가 제공되지만, 사용자 지정 시간 범위 및 시간 범위 스크러빙은 지원되지 않습니다.

{{< ui >}}Variables{{< /ui >}}
: 이 설정을 통해 사용자는 대시보드에서 조회자가 사용할 수 있는 템플릿 변수를 지정할 수 있습니다. 템플릿 변수에 대해 동일한 기본값과 사용 가능한 값을 설정하면 조회자가 이를 변경할 수 없습니다. <br>**참고**: 이 설정은 값이 와일드카드(\*)로 설정된 경우에도 적용됩니다. <br><br>기본적으로 공유 대시보드는 공유자가 현재 사용 중인 선택된 값과 사용 가능한 값을 상속합니다.

{{< ui >}}Default Theme{{< /ui >}}
: 이 설정을 통해 사용자는 공유 대시보드를 기본적으로 라이트 모드나 다크 모드 중 무엇으로 표시할지 선택할 수 있습니다. 조회자는 언제든지 이 옵션을 재정의할 수 있습니다.

## 공유 대시보드에 대한 제한 사항 {#restrictions-on-shared-dashboards}

### 비활성화된 사용자는 대시보드를 공유할 수 없습니다 {#dashboards-cannot-be-shared-by-deactivated-users}

공유 대시보드는 조직 내 활성 사용자가 공유해야 합니다. 공유자가 비활성화되면 활성 사용자가 소유권을 주장할 때까지 공유 대시보드에 **데이터가 더 이상 표시되지 않습니다**. 이 상태에 있는 동안에도 공유 대시보드 URL 및 구성 옵션은 유지됩니다.

### 모든 위젯 유형을 사용할 수 있는 것은 아닙니다 {#not-all-widget-types-are-available}

공유 대시보드는 다음 표에 있는 위젯 유형을 지원합니다. 다른 유형의 위젯은 대시보드가 공유될 때 데이터를 표시하지 않습니다.

| 카테고리 | 지원되는 위젯 |
| -------- | ----------------- |
| 시계열 및 분포 | 시계열, 막대 차트, 분포, 히트맵, 산점도, Sankey |
| 단일 값 및 요약 | 쿼리 값, 변경 사항, 상위 목록, 경보 값, 경보 그래프, 서비스 요약 |
| 표 및 계층 구조 | 표, Treemap, 파이 차트, 퍼널, 유지율 |
| 지도 | Geomap, 호스트 맵 |
| 모니터링 및 SLO | 모니터링 요약, 검사 상태, SLO, SLO 목록 |
| 텍스트 및 미디어 | 메모 및 링크, 자유 텍스트, 이미지, iFrame |
| 기타 | 이벤트 타임라인, Wildcard |

지원되지 않는 위젯이 포함된 대시보드를 공유해도 오류가 발생하지 않으며, 대시보드 API는 이러한 위젯을 거부하지 않습니다. 위젯이 데이터 없이 공유 대시보드에 표시됩니다.

### 제한된 기간 옵션 {#limited-timeframe-options}

공유 대시보드는 제한된 수의 기간 옵션을 지원하며 기간 스크러빙이나 사용자 지정 기간을 허용하지 않습니다.

### IP 주소 제한 {#ip-address-restrictions}

IP 주소를 기반으로 공유 대시보드에 대한 액세스를 제한할 수 있습니다. IP 주소 허용 목록을 활성화하려면 [Datadog 지원팀][5]에 이메일을 보내주세요. 활성화되면 관리자는 [공개 공유 설정 페이지][3]에서 IP 제한을 관리할 수 있습니다.

## 공유 대시보드 편집 {#edit-shared-dashboards}

<div class="alert alert-danger">대시보드의 콘텐츠나 레이아웃에 대한 모든 변경 사항은 공유 버전에 즉시 반영됩니다. 개인 데이터가 의도치 않게 공유되지 않도록 편집 시 주의하세요.</div>

공유 대시보드의 공유 유형, 구성 또는 수신자를 변경하려면 다음 단계를 따르세요.

1. 대시보드 오른쪽 상단 모서리에 있는 {{< ui >}}Share{{< /ui >}} 옵션을 클릭합니다.
2. {{< ui >}}Edit shared dashboard{{< /ui >}}를 선택합니다.
3. 원하는 설정을 조정합니다.
4. 변경 사항을 적용하려면 {{< ui >}}Save{{< /ui >}}를 클릭합니다.

이 메뉴에서 공유 대시보드에 대한 액세스를 일시적으로 중지하거나 다시 활성화할 수 있습니다.

## 모든 공유 대시보드 보기 {#view-all-shared-dashboards}

[공유 대시보드][2] 페이지에서 조직의 모든 공유 대시보드와 설정을 확인하세요. 이 페이지에서 공유 유형, 마지막 액세스, 공유자 등을 기준으로 대시보드를 쿼리, 필터링 및 정렬할 수 있습니다. 소유자가 없는 공유 대시보드를 찾고 소유권을 주장할 수도 있습니다.
