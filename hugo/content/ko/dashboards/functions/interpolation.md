## 채우기 {#fill}

| 함수 | 설명                                       | 예시                                    |
| :----    | :-------                                          | :---------                                 |
| `fill()` | 해당 메트릭에 누락된 메트릭 값을 보간합니다. | `<METRIC_NAME>{*}.fill(<METHOD>, <LIMIT>)` |

`fill()` 함수에는 다음 두 개의 파라미터가 있습니다.

* **`METHOD`**: 보간 방법으로 사용할 함수이며, 다음 중에서 선택합니다.
    * `linear`: 빈 구간의 시작과 끝 사이를 선형 보간합니다.
    * `last`: 빈 구간의 마지막 값으로 빈 구간을 채웁니다.
    * `zero`: 빈 구간을 0으로 채웁니다.
    * `null`: 보간을 비활성화합니다.

* `LIMIT` [*선택*, *기본*=**300**, *최대*=**600**]: 보간하려는 격차의 최대 크기를 나타내는 보간 한도(초)입니다.

`.fill()` 함수와 보간에 미치는 영향에 대한 자세한 설명은 [보간 및 Fill 수정자 관련 안내][1]를 참조하세요.

## 기본값 0 {#default-zero}

| 함수         | 설명                             | 예시                          |
| ---------------- | --------------------------------------- | -------------------------------- |
| `default_zero()` | 희소 메트릭에 기본값을 추가합니다. | `default_zero(system.load.1{*})` |

`default_zero()` 함수는 빈 시간 간격을 0 값으로 채웁니다. 보간이 활성화된 경우에는 보간을 사용하여 채웁니다. **참고**: `GAUGE` 유형 메트릭의 경우에는 보간이 기본적으로 활성화되어 있습니다. 대부분의 함수와 마찬가지로 `default_zero()` 함수는 [시간 및 공간 집계][2] **후에** 적용됩니다.

### 사용 사례 {#use-cases}

`default_zero()` 함수는 다음 사용 사례를 해결하기 위해 고안되었습니다(다른 사용 사례에서도 작동 가능).

- 희소 메트릭에 산술 연산을 수행할 때 게이지를 0으로 정렬합니다(참고: `as_count()` 또는 `as_rate()`로 쿼리한 `COUNT` 또는 `RATE` 유형 메트릭은 _항상_ 0으로 정렬되므로 `default_zero()`를 사용해도 정렬 방식은 바뀌지 않으며, `GAUGE` 유형 메트릭만 영향을 받습니다).
- 모니터가 데이터 없음 상태가 되기 전에 모니터 경보를 해제합니다. 이는 단순 경보와 다중 경보 모두에 적용되지만, 0 값으로 인해 모니터가 트리거되어서는 안 됩니다. 예를 들어, `avg(last_10m):avg:system.cpu.idle{*} < 10` 쿼리를 사용하는 모니터에는 이 방법이 효과가 없습니다. 이 모니터는 0으로 평가되면 경보가 해제되는 것이 아니라 트리거되기 때문입니다. `as_count()` 쿼리를 사용하는 오류율 모니터에는 이 함수를 사용하지 마세요. 자세한 내용은 [모니터링 평가 가이드의 as_count()][3]를 참조하세요.
- 시각적인 이유로, 또는 모니터 평가에서 시계열의 최소/최대/평균에 영향을 주기 위해 데이터가 희소 시계열의 빈 간격을 채웁니다.
- 데이터가 없을 때 시계열 위젯에 0 값을 표시합니다.

### 예시 {#example}

`default_zero()` 함수의 작동 방식을 알아보려면 [DogStatsD를 사용하여][4] 사용자 지정 메트릭에 생성한 다음 단일 포인트를 살펴보세요.

```text
$ echo -n "custom_metric:1|g" | nc -4u -w0 127.0.0.1 8125
```

이 메트릭이 지난 30분 동안 쿼리된 경우, 쿼리의 롤업 간격 중 하나에만 포인트가 존재하므로 단일 타임스탬프만 나타납니다.

```text
avg:custom_metric{*}

+---------------------+---------------+
| Timestamp           | custom_metric |
+---------------------+---------------+
| ---------           | ---------     |
| 2019-04-17 17:45:00 | 1             |
+---------------------+---------------+
```

`default_zero()` 함수는 이 포인트를 5분 앞으로(게이지의 기본 보간 한도) 보간한 다음 나머지 빈 간격을 0으로 채웁니다.

```text
default_zero(avg:custom_metric{*})

+---------------------+-----------------------------+
| Timestamp           | default_zero(custom_metric) |
+---------------------+-----------------------------+
| ---------           | ---------                   |
| 2019-04-17 17:30:00 | 0                           |
| 2019-04-17 17:31:00 | 0                           |
...
| 2019-04-17 17:44:00 | 0                           |
| 2019-04-17 17:45:00 | 1                           |
| 2019-04-17 17:46:00 | 1                           |
| 2019-04-17 17:47:00 | 1                           |
| 2019-04-17 17:48:00 | 1                           |
| 2019-04-17 17:49:00 | 1                           |
| 2019-04-17 17:50:00 | 1                           |
| 2019-04-17 17:51:00 | 0                           |
| 2019-04-17 17:52:00 | 0                           |
...
+---------------------+-----------------------------+
```
