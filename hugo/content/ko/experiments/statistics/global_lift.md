## 개요 {#overview}

실험에는 일반적으로 일부 사용자만 등록됩니다. 글로벌 리프트는 '이 변경 사항을 모든 대상 사용자에게 출시한다면 전체 메트릭 합계가 어떻게 변할까?'라는 질문에 답합니다.

예를 들어, 실험에서 사용자당 수익이 10% 증가했지만 실험 대상 모집단이 전체 수익의 20%만 차지한다면, 글로벌 수익에 미치는 예상 영향은 약 2%입니다. 이는 변경 사항을 출시할지 결정할 때 유용합니다. 실험 내에서는 인상적으로 보이는 처리군이라도 제한된 사용자에게만 적용될 경우 비즈니스 수준의 합계에는 미치는 영향이 더 작을 수 있습니다.

Datadog은 전체 메트릭 값 중 대상 모집단에서 발생하는 비중을 수치화한 _적용 범위_와 함께 글로벌 리프트를 보고합니다. 글로벌 리프트는 적용 범위와 실험에서 관찰된 로컬 리프트의 곱입니다.

## 사용자 모집단 {#user-populations}

모든 실험은 사용자 기반을 세 그룹으로 나눕니다.

| 모집단 | 설명 |
|---|---|
| **비대상** | 처음부터 대상이 아니었던 사용자(잘못된 페이지, 타겟팅 기준 미충족 또는 기타 자격 조건 미충족). 이들의 행동은 롤아웃 결정의 영향을 받지 않습니다. |
| **대상, 미등록** | 자격 기준은 충족했으나 트래픽 노출 설정으로 인해 제외된 사용자. |
| **등록됨** | 처리군 또는 대조군 변형에 할당된 사용자. |

글로벌 리프트는 대상 모집단(등록된 사용자 및 대상이지만 등록되지 않은 사용자)에 초점을 맞추며, 해당 모집단이 완전히 대조군에서 처리군으로 전환될 경우의 메트릭 영향을 추정합니다. 처리군이 완전히 출시된다면, 대상 모집단은 해당 처리군과 상호작용할 모든 사용자를 포함하게 됩니다.

## 적용 범위 {#coverage}

적용 범위(Coverage)는 대조군 경험이 모든 대상 사용자에게 배포될 경우, 대상 모집단에서 발생할 것으로 추정되는 전체 글로벌 메트릭 합계의 비율입니다. 공식은 다음과 같습니다.

```
Coverage = FER_C / TM_C
```

| 기호 | 정의 |
|---|---|
| `FER_C` | 대조군 전용 배포 시 전체 대상 모집단에 대한 예상 메트릭 합계 |
| `TM_C` | 대조군 전용 배포 시 예상 글로벌 메트릭 합계 |

이 값들은 관찰된 실험 데이터에서 추정됩니다.

```
FER_C = X_C / (p_C × t_exp)

TM_C  = TM − TEM + (X_C / p_C)
```

| 기호 | 정의 |
|---|---|
| `X_C` | 대조군 변형에서 관찰된 메트릭 합계 |
| `X_T` | 처리군 변형에서 관찰된 메트릭 합계 |
| `TEM` | 관찰된 실험 메트릭 합계: `X_T + X_C` |
| `TM` | 모든 사용자(등록 및 미등록)의 관찰된 메트릭 합계 |
| `t_exp` | 실험에 등록된 대상 사용자 비율 |
| `p_C` | 대조군 변형에 할당된 등록 사용자 비율 |

**`FER_C`에 대한 직관적 설명:** 대조군 변형은 대상 모집단의 대표 표본입니다. 대조군에 포함된 대상 사용자의 비율은 `p_C × t_exp`이므로, `X_C`을(를) 해당 비율로 나누면 대조군의 메트릭 합계를 전체 대상 모집단에 해당하는 값으로 환산할 수 있습니다.

**`TM_C`에 대한 직관적 설명:** 관찰된 글로벌 메트릭 합계(`TM`)에서 시작하여, 등록된 사용자의 관찰된 기여도(`TEM`)를 제거하고, 해당 사용자가 모두 대조군이었다면 생성했을 것으로 예상되는 값(`X_C / p_C`)으로 대체합니다. 비대상 사용자의 기여도는 변경되지 않습니다.

## 글로벌 리프트 {#global-lift}

글로벌 리프트는 적용 범위와 실험의 로컬 리프트를 곱한 값입니다.

```
Global lift = Coverage × Local lift
```

로컬 리프트는 실험 내에서 측정된 대상별 상대 리프트입니다.

```
                (Average metric value per treatment subject) − (Average metric value per control subject)
Local lift =  ──────────────────────────────────────────────────────────────────────────────────────────
                                  (Average metric value per control subject)
```

### 예시 {#example}

다음과 같은 관찰값을 가진 실험을 살펴보겠습니다.

- 50/50 트래픽 분할 (p_C = 0.5)
- 모든 대상 사용자가 등록됨(t_exp = 1.0)
- 대조군 수익: $100(`X_C`)
- 처리군 수익: $110(`X_T`)
- 모든 사용자의 총 수익: $1,010(`TM`)

글로벌 리프트 계산은 다음과 같이 진행됩니다.

| 단계 | 계산 | 값 |
|---|---|---|
| `TEM` | $100 + $110 | $210 |
| `FER_C` | $100 / (0.5 × 1.0) | $200 |
| `TM_C` | $1,010 − $210 + ($100 / 0.5) | $1,000 |
| 적용 범위 | $200 / $1,000 | 20% |
| 로컬 리프트 | ($110 − $100) / $100 | 10% |
| **글로벌 리프트** | 20% × 10% | **2%** |

다시 말해, 이 처리군을 모든 대상 사용자에게 배포하면 총 수익이 $1,000(대조군만 적용했을 경우의 반사실적 값)에서 $1,020로 2% 증가합니다.

## 지원되는 메트릭 {#supported-metrics}

글로벌 리프트는 `count` 및 `sum` 집계 유형에 대해 계산됩니다.

**참고**: 닫힌(윈도우형) 메트릭(할당을 기준으로 한 시간 윈도우로 팩트 값을 제한하는 메트릭)은 글로벌 리프트에서 지원되지 않습니다.
