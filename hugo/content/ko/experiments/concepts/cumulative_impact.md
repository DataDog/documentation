## 개요 {#overview}

실험을 실행하는 팀은 시간이 지남에 따라 메트릭을 누적적으로 얼마나 변화시켰는지 파악해야 합니다. 성공한 실험에서 관찰된 리프트를 합산하는 것이 이를 수행하는 자연스러운 방법처럼 보일 수 있지만, 이는 체계적으로 실제 영향을 과대평가합니다. 부풀려진 추정치는 실험에 대한 신뢰를 떨어뜨리고 진행 상황을 정직하게 평가하기 어렵게 만듭니다.

누적 영향은 팀이 단일 메트릭에 대해 실행한 모든 실험의 효과를 집계하고 총 변동에 대한 노이즈 조정 추정치를 생성하는 메트릭 수준의 뷰입니다. 기존 메트릭 추세와 함께 메트릭 개요 페이지에서 확인할 수 있으며, 누적 영향 차트와 효과 분포라는 2가지 새로운 구성 요소를 포함합니다.

## 누적 영향 활용 {#using-cumulative-impact}

### 단순 집계가 영향을 과대평가하는 이유 {#why-naive-aggregation-overstates-impact}

실험 결과를 집계할 때 발생하는 어려움 중 하나는 *승자의 저주*입니다. 이는 통계적으로 유의미한 결과가 실제 효과를 과대평가하는 체계적인 경향을 의미합니다. 측정된 리프트가 큰 실험일수록 유의성에 도달하여 배포될 가능성이 높기 때문에, '성공한' 실험 목록은 실제보다 높게 측정된 결과로 편향됩니다. 이러한 측정값을 합산하면 편향이 가중됩니다.

과거에는 승자의 저주를 보정하기 위해 데이터 팀이 맞춤형 통계 모델을 구축하거나 경험 법칙에 의존해야 했습니다. Datadog Experiments는 메트릭에 대한 팀의 모든 실험 전반에 걸쳐 통계 모델을 적용하고 누적 영향에 대한 보정된 추정치를 생성하여 이 보정을 자동으로 수행합니다.

### 누적 영향 차트 읽기 {#reading-the-cumulative-impact-chart}

누적 영향 차트는 선택한 기간 동안 메트릭이 어떻게 변동했는지 보여줍니다. **시간 프레임** 선택기를 평가하려는 기간(예: 지난 분기)으로 설정하면 해당 기간 동안 완료된 실험이 차트에 채워집니다.

차트는 2가지 수치를 중점적으로 보여줍니다.

1. 해당 기간 동안 실행된 실험 수와 그중 처리 변형을 배포한 실험 수.
2. 상대적 또는 절대적 개선으로 표현된 메트릭에 대한 누적 영향.

{{< img src="/product_analytics/experiment/cumulative_impact/cumulative_impact_overview.png" alt="누적 영향 섹션을 보여주는 메트릭 개요 페이지입니다. 지난 6개월로 설정된 시간 프레임 선택기, 성공한 실험 수와 함께 표시된 +5.58%의 누적 영향 값, 시간에 따라 그려진 누적 영향 차트가 포함되어 있습니다." style="width:90%;" >}}

**Including X winning experiments**를 클릭하면 누적 영향 계산에 사용된 실험을 확인할 수 있습니다. 목록에서 실험을 선택하면 결과 페이지가 열리며, 여기서 원래 측정된 리프트, 배포 결정, 누적 계산에 사용된 보정된 추정치를 확인할 수 있습니다. 이를 통해 개별 기여도를 소스까지 추적할 수 있으며, 이는 경영진에게 영향력을 보고하거나 프로그램 수준의 주장을 감사할 때 유용합니다.

### 효과 분포 읽기{#reading-the-effect-distribution}

누적 영향 차트 오른쪽에는 효과 분포가 있습니다. 이는 메트릭에 대한 팀의 실제 효과를 시각화한 것입니다. 분포의 중심은 팀이 평균적인 실험에서 만들어내는 효과의 크기를 나타내며, 확산 정도는 그러한 효과가 얼마나 가변적인지를 나타냅니다.

{{< img src="/product_analytics/experiment/cumulative_impact/effect_distribution.png" alt="실험 효과 분포 패널은 10개의 완료된 실험에서 평균 효과 크기가 +0.55%, 표준 편차가 0.15%임을 보여주며, -1%와 +1% 사이의 0 위에 중심을 둔 종 모양 곡선을 나타냅니다." style="width:80%;" >}}

분포는 노이즈가 조정되어 있습니다. 노이즈가 많은 결과가 데이터가 뒷받침하는 범위 이상으로 분포를 더 넓게 늘리지 않습니다.

효과 분포는 다음 2가지 결정을 내리는 데 도움이 됩니다.

- **투자할 영역.** 특정 메트릭에서 분포가 0보다 훨씬 높게 나타나는 팀은 신뢰할 수 있는 리프트를 보여주고 있으므로 이 분야에 계속 투자하는 것이 좋습니다. 분포가 0에 걸쳐 있는 팀은 노력을 다른 곳으로 돌리는 것이 좋습니다.
- **향후 실험 규모 설정.** 팀이 일반적으로 5% [최소 탐지 가능한 효과][1]에 대해 실험 성능을 설정하지만, 분포상 실제 효과가 보통 플러스 마이너스 3% 이내라면 해당 실험은 검정력이 부족할 가능성이 높습니다. 표본 크기를 늘리거나, 타겟팅을 넓히거나, 더 높은 기대 영향력을 가진 기회에 집중하는 것을 고려하세요.

### 포함된 실험{#which-experiments-are-included}

누적 영향은 선택한 기간 내에 해당 메트릭을 타겟팅하고 결과를 생성한 모든 실험을 고려합니다. 각 실험이 어떻게 기여하는지는 몇 가지 규칙에 따라 결정됩니다.

- **모델 적합도:** 진단 결과가 실패하지 않은 모든 실험은 통계 모델 적합에 기여합니다.
- **집계:** 비대조군 변형을 배포한 실험만 누적 합계에 포함됩니다. 대조군 변형을 배포했거나 배포 결정 없이 종료된 실험은 합산되지 않습니다.
- **진단:** 진단에 실패한 실험은 적합 과정에서 완전히 제외됩니다. 진단이 없거나 진단 결과가 통과 또는 경고인 실험은 포함됩니다.

### 로컬 뷰 및 글로벌 뷰 {#local-and-global-views}

일부 메트릭의 경우 누적 영향에 대한 *로컬 뷰*와 *글로벌 뷰* 간을 전환할 수 있습니다.

로컬 뷰는 '각 실험에 노출된 사용자들의 경우 이 메트릭이 얼마나 변했는가?'라는 질문에 답합니다. 노출 규모에 의해 희석되지 않으므로 팀 간 또는 영역 간의 효과 크기를 비교할 때 적합한 뷰입니다.

글로벌 뷰는 '전체 사용자 기반의 경우 이 메트릭이 얼마나 변했는가?'라는 질문에 답합니다. 각 실험의 보정된 추정치에 해당 실험에 노출된 사용자 비율을 가중치로 적용하여 프로그램 수준의 총 변동 추정치를 산출합니다. 조직 전체의 영향력을 전달할 때는 글로벌 뷰가 적합합니다. 소규모 사용자층에서 나타난 큰 폭의 리프트는 대규모 사용자층에서 나타난 작은 폭의 리프트와 비교하여 상대적으로 낮게 평가되기 때문입니다.

두 뷰 모두 동일한 보정 추정치를 사용하며, 이러한 추정치를 결합하는 방식에서만 차이가 있습니다.

### 시간 프레임 선택 {#choosing-a-time-frame}

시간 프레임 선택기는 포함할 실험을 결정합니다. 기간이 길수록 더 많은 실험이 포함되어 모델 적합도가 향상되고 효과 분포가 더 매끄러워지지만, 팀의 방향이 변경된 경우 서로 다른 팀 전략이 혼재될 수 있습니다.

팀의 실험 전략이 대체로 일관되게 유지된 기간(보통 분기 또는 반기)을 시작점으로 잡는 것이 합리적입니다. 기간을 비교하는 것도 유용합니다. 시간이 지남에 따라 효과 분포가 상향 이동한 팀은 단순히 더 많은 배포 결정을 내린 것뿐만 아니라 더 큰 실제 효과를 만들어내고 있는 것입니다.

## 통계 세부 정보 {#statistical-details}

이 섹션에서는 보정된 추정치와 효과 분포를 산출하는 모델에 대해 설명합니다. 결과를 이해, 감사 또는 재현하려는 데이터 과학자 및 통계학자를 위한 내용입니다.

### 계층적 모델 {#the-hierarchical-model}

Datadog은 경험적 베이즈 메타 분석의 표준 정형인 계층적 정규-정규 모델을 사용합니다. θ_i를 대상 메트릭에 대한 실험 i의 잠재적 실제 효과라고 하고, y_i를 알려진 표준 오차 σ_i를 사용하여 해당 실험에서 추정된 리프트라고 합니다. 모델은 다음과 같습니다.

```
y_i | θ_i  ~ Normal(θ_i, σ_i²)     (sampling distribution)
θ_i        ~ Normal(μ, τ²)         (population distribution of true effects)
```

첫 번째 줄은 각 실험이 실험의 표준 오차에 의해 결정되는 노이즈 수준으로 자체 실제 효과에 대한 노이즈가 있는 측정을 제공함을 나타냅니다. 두 번째 줄은 팀의 실제 효과 자체가 평균 μ와 분산 τ²를 가진 공유 분포에서 도출됨을 나타냅니다. 이 공유 분포가 UI에 *effect distribution*으로 표시되는 것입니다.

잠재적 θ_i에 대해 주변화하면 관측된 리프트에 대한 주변 가능도는 다음과 같습니다.

```
y_i ~ Normal(μ, τ² + σ_i²)
```

최적화 도구는 이것을 적합시킵니다.

### 사전 분포 {#priors}

Datadog은 모집단 파라미터에 대해 약한 정보 사전 분포를 사용합니다. 재스케일링된 데이터(아래 참조)에 대한 기본값은 다음과 같습니다.

```
μ ~ Normal(0, 1)
τ ~ HalfCauchy(0, 0.25)
```

μ에 대한 정규 사전 분포는 재스케일링 후 대부분의 메트릭 스케일에서 정보를 제공하지 않을 만큼 충분히 넓습니다. τ에 대한 하프 코시(half-Cauchy) 사전 분포는 계층적 스케일 파라미터에 대한 일반적인 선택입니다. 이는 0 이상의 실수 범위에서 정의되며 확률질량이 0 근처에 집중되어 있으므로, 데이터가 불명확할 때 모델은 동질성이 높은 경우를 선호합니다. 반면 꼬리가 두꺼워, 데이터가 뒷받침하는 경우에는 큰 이질성도 허용합니다.

### 수치적 안정성을 위한 재스케일링 {#rescaling-for-numerical-stability}

적합 전에 관측된 리프트와 표준 오차는 평균 0, 분산 1로 재스케일링됩니다. ȳ를 리프트의 표본 평균이라 하고 s_y를 표본 표준 편차라고 합니다. 최적화 도구는 재스케일링된 수량에 대해 작동합니다.

```
ỹ_i = (y_i − ȳ) / s_y
σ̃_i = σ_i      / s_y
```

이는 자연적 스케일이 여러 자릿수만큼 차이 나는 메트릭 전반에 걸쳐 단일 사전 하이퍼파라미터 세트가 작동함을 의미합니다. 적합 후, μ와 τ의 추정치는 원래 스케일로 다시 변환됩니다.

```
μ̂ = μ̃ · s_y + ȳ
τ̂ = τ̃ · s_y
```

### 모델 적합 {#fitting-the-model}

모델 파라미터(μ, τ)는 최대 사후 확률 추정(MAP)으로 추정됩니다. 최적화 중에 τ를 양수로 유지하기 위해 모델을 τ = exp(η)로 재파라미터화하고 최적화 도구는 (μ, η)에 대해 탐색합니다.

목적 함수는 관측된 리프트가 주어졌을 때 (μ, η)의 음의 로그 사후 확률입니다.

```
−log p(μ, η | data) = −[Σ_i log Normal(y_i | μ, τ² + σ_i²)]
                     − log Normal(μ | μ_prior_mean, μ_prior_sd²)
                     − log HalfCauchy(τ | τ_prior_scale)
                     − η                          (Jacobian of τ = exp(η))
```

최적화는 기울기를 사용하지 않는 심플렉스 방법인 넬더-미드(Nelder-Mead)법을 사용합니다. 이는 2차원 문제에서 강력한 선택이며 τ = 0 근처에서 발생하는 유한 차분 기울기와 관련된 문제를 방지합니다.

### 보정된 추정치(사후 평균) {#corrected-estimates-posterior-means}

(μ̂, τ̂)가 적합된 후, 각 실험은 적합된 사전 분포 하에서 실제 효과의 사후 평균과 동일한 보정된 추정치를 받습니다. 정규-정규 켤레 업데이트는 관측된 리프트와 모집단 평균의 정밀도 가중 평균입니다.

```
θ̂_i = (y_i / σ_i² + μ̂ / τ̂²) / (1 / σ_i² + 1 / τ̂²)
```

동일하게, θ̂_i = (1 − w_i) · μ̂ + w_i · y_i이며, 여기서 w_i = τ̂² / (τ̂² + σ_i²)는 관측된 리프트에 부여된 가중치입니다. 구간이 좁은(작은 σ_i) 실험은 관측된 리프트의 대부분을 유지하지만, 구간이 넓은 실험은 모집단 평균 μ̂ 쪽으로 당겨집니다. 이것이 승자의 저주를 보정하는 축소 단계입니다.

### 누적 영향으로 집계 {#aggregating-to-cumulative-impact}

축소된 추정치는 메트릭이 자연적으로 가산적인지 또는 승법적인지에 따라 다르게 결합됩니다.

상대적 리프트 메트릭의 경우, 누적 영향은 승법적으로 계산됩니다.

```
Cumulative relative impact = ∏ (1 + θ̂_i) − 1
```

절대 차이 메트릭의 경우, 누적 영향은 축소된 추정치의 합입니다.

```
Cumulative absolute impact = Σ θ̂_i
```

비대조군 변형을 배포한 실험만 합계 또는 곱에 포함됩니다. UI의 차트는 실험 종료일 순으로 정렬된 이 합계 또는 곱의 누적 버전을 플롯하므로 시간이 지남에 따라 영향이 어떻게 누적되었는지 확인할 수 있습니다.

### 커버리지 가중치(글로벌 뷰) {#coverage-weighting-global-view}

글로벌 뷰는 동일한 축소 추정치를 사용하지만, 각 실험의 *커버리지*(실험에 노출된 적격 사용자 기반의 비율)를 기준으로 가중치를 부여합니다. 실험 i의 커버리지를 c_i라고 하면 다음과 같습니다.

```
Global relative impact = ∏ (1 + c_i · θ̂_i) − 1
Global absolute impact = Σ c_i · θ̂_i
```

커버리지 가중치는 노출된 사용자별 추정치를 프로그램 수준의 추정치로 변환하는 역할을 합니다. 기록된 커버리지 값이 없는 실험은 글로벌 뷰에서 제외되지만, 로컬 뷰 및 모델 적합에는 계속 기여합니다.

### 진단 적격성 {#diagnostic-eligibility}

모델을 적합하기 전에 각 실험에 대해 진단 검사를 수행합니다. 진단은 심각한 할당 불균형, 변형 간의 혼합 할당, 누락된 메트릭 데이터 등 실험 품질과 관련된 문제에 플래그를 지정합니다. 실험의 종합 진단 상태가 FAIL이 아닌 경우 해당 실험은 *적격*으로 간주됩니다. 진단 행이 없는 실험은 적격으로 처리됩니다.

실패한 실험은 모델 적합 및 누적 집계에서 완전히 제외됩니다. 이러한 실험은 모집단 평균으로 수렴되지 않고 합산되지 않으며 제외됩니다. 이는 신뢰할 수 없는 측정값이 누적 합계나 효과 분포를 오염시키는 것을 방지합니다.

### 최소 표본 크기 {#minimum-sample-size}

모델에는 최소 5개의 적격 실험이 필요합니다. 실험 수가 이보다 적으면 τ의 MAP 추정치가 불안정해지고 결과적인 축소를 신뢰할 수 없게 됩니다. 이 임계값을 충족하지 못하면 누적 영향 값이나 효과 분포가 표시되지 않습니다.

## 문제 해결 {#troubleshooting}

### 차트가 표시되지 않음 {#charts-not-showing}

누적 영향을 계산하려면 모델을 적합하기 위해 진단 결과가 실패가 아닌 실험이 최소 5개 필요합니다. 적격 실험이 5개 미만인 경우, Datadog은 누적 영향 값을 표시하지 않습니다. 이를 해결하려면 시간 프레임을 연장하거나 해당 메트릭에 대해 더 많은 실험을 실행하세요.
