## 개요 {#overview}

Datadog Real User Monitoring(RUM)을 사용하면 애플리케이션을 사용하는 개개인의 실시간 성능 및 사용자 여정을 시각화하고 분석할 수 있습니다.

## Roku 애플리케이션 모니터링을 시작하십시오.{#start-monitoring-roku-applications}

Roku용 RUM을 시작하려면 애플리케이션을 생성하고 Roku SDK를 구성하십시오.

{{< whatsnext desc="이 섹션에는 다음 주제가 포함되어 있습니다.">}}
  {{< nextlink href="/real_user_monitoring/application_monitoring/roku/setup">}}<u>설정</u>: Roku SDK 설정 방법, 백그라운드 이벤트 추적, 그리고 기기가 오프라인일 때 데이터를 전송하는 방법을 알아봅니다.{{< /nextlink >}}
  {{< nextlink href="/real_user_monitoring/application_monitoring/roku/error_tracking">}}<u>크래시 리포팅</u>: 크래시 리포팅을 추가하고, 난독화가 해제된 스택 추적을 가져온 후, 구현을 테스트하십시오.{{< /nextlink >}}
  {{< nextlink href="/real_user_monitoring/application_monitoring/roku/advanced_configuration">}}<u>고급 구성</u>: 사용자 세션 보강, 이벤트 및 데이터 관리, 사용자 지정 전역 속성 추적, 초기화 매개변수 검토, RUM 이벤트 수정 또는 삭제 등을 수행합니다.{{< /nextlink >}}
  {{< nextlink href="/real_user_monitoring/application_monitoring/roku/web_view_tracking">}}<u>웹 뷰 추적</u>: 웹 뷰를 모니터링하고 모바일 애플리케이션의 사각지대를 제거합니다.{{< /nextlink >}}
