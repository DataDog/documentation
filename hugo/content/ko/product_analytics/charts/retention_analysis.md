유지율 차트는 사용자가 페이지나 액션으로 얼마나 자주 돌아오는지 시각화하여 제품 및 기능의 지속적인 가치를 평가하는 데 도움을 줍니다.

{{< img src="/product_analytics/retention/retention_chart.png" alt="Retention Analysis 차트 예시" style="width:90%;" >}}

사용자 유지율은 *코호트*를 기준으로 측정합니다. 코호트란 특정 링크 클릭과 같이 정의된 시작 이벤트를 수행한 사용자 그룹입니다. 코호트 내 사용자가 동일한 링크를 다시 클릭하거나 결제로 진행하는 등 지정된 복귀 이벤트를 이후에 완료하면 *유지된* 것으로 간주합니다.

보기와 액션만 이벤트로 사용할 수 있습니다.

## 전제 조건 {#prerequisites}

유지율 데이터를 수집하려면 SDK에서 `usr.id` 속성을 설정합니다. [고유 사용자 속성 전송 지침][1]을 참조하세요.

## 유지율 이벤트 계산 {#calculating-retention-events}

유지율은 코호트 크기를 고려하여 코호트 전체의 행동을 요약하는 가중 평균으로 계산됩니다. 코호트가 클수록 최종 값에 더 많은 영향을 미치므로 단순 평균보다 전체를 더 잘 대표하는 결과를 얻을 수 있습니다. Datadog은 모든 시각화 유형에 이 계산을 적용합니다. 예를 들어, 유지율 그리드에서 각 시간 간격의 요약 셀에는 가중 평균이 표시됩니다.

유지율 그리드의 1주 차와 같이 특정 기간의 값을 계산하려면 각 코호트의 값에 코호트 크기를 곱합니다. 결과를 합산한 다음 전체 코호트 크기로 나눕니다.

```
Weighted Average = (Σ (cohort_value × cohort_size)) / (Σ cohort_size)
```

예를 들어, 1주 후 91%의 가중 평균 유지율은 다음과 같이 계산됩니다.

```
(99 * 1.8k + 92 * 2.35k + 81 * 1.75k) / (1.8k + 2.35k + 1.75k)
```

각 코호트의 유지율은 사용자 수에 따라 가중치가 적용된 후 전체 메트릭에 반영됩니다.

{{< img src="/product_analytics/retention/pana_retention_weighed_avg.png" alt="가중 평균 유지율을 보여주는 Retention Analysis 그래프 예시" style="width:90%;" >}}

<div class="alert alert-info">데이터가 일부만 제공되거나 불완전한 경우 유지율 차트에 비활성화된 값이 표시됩니다. 이는 해당 기간이 아직 진행 중이어서 유지율을 완전히 계산할 수 없는 경우에 발생합니다.</div>

## 유지율 차트 생성 {#create-a-retention-chart}

1. {{< ui >}}Product Analytics{{< /ui >}}에서 {{< ui >}}Create New{{< /ui >}} > {{< ui >}}Retention{{< /ui >}}을 선택합니다.

1. 유지율을 분석할 시작 단계와 복귀 단계를 정의합니다.

1. (필요시) {{< ui >}}Filter by{{< /ui >}} 또는 {{< ui >}}Compare by{{< /ui >}}를 사용하여 국가 또는 장치 유형과 같은 속성을 기반으로 차트 결과를 필터링하거나 그룹화합니다.

## 유지율 차트 분석 {#analyze-a-retention-chart}

유지율 차트를 생성하면 각 코호트의 유지율이 지정한 복귀 기간별로 분류되어 백분율 또는 사용자 수로 표시됩니다.

{{< img src="/product_analytics/retention/retention_analysis.png" alt="Advanced options의 복귀 설정, 보기 및 그룹화 컨트롤, 차트 유형 선택기, 시간 범위 선택기, 코호트 셀 툴팁을 번호로 표시한 Retention 차트" style="width:90%;" >}}

1. {{< ui >}}Advanced options{{< /ui >}}를 사용하여 유지율 계산에 포함할 복귀 이벤트의 범위를 지정합니다.

   - {{< ui >}}Returned on{{< /ui >}}: 특정 복귀 기간에 복귀 이벤트를 트리거한 사용자 비율을 계산합니다. 시작 이벤트 이후 일정 기간(예: 며칠 또는 몇 주)이 지난 뒤 사용자가 복귀 이벤트를 완료할 가능성을 확인할 수 있으며, 제품과 기능 전반의 유지율을 평가하는 데 유용합니다.
   - {{< ui >}}Returned on or after{{< /ui >}}: 특정 복귀 기간 또는 그 이후의 어느 기간에든 복귀 이벤트를 트리거한 사용자 비율을 계산합니다. 이 기능을 사용하면 제품 사용을 완전히 중단하거나 주요 기능을 더 이상 사용하지 않는 사용자를 파악할 수 있으며, 온보딩 경험의 효과를 평가하는 데 유용합니다.

2. {{< ui >}}Viewing{{< /ui >}} 행을 사용하여 표시할 항목을 제어합니다.

   - {{< ui >}}All Cohorts{{< /ui >}}, {{< ui >}}Weighted Average{{< /ui >}} 또는 특정 코호트: 차트에 표시할 코호트를 선택합니다. 가중 평균 계산 방법에 대한 자세한 내용은 [유지율 이벤트 계산](#calculating-retention-events)을 참조하세요.
   - {{< ui >}}Unique users{{< /ui >}} 또는 {{< ui >}}Unique accounts{{< /ui >}}: 사용자가 쿠키를 삭제하거나 장치를 변경하면 재설정될 수 있는 `@usr.id` 또는 장기간에 걸쳐 동일한 로그인 계정을 추적하는 `@account.id` 중 어떤 기준으로 유지율을 측정할지 선택합니다.
   - {{< ui >}}Rate{{< /ui >}} 또는 {{< ui >}}Count{{< /ui >}}: 유지율을 백분율이나 절대값으로 표시할지 선택합니다.
   - {{< ui >}}Each day{{< /ui >}}, {{< ui >}}Each week{{< /ui >}} 또는 {{< ui >}}Each month{{< /ui >}}: 복귀 이벤트를 그룹화할 시간 단위를 선택합니다. 일일 유지율은 최대 한 달, 주간 유지율은 최대 1년, 월간 유지율은 최대 16개월까지 적용할 수 있습니다.

3. 차트 유형 선택기를 사용하여 차트 유형을 전환합니다.

   - {{< ui >}}Retention{{< /ui >}}: 지정된 코호트의 유지율 변화를 보여주는 유지율 곡선과 기간별 코호트의 세부 데이터를 보여주는 유지율 그리드가 모두 포함됩니다.
   - {{< ui >}}Timeseries{{< /ui >}}: 특정 코호트에 초점을 맞추지 않고 선택한 단일 복귀 기간의 유지율이 시간에 따라 어떻게 변하는지 보여줍니다.
   - {{< ui >}}Query value{{< /ui >}}: 선택한 코호트(전체 코호트의 가중 평균 또는 특정 코호트)를 기준으로 선택한 단일 복귀 기간의 유지율을 비율이나 사용자 수로 나타내는 하나의 숫자를 표시합니다.
   - {{< ui >}}Top list{{< /ui >}}: {{< ui >}}Compare{{< /ui >}} 속성이 지정된 경우, 지정된 기간 동안 그룹별 결과를 유지율 또는 사용자 수에 따라 순위순으로 표시합니다.

4. 시간 범위 선택기를 사용하여 차트에서 분석할 데이터의 기간을 변경합니다.

5. 셀 위로 마우스를 가져가면 해당 기간에 복귀한 정확한 사용자 수, 복귀율 및 이전 기간 대비 변화량을 확인할 수 있습니다. 셀을 클릭하여 사용자 목록을 확인하고 CSV로 내보냅니다.

### 동일한 이벤트와 서로 다른 이벤트 사용 {#using-matching-vs-differing-events}

유지율 차트에서 시작 이벤트와 복귀 이벤트를 동일하거나 다르게 구성할 수 있습니다.

두 이벤트가 동일하면 0주 차에는 초기 이벤트를 완료한 모든 사용자가 포함되므로 유지율이 항상 100%입니다. 나머지 각 셀은 해당 주의 사용자를 0주 차와 비교하여 최초 코호트 중 해당 주에 이벤트를 다시 완료한 사용자의 비율을 보여줍니다.

{{< img src="/product_analytics/retention/retention_matching_events.png" alt="동일한 이벤트의 유지율 그래프" style="width:90%;" >}}

위 그래프의 **2026년 8월 17일** 행을 왼쪽에서 오른쪽으로 살펴보면 다음과 같습니다.
- 해당 주에 이벤트를 완료한 사용자 1만 430명 중 23%가 1주 후에 복귀하여 이벤트를 다시 완료했습니다.
- 해당 사용자 중 21%가 2주 후에 복귀하여 이벤트를 다시 완료했습니다.
- 해당 사용자 중 11%가 3주 후에 복귀하여 이벤트를 다시 완료했습니다.

두 이벤트가 서로 다르면 0주 차에는 초기 이벤트와 복귀 이벤트를 모두 완료한 사용자가 표시됩니다. 그 이후의 각 셀은 최초 코호트 중 해당 주에 복귀 이벤트를 완료한 사용자 비율을 보여줍니다.

{{< img src="/product_analytics/retention/retention_differing_events.png" alt="서로 다른 이벤트의 유지율 그래프" style="width:90%;" >}}

위 그래프의 **2026년 8월 17일** 행을 왼쪽에서 오른쪽으로 살펴보면 다음과 같습니다.
- 해당 주에 사용자 1만 430명이 시작 이벤트를 완료했습니다.
- 해당 사용자 중 41%가 같은 주에 복귀 이벤트도 완료했습니다.
- 해당 사용자 중 23%는 1주 후, 20%는 2주 후, 11%는 3주 후에 복귀 이벤트를 완료했습니다.
