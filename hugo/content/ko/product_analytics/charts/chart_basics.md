사용자 및 제품 분석을 지원하기 위해 필요시 Product Analytics 차트를 생성, 저장 및 공유합니다. 

## 차트 생성 {#create-a-chart}

차트를 처음부터 생성하거나 미리 만들어진 템플릿을 사용하여 사용자 행동을 탐색하거나 제품 메트릭을 시각화합니다.

처음부터 차트를 생성하려면 Product Analytics 사이드바에서 {{< ui >}}Create New{{< /ui >}}를 선택한 다음 차트 유형을 선택합니다. 

{{< img src="product_analytics/chart_basics/chart_basics_create.png" alt="'Create New' 버튼과 선택 가능한 차트 유형 목록이 표시된 Product Analytics 사이드바" style="width:50%;" >}}

템플릿에서 차트를 생성하려면 Product Analytics {{< ui >}}Charts{{< /ui >}} 페이지에서 {{< ui >}}Explore all templates{{< /ui >}}를 클릭합니다. 

{{< img src="product_analytics/chart_basics/chart_basics_template.png" alt="차트 템플릿으로 시작 섹션과 모든 템플릿 탐색 링크가 표시된 차트 페이지" style="width:100%;" >}}

## 차트 저장 또는 공유 {#save-or-share-a-chart}

주요 제품 메트릭의 시간에 따른 변화를 추적할 수 있도록 차트를 저장하거나, 팀이 동일한 인사이트를 바탕으로 조치를 취할 수 있도록 공유합니다.

{{< img src="product_analytics/chart_basics/chart_basics.png" alt="차트 이름 필드와 공유 및 저장 버튼에 번호가 지정된 설명 표시가 있는 차트 편집기" style="width:100%;" >}}

1. 차트 이름을 클릭하여 이름을 변경합니다.

2. {{< ui >}}Save{{< /ui >}}를 클릭하여 차트를 {{< ui >}}Charts{{< /ui >}} 페이지에 저장합니다. 드롭다운을 사용하여 차트를 대시보드나 노트북에 저장합니다. 

   {{< ui >}}Share{{< /ui >}}를 클릭하여 차트를 클립보드에 복사합니다. 드롭다운을 사용하여 차트를 PNG 형식으로 내보내거나, 지원되는 경우 차트 데이터를 CSV 형식으로 내보냅니다.
