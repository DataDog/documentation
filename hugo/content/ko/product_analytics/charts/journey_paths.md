title: 여정 경로

여정 경로는 사용자가 선택한 이벤트 사이에서 취하는 가장 일반적인 경로를 보여줍니다.

여정 경로를 사용하여 다음을 수행합니다.
- 사용자가 주요 여정을 탐색하고 워크플로를 완료하는 방법을 확인합니다.
- 사용자가 효율적으로 전환하고 있는지 아니면 예상치 못한 우회 경로를 이용하고 있는지 파악합니다.
- 사용자가 어디에서 왜 이탈하는지 조사합니다.

{{< img src="product_analytics/journeys/journey_paths/pana_journey_paths_conversion_chart.png" alt="두 조회 사이에서 사용자가 취하는 상위 경로를 보여주는 렌더링된 여정 경로 차트입니다." style="width:100%;" >}}

## 여정 경로 차트 생성 {#create-a-journey-paths-chart}

1. {{< ui >}}Product Analytics{{< /ui >}}에서 {{< ui >}}Create New{{< /ui >}} > {{< ui >}}Journey Paths{{< /ui >}}를 선택합니다.

2. 경로를 분석할 최소 두 개의 이벤트를 선택하여 {{< ui >}}User steps{{< /ui >}}를 정의합니다. 

   특정 단계의 경우 {{< ui >}}or...{{< /ui >}}를 클릭하여 여러 이벤트를 지정하거나, 필터 아이콘을 클릭하여 지정된 속성별로 단계를 필터링합니다. 

3. (선택 사항) {{< ui >}}Filter by{{< /ui >}} 기준을 사용하여 국가 또는 장치 유형과 같은 속성을 기반으로 차트 결과를 필터링합니다.

## 여정 경로 차트 분석 {#analyze-a-journey-paths-chart}

여정의 단계를 정의하면 차트에 사용자가 단계 사이에서 취한 가장 일반적인 경로가 표시됩니다.

각 경로는 해당 경로를 따른 세션의 비율과 수, 그 경로에서 보낸 평균 시간을 보여줍니다. 나열된 이벤트가 없는 경로는 중간 조회나 작업 없이 시작 이벤트에서 종료 이벤트로 직접 이동한 세션을 나타냅니다.

{{< img src="product_analytics/journeys/journey_paths/pana_journey_paths_customization.png" alt="전환/이탈 선택기, 단계 선택기, 시간 범위, 이벤트 유형 토글, 더 보기, 경로 옵션 메뉴, 더 많은 경로/더 적은 경로 컨트롤에 대한 번호가 매겨진 콜아웃이 있는 여정 경로 차트입니다." style="width:100%;" >}}

분석하려는 경로에 집중할 수 있도록 다양한 방법으로 여정 경로 차트를 구체화할 수 있습니다.

1. {{< ui >}}Converted{{< /ui >}}/{{< ui >}}Dropped{{< /ui >}} 선택기를 사용하여 최종 단계에 도달한 경로와 이탈한 경로 간에 전환합니다. 드롭오프 경로에 끝 노드가 없습니다.

2. 단계가 여러 개인 여정의 경우, 단계 선택 도구를 사용하여 경로를 분석할 단계 쌍을 선택하세요.  

3. 기간 선택 도구를 사용하여 차트가 분석할 데이터 기간을 변경하세요.

4. {{< ui >}}Views{{< /ui >}} 및 {{< ui >}}Actions{{< /ui >}} 토글을 사용하여 경로 노드로 표시할 이벤트 유형을 제어하세요. 조회, 액션, 사용자 지정 액션은 다이어그램에서 각각 고유한 색상과 아이콘으로 표시되므로 경로의 각 단계에서 이벤트 유형을 식별할 수 있습니다.

5. 잘린 경로의 경우 {{< ui >}}View more{{< /ui >}}를 클릭하여 해당 경로의 다음 이벤트를 확인하세요. {{< ui >}}View less{{< /ui >}}를 클릭하여 다시 접으세요.

6. 이벤트를 클릭하여 Session Replay 또는 해당 경로와 관련된 사용자를 조회할 수 있는 옵션 메뉴를 여세요. 또는 **Option**(macOS) 또는 **Alt**(Windows/Linux)를 누른 상태에서 이벤트를 클릭하여 다이어그램에서 숨기세요.

7. {{< ui >}}More Paths{{< /ui >}} 및 {{< ui >}}Fewer Paths{{< /ui >}}를 사용하여 표시할 경로 수를 조절하세요.
