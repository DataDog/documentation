## 개요 {#overview}

프로덕션 보안 운영의 속도와 확장성을 높이세요. Datadog Security는 애플리케이션, 호스트, 컨테이너 및 클라우드 인프라 전반에 걸쳐 실시간 위협 탐지와 지속적인 구성 감사를 제공합니다. Datadog Security는 Datadog 관측 가능성 플랫폼과 결합되어 조직의 공동 목표에 맞춰 보안과 운영을 전례 없는 수준으로 통합합니다.

Datadog Security에는 다음이 포함됩니다. 
- [Cloud SIEM](#cloud-siem)
- [Code Security](#code-security)
- [Cloud Security](#cloud-security)
- [App and API Protection](#app-and-api-protection)
- [AI Guard](#ai-guard)
- [Workload Protection](#workload-protection)
- [Sensitive Data Scanner](#sensitive-data-scanner)
 
자세한 내용을 알아보려면 [30초 제품 가이드 투어][14]를 확인하세요.

## Cloud SIEM {#cloud-siem}

[Cloud SIEM][4](Security Information and Event Management)은 표적 공격, 시스템과 통신하는 IP 중 위협 인텔리전스 목록과 일치하는 IP, 안전하지 않은 구성 등 애플리케이션 및 인프라에 대한 실시간 위협을 탐지합니다. Cloud SIEM은 [Datadog Log Management][5]를 기반으로 합니다. 이러한 영역을 결합하면 [Datadog Cloud SIEM에서 탐지한 위협의 수정을 자동화][6]하여 위협 대응 워크플로를 가속화할 수 있습니다. 자세한 내용은 전용 [가이드 투어](https://www.datadoghq.com/guided-tour/security/cloud-siem/)를 확인하세요.

{{< img src="security/security_monitoring/cloud_siem_overview_2025.png" alt="중요 신호, 의심스러운 행위자, 영향을 받은 리소스, 위협 인텔리전스 및 신호 추세 위젯이 포함된 Security Overview 섹션을 보여주는 Cloud SIEM 홈페이지" width="100%">}}

## Code Security {#code-security}

[Code Security][20]는 리포지토리와 실행 중인 서비스에서 애플리케이션에 사용되는 자사 코드와 오픈소스 라이브러리를 스캔하여 개발부터 프로덕션까지 엔드투엔드 가시성을 제공합니다. 다음 기능이 포함됩니다.

- 자사 코드의 보안 및 품질 문제를 식별하는 [Static Code Analysis(SAST)][27]
- 리포지토리와 서비스의 오픈소스 종속성을 식별하는 [Software Composition Analysis(SCA)][28]
- 서비스 내 자사 코드의 취약성을 식별하는 [Runtime Code Analysis(IAST)][29]
- 유출된 시크릿을 식별하고 검증하는 [Secret Scanning][30](미리 보기)

IDE 통합, 풀 리퀘스트 주석 및 CI/CD 게이트를 통해 Code Security는 팀이 조직 전체에서 DevSecOps를 구현하도록 지원합니다.
- **개발자:** 취약성 조기 탐지, 코드 품질 개선, 디버깅 및 패치 시간 단축을 통한 개발 가속화
- **보안 관리자:** 보안 태세 강화, 취약성 조기 경보에 대응한 패치 관리 개선, 규정 준수 모니터링
- **사이트 안정성 엔지니어(SRE):** CI/CD 워크플로 전반의 자동화된 보안 검사, 보안 규정 준수 및 시스템 복원력 SAST는 SRE의 수동 오버헤드를 줄이고 각 릴리스의 취약성을 철저히 테스트하도록 합니다.

## Cloud Security {#cloud-security}

[Cloud Security][10]는 클라우드 인프라 전체에서 실시간 위협 탐지 및 지속적인 구성 감사를 제공하며, 이를 하나의 통합 보기에서 제공하여 원활한 협업과 신속한 수정을 지원합니다. 관측 가능성 데이터를 기반으로 보안 팀은 전체 공격 흐름을 추적하여 위협의 영향을 파악하고 취약성이 트리거된 리소스의 소유자를 식별할 수 있습니다.

Cloud Security에는 [Workload Protection][12], [Misconfigurations][11], [Identity Risks][15] 및 [Vulnerabilities][16]가 포함됩니다. 자세한 내용은 전용 [가이드 투어][13]를 확인하세요.

{{< img src="security/csm/csm_overview_3.png" alt="Cloud Security 개요의 Security Inbox에는 우선순위가 지정된 보안 이슈 목록이 표시됩니다." width="100%">}}

Datadog Security를 시작하려면 Datadog에서 [{{< ui >}}Security{{< /ui >}} > {{< ui >}}Setup{{< /ui >}}][9] 페이지로 이동합니다. 해당 페이지에는 단일 또는 다중 구성에 대한 자세한 정보가 있습니다. 또는 아래의 시작하기 섹션에서 플랫폼의 각 영역에 대해 자세히 알아보세요.

##  App and API Protection {#app-and-api-protection}

Datadog [App and API Protection (AAP)][1]은 서버 측 요청 위조(SSRF), SQL 인젝션, Log4Shell, 반사형 교차 사이트 스크립팅(XSS)과 같이 코드 수준의 취약점을 악용하려는 애플리케이션 수준의 공격에 대한 관측 가능성을 제공합니다. AAP는 [Datadog APM][2], [Datadog Agent][3] 및 인앱 탐지 규칙을 활용하여 애플리케이션 환경의 위협을 탐지합니다. 자세한 내용은 제품 [가이드 투어](https://www.datadoghq.com/guided-tour/security/application-security-management/)를 확인하세요.

## AI Guard {#ai-guard}

[AI Guard][35]는 AI 동작을 실시간으로 검사, 차단 및 제어합니다. 이 기능은 AI 앱 또는 에이전트와 인라인으로 배치되어 Prompt Protection, Tool Protection 및 Sensitive Data Protection을 사용해 프롬프트 인젝션, 탈옥 및 민감한 데이터 유출 공격으로부터 보호합니다. 이러한 보호 기능은 OpenAI, Anthropic, Bedrock, VertexAI 및 Azure를 포함한 모든 대상 AI 모델에 적용됩니다.

{{< img src="security/ai_guard/ai_guard_detection_rules_1.png" alt="AI Guard 탐지 규칙 탐색기" width="100%">}}

## Workload Protection {#workload-protection}

[Workload Protection][26]은 환경 전체에서 파일, 네트워크, 프로세스 활동을 모니터링하여 인프라를 노리는 실시간 위협을 탐지합니다. Datadog 플랫폼의 일부인 Workload Protection의 실시간 위협 탐지를 메트릭, 로그, 트레이스 및 기타 텔레메트리와 결합하여 워크로드에 대한 잠재적 공격의 전체 컨텍스트를 확인할 수 있습니다.

- [Automated response][31]로 위협을 사전에 차단
- 기본 제공 및 사용자 지정 [탐지 규칙][32] 관리
- 실시간 [알림][33] 설정
- [보안 신호][34]를 조사하고 수정합니다.

## Sensitive Data Scanner {#sensitive-data-scanner}

[Sensitive Data Scanner][24]는 민감한 데이터를 발견하고 분류하며 필요시 마스킹하여 민감한 데이터 유출을 방지하고 규정 미준수 위험을 줄이는 데 도움이 됩니다. 애플리케이션 로그, APM 스팬, RUM 이벤트, Event Management 이벤트 등 텔레메트리 데이터에서 민감한 데이터를 검사할 수 있습니다. 또한 클라우드 스토리지 리소스 내의 민감한 정보를 검사할 수 있습니다. 

[Sensitive Data Scanner][25]를 설정한 후 {{< ui >}}Findings{{< /ui >}} 페이지에서 식별된 민감한 데이터 발견 결과의 세부 정보를 확인하여 발견 결과를 분류하고 조사하고 수정할 수 있습니다.
