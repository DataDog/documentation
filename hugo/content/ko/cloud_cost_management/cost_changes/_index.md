## 개요 {#overview}

Cloud Cost Management를 사용하면 예상치 못한 비용 변동이 심각한 문제로 악화되기 전에 선제적으로 탐지하고 대응할 수 있습니다. 이러한 도구를 사용하여 AWS, Azure, Google Cloud 전반에서 이상 징후를 자동으로 식별하고, 사용자 지정 경보를 설정하고, 거의 실시간으로 비용을 추적하세요.

## 주요 기능 {#key-features}

{{< whatsnext desc="이 섹션에는 다음 주제가 포함되어 있습니다." >}}
    {{< nextlink href="/cloud_cost_management/cost_changes/anomalies" >}}<u>이상 징후</u>: 머신러닝을 통해 비정상적인 비용 패턴을 자동으로 탐지합니다. Watchdog Explains를 사용해 비용 변동의 원인을 파악하고 팀과 컨텍스트를 공유하여 더 빠르게 문제를 해결할 수 있습니다.{{< /nextlink >}}
    {{< nextlink href="/cloud_cost_management/cost_changes/monitors" >}}<u>모니터링</u>: 비용이 임계값을 초과하거나 예상치 못한 변동이 발생하면 사용자 지정 경보를 생성합니다. 여기에는 15분 이내에 경보를 보내는 실시간 AI 이상 징후 모니터가 포함됩니다. 특정 조건을 정의하고, 공급자/태그 기준으로 필터링하고, 알림 채널(이메일, Slack, PagerDuty 등)과 통합합니다.{{< /nextlink >}}
    {{< nextlink href="/cloud_cost_management/cost_changes/real_time_costs" >}}<u>실시간 비용</u>: 5분마다 업데이트되는 Amazon EC2 비용의 실시간에 근접한 추정치를 확인합니다. 며칠이 아닌 몇 시간 내에 비용 변동에 대응하고, Kubernetes 클러스터 비용을 실시간으로 추적합니다.{{< /nextlink >}}
