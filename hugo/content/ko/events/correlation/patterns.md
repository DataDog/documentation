## 개요 {#overview}

패턴 기반 상관 관계를 사용하면 이벤트가 어떻게 연관되는지를 제어할 수 있습니다. 또한 Datadog은 머신러닝을 사용하여 Datadog Monitor 이벤트와 관련하여 패턴을 자동으로 보강합니다. 이때 Datadog 및 기타 휴리스틱을 통해 수집된 텔레메트리를 활용합니다.

시작을 돕기 위해 Datadog은 환경에 따라 [패턴 기반 상관 관계][1]를 자동으로 제안합니다. 추천 항목 중 하나를 클릭하여 추천된 패턴의 구성을 엽니다. 구성 필드는 미리 채워져 있습니다.

## 패턴 생성 {#create-a-pattern}

패턴을 생성하려면 다음 단계를 따르세요.
1. [Correlation][1]으로 이동합니다.
1. 패턴 테이블 상단에서 {{< ui >}}\+ Add a Pattern{{< /ui >}}을 클릭합니다. 그러면 패턴 구성 페이지가 열리고, 좌측에 기본 추천 패턴이 표시되고, 우측에 패턴 출력 미리보기가 표시됩니다. 
1. {{< ui >}}\+ Continue With Pattern{{< /ui >}}을 클릭하여 추천 패턴을 조정할 수 있습니다. 추가 조정을 위해 미리 채워진 구성 페이지로 이동합니다. 또는 {{< ui >}}\+ Personalize From Scratch{{< /ui >}}를 클릭하여 직접 패턴을 생성할 수 있습니다.

먼저, 이벤트 집계 키를 기반으로 경보를 생성하기 위해 이벤트가 중복 제거됩니다. 그런 다음, 구성에 따라 경보가 작업 항목과 연관됩니다. 
{{< img src="events/correlation/correlation_helper.mp4" alt="이벤트가 정의된 소스 및 필터와 일치하면 중복 제거되어 경보가 생성됩니다. 경보는 그룹화 속성을 기반으로 연관되며, 프로세스가 새 작업 항목에서 반복되기 전에 해당 이벤트가 정의된 시간 창 내에서 중복 제거됩니다. 이러한 구성은 설정에서 수정할 수 있습니다." video=true >}}
집계 키와 함께 이벤트를 보내는 방법에 대한 자세한 내용은 [Datadog으로 이벤트 보내기][5]를 참조하세요. 집계 키가 없는 이벤트는 시간 범위 내에서 하나의 단일 경보로 중복 제거됩니다.

### 추천 패턴 {#suggested-patterns}
사용자가 일반적으로 사용하는 서비스와 환경 태그를 기반으로 추천 패턴을 제안해 이벤트 상관관계를 빠르게 수립할 수 있도록 도와줍니다. 

### 구성 {#configuration}
[상관관계 구성 페이지][2]에서
1. 드롭다운에서 그룹화할 이벤트 소스를 선택합니다.
1. 위에 정의된 소스에서 이벤트를 제외하려면 {{< ui >}}Filter by these events or tags{{< /ui >}}에서 이벤트 쿼리를 추가하여 필터링합니다.
1. 관련 이벤트를 추가하여 변경 사항이나 기타 보조 이벤트를 연결함으로써 작업 항목 조사를 지원합니다. 관련 이벤트는 작업 항목에 추가되지만 새 작업 항목을 생성하지는 않습니다.
1. 그룹화 태그를 정의합니다. 그룹화 태그는 이벤트 패싯입니다. 드롭다운에 태그가 보이지 않으면 아래의 [고급 설정 섹션](#advanced-settings-optional)을 참조하세요. 
**참고**: 이벤트 속성과 태그 모두에 대해 패싯을 생성할 수 있습니다. 자세한 내용은 [facets][4] 문서를 참조하세요. 

### 고급 설정(선택 사항) {#advanced-settings-optional}
1. {{< ui >}}Show Advanced Settings{{< /ui >}}를 클릭합니다.
1. 그룹화 태그를 추가하여 이벤트를 연관시키고 작업 항목 제목을 사용자 지정할 수 있습니다.
   
   그룹화 태그 추가
   새 그룹화 태그를 추가하는 방법은 [새 이벤트 패싯][3]을 추가하는 방법과 동일합니다.

   작업 항목 제목 사용자 지정
   : 자동으로 생성된 작업 항목 제목을 대체할 템플릿을 생성합니다. 핸들바 구문(예: "{{tag.service}}")을 사용하여 태그 템플릿 변수를 참조하여 쉼표로 구분된 태그 값 목록을 포함할 수 있습니다.
   
1. {{< ui >}}Correlator Logic{{< /ui >}}에서 작업 항목을 생성할 시기와 경보를 연관시키고 이벤트를 중복 제거할 기간을 구성합니다.

   {{< img src="events/correlation/pattern/correlator_logic_advanced_settings.png" alt="최소 경보 수, 상관관계 기간, 자동 종료, 이벤트 중복 제거 및 확장 중복 제거 옵션을 보여주는 Advanced Settings의 Correlator Logic 탭" style="width:100%;" >}}

   최소 경보 수
   : 작업 항목을 생성하는 데 필요한 최소 경보 수입니다. 최솟값이 1이면 첫 번째 연관 경보가 작업 항목을 생성합니다.

   상관관계 기간
   : 동일한 작업 항목에 새 경보를 추가할 수 있는 최대 기간입니다. 이 기간은 첫 번째 경보가 연관될 때 시작됩니다.

   자동 종료 후 새 작업 항목 생성
   : 활성화되면 이전 작업 항목이 자동으로 종료된 후 일치하는 경보가 새 작업 항목을 생성합니다.

   중복 제거 기간
   : 작업 항목에 이미 포함된 경보에서 발생하는 추가 이벤트가 해당 경보와 연관되는 기간입니다. 이 기간은 첫 번째 경보가 연관될 때 시작됩니다.

   모든 경보가 해결될 때까지 중복 제거 기간 연장
   : 활성화되면 작업 항목에 이미 포함된 미해결 경보는 중복 제거 기간이 만료된 후에도 최대 30일까지 이벤트를 계속 수신할 수 있습니다. 이 설정은 새 경보를 추가하기 위한 상관관계 기간을 연장하지 않습니다.

   예를 들어, 최소 경보 수가 1개이고 상관관계 기간이 48시간이며 중복 제거 기간이 48시간인 패턴을 고려해 보세요.
   - 경보 A가 월요일 오전 9:00에 연계됩니다. 작업 항목이 생성되고 기간이 둘 다 시작됩니다.
   - 경보 B가 월요일 오전 10:00에 연계되어 동일한 작업 항목에 추가됩니다. 중복 제거 기간에 경보 A 또는 경보 B에서 발생하는 추가 이벤트는 해당 기존 경보와 연계됩니다.
   - 구성된 두 기간은 수요일 오전 9:00에 만료됩니다.
   - 경보 C가 수요일 오전 10:00에 연계됩니다. 상관관계 기간이 종료되었기 때문에 기존 작업 항목에 참여할 수 없으며 **Create a new work item after auto-closure** 설정과 관계없이 새 작업 항목을 생성합니다.

   **Extend dedupe window until all alerts resolve**가 활성화되면 해결되지 않은 경보 A 또는 경보 B의 이벤트는 수요일 오전 9:00시 이후에도 최대 30일 동안 기존 상관관계를 계속 업데이트할 수 있습니다. 경보 C는 새 경보이므로 기존 작업 항목에 참여할 수 없습니다.

   작업 항목은 모든 경보가 해결될 때만 자동으로 닫힙니다. 경보가 해결되지 않은 상태에서 중복 제거가 종료되면 상관관계 분석이 중지되고 수동으로 닫지 않는 한 작업 항목은 열린 상태로 유지됩니다.

   작업 항목에는 경보가 최대 500개까지 포함될 수 있으며 각 경보는 이벤트를 최대 100개 유지할 수 있습니다. 경보가 100개의 이벤트에 도달하면 상관관계 식별자는 복구 이벤트를 포함하여 해당 경보에 대한 이후의 모든 이벤트를 삭제합니다. 경보가 해결될 수 없으므로 수동으로 닫지 않는 한 작업 항목은 열린 상태로 유지됩니다.

   작업 항목이 경보 해결 전에 처리를 중지하면 {{< ui >}}Ended incomplete{{< /ui >}} 배지가 표시됩니다. 배지 위로 마우스를 가져가면 처리가 중지된 이유를 확인할 수 있습니다.

   작업 항목의 이벤트 목록은 일치하는 이벤트를 독립적으로 검색하므로 작업 항목이 일치하는 이벤트를 100개 이상 표시할 수 있습니다. 표시된 이벤트 수는 상관관계 식별자가 유지하고 처리하는 이벤트 수와 다를 수 있습니다.


## 패턴 출력 미리보기 {#preview-pattern-output}

구성을 통해 잠재적으로 생성될 수 있는 패턴과 작업 항목을 미리 볼 수 있습니다. 미리보기 패널에 표시되는 항목 
- 수집된 이벤트 총 수(첫 1,000개 이벤트로 제한)
- 이벤트에서 중복 제거될 경보 수
- 구성에 따라 생성될 작업 항목 수 

이 데이터를 이용해 내 상관관계에 있을 영향을 미리 보고 패턴의 예측 결과를 이해할 수 있습니다.

**참고**: 미리보기 작업 항목의 기본 제목은 상관관계의 첫 번째 경보입니다. 패턴을 저장하면 이벤트 관리 작업 항목 제목이 지능적으로 생성됩니다. 

## Work Management 대상 선택 {#select-a-work-management-destination}

1. {{< ui >}}Project{{< /ui >}} 드롭다운 메뉴에서 그룹화된 이벤트를 보낼 기존 작업 항목을 선택합니다.
1. (선택 사항) 결과 작업 항목에 태그를 추가합니다.
1. {{< ui >}}Save and Activate{{< /ui >}}를 클릭하여 이 패턴을 활성화하고 이벤트를 작업 항목으로 그룹화합니다.

## 기존 패턴 업데이트{#update-existing-pattern}
기존 패턴을 업데이트하면 모든 실시간 작업 항목의 처리가 중단됩니다. 패턴과 일치하는 새 이벤트는 새 작업 항목을 생성합니다.
