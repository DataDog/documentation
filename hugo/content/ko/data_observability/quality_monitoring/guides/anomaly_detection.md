**참고**: 이 페이지는 이상 기반 Data Observability 모니터에만 적용됩니다. 모니터가 **임계값** 탐지 방법을 사용하는 경우 이 내용은 적용되지 않습니다.

## 개요 {#overview}

기본적으로 [Data Observability 모니터][1]는 테이블 신선도 및 행 수와 같은 데이터 품질 메트릭의 일반적인 패턴에 맞게 조정된 이상 탐지 모델을 사용합니다.

모델은 메트릭의 이력을 학습하여 예상 범위를 설정합니다. 관측값이 해당 범위를 벗어나면 모니터가 경보를 발생시킵니다.

## 학습 기간 {#training-period}

이상 탐지 모니터를 생성하면 학습 기간이 시작됩니다. 학습 기간 동안 모니터는 메트릭의 기준 동작을 학습하기 위해 과거 값을 수집합니다. 이 기간에는 경보가 발생하지 않으며 모니터 차트가 파란색으로 표시됩니다.

학습은 일반적으로 3일에서 9일 정도 소요됩니다. 많은 데이터 파이프라인이 주말에 다르게 동작하므로 모델은 평일과 주말 동작을 모두 관찰해야 합니다.

학습이 완료되면 모니터가 경보를 발생시킬 수 있습니다. 차트는 시간에 따른 관측값을 보여주며, 예상 값의 범위를 나타내는 음영 영역이 선의 위아래에 표시됩니다. 색상은 현재 상태를 나타냅니다.

| 색상 | 상태 | 설명 |
|-------|-------|-------------|
| 파란색 | 학습 | 모니터가 기준 동작을 학습하고 있습니다. 경보가 발생하지 않습니다. |
| 녹색 | 정상 | 관측값이 예상 범위 내에 있습니다. |
| 빨간색 | 경보 발생 중 | 관측값이 예상 범위를 벗어났습니다. |

## 경보 상태 {#alert-state}

이상이 발견되면 모델은 관측값이 원래 예상 범위로 돌아오거나 이상이 충분히 오래 지속되어 모델이 이를 새로운 정상 상태로 간주할 때까지 일정 시간 동안 경보 상태를 유지합니다. 모니터를 수동으로 해결하여 정상 상태로 되돌리려면 [주석][2]을 사용하세요.

## 메트릭별 동작 {#metric-specific-behavior}

모델은 메트릭에 따라 다르게 작동합니다.

### 신선도 {#freshness}

신선도 모니터는 마지막 새로 고침 이후 경과 시간이 과거 업데이트 패턴을 기반으로 한 예상 시간보다 길면 경보를 발생시킵니다. 모델은 사소한 지연으로 인해 경보가 발생하는 것을 방지하기 위해 상한값에 작은 버퍼를 추가합니다.

### 행 개수 {#row-count}

행 개수 모니터는 비정상적인 변화가 있을 때뿐만 아니라 행 개수가 평소보다 오래 변하지 않는 정체 상태에서도 경보를 발생시킵니다. 행 개수가 정체되면 파이프라인이 정상적으로 작동하지 않음을 나타낼 수 있습니다.

### 백분율(예: nullness, uniqueness) {#percentage-eg-nullness-uniqueness}

백분율 메트릭은 0에서 100까지의 척도로 측정됩니다. 메트릭이 0이나 100이었던 적이 없는 경우 이러한 값으로 변경되면 경보가 발생합니다.

### Custom SQL {#custom-sql}

Custom SQL 모니터의 경우 메트릭에 사용할 모델 유형으로 **Freshness**, **Percentage** 또는 **Default**를 선택하세요.  **Default** 모델은 메트릭의 이력에서 범위를 추론합니다. 예를 들어, 사용자 지정 메트릭이 음수 값을 반환한 적이 없는 경우 모델은 하한값을 0으로 제한합니다.

## 계절성 {#seasonality}

이 모델은 최대 400일의 기록을 사용하여 계절적 패턴, 추세 및 과거 주석을 반영합니다. 예를 들어, 메트릭이 일요일마다 지속적으로 하락하는 경우 모델은 일요일의 낮은 값을 이상으로 간주하지 않고 정상으로 처리합니다.

다음과 같은 계절성 패턴이 탐지됩니다.

| 패턴 | 설명 |
|---------|-------------|
| 하루 중 시간대 | 영업 시간에 행 수가 더 많은 것과 같이 일중 패턴을 따르는 메트릭입니다. |
| 주중 시간대 | 시간 단위로 일주일 전체에 걸쳐 일관된 패턴을 보이는 메트릭입니다. |
| 요일 | 일요일에 활동이 낮은 것과 같이 요일에 따라 다른 패턴을 보이는 메트릭입니다. |
| 월중 일자 | 월말 급증과 같이 달력상의 월 주기에 따라 반복되는 패턴을 보이는 메트릭입니다. |

모든 계절성 패턴을 모든 메트릭 유형에 사용할 수 있는 것은 아닙니다. 또한 모델이 특정 패턴을 탐지하려면 정상적인 이력의 완전한 주기가 여러 번 필요합니다.

## 추세 {#trends}

모델은 메트릭이 시간이 지남에 따라 증가하는지 또는 감소하는지를 고려합니다. 매주 행이 지속적으로 추가되는 메트릭의 경우 모델은 성장을 이상으로 간주하지 않고 변화의 방향과 속도에 따라 예상 범위를 조정합니다.

## 주석 {#annotations}

주석을 사용하면 모델이 경보를 놓치거나 잘못된 경보를 발생시켜 데이터 포인트를 잘못 분류한 경우 즉시 재학습할 수 있습니다. 데이터 품질 기대치는 종종 메트릭별로 다르기 때문에 주석은 팀의 요구 사항에 맞게 모델을 조정하는 주요 수단입니다.

주석은 다음과 같은 두 가지 효과가 있습니다.
- **현재 상태 수정**: 플래그가 지정된 포인트를 예상된 것으로 표시하면 다음 관측 시 모니터가 경보 상태에서 정상 상태로 전환되고 이후 새로운 이상에 대해 경보를 발생시킬 수 있습니다.
- **향후 예측 형성**: 모델은 주석이 달린 포인트를 사용하여 향후 범위를 조정하므로 피드백을 통해 정확도가 즉시 향상됩니다.

사용 가능한 주석 유형과 적용 방법은 Data Observability Monitor 페이지의 [Annotate bounds][2]를 참조하세요.
