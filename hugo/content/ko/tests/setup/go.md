## Orchestrion 설치 {#installing-orchestrion}

Orchestrion은 컴파일 시간에 Go 소스 코드를 처리하고 `dd-trace-go`를 사용하여 계측을 자동으로 삽입하는 도구입니다.

다음 명령을 사용하여 [https://github.com/datadog/orchestrion][1]에서 `orchestrion`을 설치하세요.

```bash
$ go install github.com/DataDog/orchestrion@latest
```

{{% collapse-content title="선택 사항: 프로젝트 go.mod 등록" level="h3" expanded=false %}}

다음 명령을 실행하여 프로젝트의 종속성에 `orchestrion`을 자동으로 추가할 수 있습니다.

```bash
$ orchestrion pin
```

이 명령은 다음과 같은 효과가 있습니다.
1. 다음과 유사한 내용이 포함된 새 `orchestrion.tool.go` 파일을 생성합니다.
    
    ```go
    // Code generated by `orchestrion pin`; DO NOT EDIT.

    // This file is generated by `orchestrion pin`, and is used to include a blank import of the
    // orchestrion package(s) so that `go mod tidy` does not remove the requirements rom go.mod.
    // This file should be checked into source control.

    //go:build tools

    package tools

    import _ "github.com/DataDog/orchestrion"
    ```

2. `go get github.com/DataDog/orchstrion@<current-release>`를 실행하여 프로젝트 버전이
    현재 사용 중인 버전과 일치하는지 확인합니다.
3. `go mod tidy`를 실행하여 `go.mod` 및 `go.sum` 파일이 최신 상태인지 확인합니다.

이 명령을 실행하지 않으면 필요할 때 자동으로 수행됩니다. 완료되면 이 프로젝트에서 사용하는 `orchestrion` 버전을
다른 종속성과 마찬가지로 `go.mod` 파일을 사용하여 직접 제어할 수 있습니다.

{{% /collapse-content %}}


Orchestrion은 Go의 [공식 릴리스 정책][go-releases]에 따라 최신 Go 릴리스 두 가지를 지원합니다. 이전 Go 릴리스에서도
정상적으로 작동할 수 있지만, 작동하지 않는 이전 릴리스는 Datadog에서 지원할 수 없습니다.

또한 Orchestrion은 [Go 모듈][go-modules]을 사용하는 프로젝트만 지원합니다.

[go-releases]: https://go.dev/doc/devel/release#policy
[go-modules]: https://pkg.go.dev/cmd/go#hdr-Modules__module_versions__and_more

## 테스트 계측 {#instrumenting-tests}

라이브러리를 구성하려면 테스트 프로세스를 시작하기 전에 다음 환경 변수를 설정하세요. 병렬 테스트 실행기의 경우, 모든 작업자가 상속받을 수 있도록 상위 프로세스에서 설정하세요.

`DD_CIVISIBILITY_ENABLED=true` (필수)
: Test Optimization을 활성화합니다.<br/>
**기본**: `false`

`DD_SERVICE`(선택 사항)
: 테스트 중인 서비스 또는 라이브러리의 이름입니다.<br/>
**기본값**: 리포지토리 이름

`DD_ENV`(선택 사항)
: 테스트가 실행되는 환경의 이름입니다.<br/>
**기본**: `(empty)`<br/>
**예시**: `local`, `ci`

`DD_CIVISIBILITY_AGENTLESS_ENABLED=true`(Agentless 모드 사용 시 필수)
: 테스트 결과를 Datadog으로 직접 전송하는 Agentless 모드를 활성화합니다.<br/>
**기본값**: `false`

`DD_API_KEY`(Agentless 모드 사용 시 필수)
: 테스트 결과 업로드를 인증하는 데 사용되는 Datadog API 키입니다. 이 변수는 Agentless 모드를 활성화하지 않습니다.<br/>
**기본값**: `(empty)`

`DD_SITE`(Agentless 모드 사용 시 선택 사항)
: 테스트 결과를 업로드할 [Datadog 사이트][2]입니다. US1 이외의 사이트를 사용할 때 이 구성을 설정하세요.<br/>
**기본값**: `datadoghq.com`

`DD_TRACE_AGENT_URL`(Datadog Agent를 사용할 때만)
: `http://hostname:port` 형식의 트레이스 수집용 Datadog Agent URL입니다.<br/>
**기본값**: `http://localhost:8126`

`DD_TEST_SESSION_NAME`(선택 사항)
: `unit-tests`, `integration-tests` 또는 `smoke-tests`와 같은 테스트 그룹을 식별합니다.<br/>
**기본값**: CI 작업 이름 및 테스트 명령, 또는 CI 작업 이름을 사용할 수 없는 경우 테스트 명령입니다.<br/>
**예**: `unit-tests`, `integration-tests`, `smoke-tests`

go test 명령 앞에 `orchestrion`을 붙이세요.

```bash
$ orchestrion go test -race ./...
```

`orchestrion pin`을 실행하지 않은 경우 `orchestrion pin`이 자동으로 실행되므로 다음과 유사한 메시지가 나타날 수 있습니다.

```
  ╭──────────────────────────────────────────────────────────────────────────────╮
  │                                                                              │
  │  Warning: github.com/DataDog/orchestrion is not present in your go.mod       │
  │  file.                                                                       │
  │  In order to ensure build reliability and reproductibility, orchestrion      │
  │  will now add itself in your go.mod file by:                                 │
  │                                                                              │
  │      1. creating a new file named orchestrion.tool.go                        │
  │      2. running go get github.com/DataDog/orchestrion@v0.9.4                 │
  │      3. running go mod tidy                                                  │
  │                                                                              │
  │  You should commit the resulting changes into your source control system.    │
  │                                                                              │
  ╰──────────────────────────────────────────────────────────────────────────────╯
```

### 대안 {#alternative}

_Orchestrion_은 기본적으로 표준 Go 툴체인 `-toolexec` 프록시입니다. `orchestrion go`를 사용하는 대신,
이를 허용하는 `go` 명령에 `-toolexec` 인수를 수동으로 제공할 수도 있습니다.

```console
$ go build -toolexec 'orchestrion toolexec' .
$ go test -toolexec 'orchestrion toolexec' -race .
```
