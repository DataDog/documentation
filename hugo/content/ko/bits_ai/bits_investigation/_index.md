## 개요 {#overview}

Bits Investigation 은 프로덕션 문제를 전 과정에 걸쳐 조사하는 자율 AI 에이전트입니다. 반복적으로 가설을 세우고 관련 원격 분석 데이터를 수집하며, 데이터 기반 추론을 통해 온콜 엔지니어가 근본 원인을 파악하도록 돕습니다. 수동 작업과 인지 부하를 줄임으로써 Bits Investigation 은 온콜 운영을 더 원활하고 효율적으로 만듭니다.
