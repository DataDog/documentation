## 개요 {#overview}

<div class="alert alert-info">Real User Monitoring이 있는 경우 RUM 미리보기, Session Replay, Error Tracking 및 Synthetic 브라우저 테스트의 추가 성능 데이터에 액세스할 수 있습니다.</div>

Synthetic 브라우저 테스트에는 Real User Monitoring SDK가 포함되어 있어 다음을 탐색할 수 있습니다.

- 모든 테스트에 대한 [Session Replay][1]. 각 단계와 [브라우저 개발 도구][2]에 사용 가능한 스크린샷 외에도 추가 컨텍스트에 액세스할 수 있습니다.
- [RUM Explorer][3]의 세션.
- [Error Tracking][4]을 사용하여 다양한 단계, 테스트 및 테스트 실행 전반에서 집계된 오류를 확인할 수 있습니다. 오류 영향의 범위를 지정하고 가장 심각한 문제를 우선적으로 해결할 수 있습니다. 
- 추가 검색 및 모니터링 기능을 포함한 RUM의 추가 리소스 및 타이밍 정보.

## RUM 애플리케이션에서 Synthetic 데이터 허용 {#allow-synthetic-data-on-rum-applications}

<div class="alert alert-danger">
대상 애플리케이션이 이미 RUM으로 계측된 경우 Synthetic 테스트 설정 내에서 RUM 데이터 수집을 활성화하면 안 됩니다. 이렇게 하면 예기치 않은 동작이 발생할 수 있습니다.</div>

브라우저 테스트 레코딩에서 {{< ui >}}Start Recording{{< /ui >}} 버튼 위의 {{< ui >}}Collect RUM Data on{{< /ui >}}을 클릭하고 데이터를 수집할 애플리케이션을 선택하세요. 레코딩 및 테스트 설정을 저장하면, RUM은 테스트 데이터를 수집하고 브라우저 테스트 실행에서 세션 레코딩을 생성합니다. 

1. {{< ui >}}Digital Experience{{< /ui >}} > {{< ui >}}Settings{{< /ui >}}(Synthetic Monitoring & Testing 아래) > [{{< ui >}}Integration Settings{{< /ui >}}][5]로 이동합니다.
2. {{< ui >}}Synthetic Data RUM Collection{{< /ui >}} 아래에서 {{< ui >}}Enable Synthetic RUM data collection{{< /ui >}}을 클릭하여 Datadog이 테스트 실행에서 RUM 데이터를 수집하도록 활성화합니다.
3. {{< ui >}}Save RUM Data Collection{{< /ui >}}을 클릭합니다.
4. {{< ui >}}Synthetic Data RUM Applications{{< /ui >}} 아래의 드롭다운 메뉴에서 브라우저 테스트 레코더에 제안된 기본 RUM 애플리케이션을 선택합니다. 
5. {{< ui >}}Save RUM Data Applications{{< /ui >}}를 클릭합니다.

선택적으로 {{< ui >}}Synthetic Tests Default{{< /ui >}}를 클릭한 후 드롭다운 메뉴에서 다른 RUM 애플리케이션을 선택합니다. 이 애플리케이션은 브라우저 테스트 레코딩에 표시됩니다.

자세한 내용은 [Synthetic Monitoring 설정][6]을 참조하세요.

## Synthetic Monitoring에서 RUM Explorer로{#synthetic-monitoring-to-rum-explorer}

[브라우저 테스트 목록][7]으로 이동하여 샘플 테스트 실행을 클릭합니다. 

{{< img src="synthetics/guide/rum_in_synthetics/browser_test_step_side_panel.png" alt="테스트 단계 세부 정보 사이드 패널" style="width:100%;" >}}

단계 세부 정보 사이드 패널이 `This Synthetic test generated data in Real User Monitoring`과 함께 나타나며, 여기에는 세션 ID와 {{< ui >}}Go to the View in RUM{{< /ui >}} 버튼이 포함되어 있습니다. 

{{< img src="synthetics/guide/rum_in_synthetics/generated_rum_data.png" alt="Synthetics Explorer" style="width:80%;" >}}

이 테스트 단계의 오류, 리소스 및 성능 데이터를 [RUM Explorer][3]에서 보려면 {{< ui >}}Go to the View in RUM{{< /ui >}}을 클릭하세요. 또는 {{< ui >}}Replay Session{{< /ui >}} 버튼을 클릭하거나 {{< ui >}}View all sessions in RUM{{< /ui >}}을 클릭하여 브라우저 테스트에서 캡처된 사용 가능한 Session Replay를 탐색하세요.

## RUM Explorer에서 Synthetic Monitoring으로{#rum-explorer-to-synthetic-monitoring}

RUM Explorer에서 [세션 목록][8]으로 이동하여 재생이 가능한 세션을 클릭합니다. 

{{< img src="synthetics/guide/rum_in_synthetics/sessions_details_panel.png" alt="세션 세부 정보 사이드 패널" style="width:100%;" >}}

세션 패널이 `This event was generated by a Synthetic test run`과 함께 나타나며, 여기에는 테스트 ID와 {{< ui >}}View Synthetic Test Result{{< /ui >}} 버튼이 포함되어 있습니다.

{{< img src="synthetics/guide/rum_in_synthetics/synthetic_test_session.png" alt="세션 세부 정보" style="width:80%;" >}}

Synthetic Monitoring 및 테스트 결과로 돌아가려면 {{< ui >}}View Synthetic Test Result{{< /ui >}}를 클릭합니다.
