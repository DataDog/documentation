## 개요 {#overview}

Edit Tags 프로세서는 메트릭의 태그를 추가하거나 이름을 바꿀 수 있습니다. 이 프로세서를 사용하여 메트릭에 추가 컨텍스트를 더하고 중요한 속성 전반에 걸쳐 명명 규칙을 표준화하세요.

다음 태그 및 태그 접두사는 특정 플랫폼 기능을 제공하므로 이름을 바꿀 수 없습니다.

- `host`
- `service`
- `ddsource`
- `function_arn`
- `datadog_*`
- `_dd.*`

## 설정 {#setup}

###  태그 추가 {#add-tag}

**태그 추가**를 사용하여 메트릭에 새 키-값 태그를 추가하세요.

**태그 추가** 작업을 설정하려면 다음 단계를 따르세요.

1. **작업** 드롭다운 메뉴에서 **태그 추가**를 선택합니다.
1. 필터 쿼리를 정의합니다. 쿼리 생성에 대한 자세한 내용은 [메트릭 검색 구문][1]을 참조하세요.
    - 필터와 일치하는 메트릭만 처리됩니다.
    - 모든 메트릭은 필터 쿼리와 일치하는지 여부에 관계없이 파이프라인의 다음 단계로 전송됩니다.
1. 메트릭에 추가할 태그 키와 값을 입력합니다. **참고**: 추가하려는 태그가 이미 존재하는 경우, Worker는 오류를 기록하며 기존 태그는 변경되지 않습니다.

### 태그 이름 바꾸기 {#rename-tag}

**태그 이름 바꾸기**를 사용하여 메트릭의 태그 이름을 바꾸세요.

**태그 이름 바꾸기** 작업을 설정하려면 다음 단계를 따르세요.

1. **작업** 드롭다운 메뉴에서 **태그 이름 바꾸기**를 선택합니다.
1. 필터 쿼리를 정의합니다. 쿼리 생성에 대한 자세한 내용은 [메트릭 검색 구문][1]을 참조하세요.
    - 필터와 일치하는 메트릭만 처리됩니다.



    - 모든 메트릭은 필터 쿼리와 일치하는지 여부에 관계없이 파이프라인의 다음 단계로 전송됩니다.
1. **From** 필드에 이름을 바꿀 태그 키를 입력합니다.
1. **To** 필드에 원래 태그의 새 태그 키를 입력합니다. **참고**: **To** 필드의 태그 키가 이미 존재하는 경우, Worker는 오류를 기록하며 **From** 필드의 태그 키는 이름이 바뀌지 않습니다.
