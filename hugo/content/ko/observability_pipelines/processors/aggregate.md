## 개요 {#overview}

Aggregate 프로세서는 선택한 집계 모드에 따라 동일한 태그 값을 가진 여러 메트릭을 하나의 샘플로 결합합니다. 메트릭을 집계하면 메트릭 볼륨과 비용을 줄이는 데 도움이 될 수 있습니다.

## 설정 {#setup}

Aggregate 프로세서를 설정하려면 다음 단계를 따르세요.

1. 필터 쿼리를 정의합니다. 쿼리 생성에 대한 자세한 내용은 [메트릭 검색 구문][1]을 참조하세요.
    - 필터 쿼리와 일치하지 않는 메트릭은 파이프라인의 다음 단계로 전송됩니다.
    - 쿼리와 일치하는 메트릭은 집계되며, 집계된 메트릭은 파이프라인의 다음 단계로 전송됩니다.
1. **Mode** 드롭다운 메뉴에서 사용할 집계 함수를 선택합니다. 자세한 내용은 [모드](#modes) 섹션을 참조하세요.
1. **Interval** 필드에 메트릭을 집계할 시간 범위를 초 단위로 입력합니다. 최대값은 60초입니다.

## 모드 {#modes}

Aggregate 프로세서는 다음 모드에 따라 여러 메트릭을 하나의 메트릭으로 결합할 수 있습니다. 일부 모드는 증분형 또는 절대형 등 특정 [메트릭 유형][2]에서만 사용할 수 있습니다.

| 모드   | 설명                                                                            | 증분 메트릭 | 절대 메트릭 |
| ------ | -------------------------------------------------------------------------------------- | :-----------------: | :--------------: |
| Auto   | 기본 모드입니다. 증분 메트릭을 합산하고 절대 메트릭에는 최신 값을 사용합니다. | {{< X >}}           | {{< X >}}        |
| Sum    | 메트릭 값을 합산합니다.                                                                | {{< X >}}           |                  |
| Count  | 메트릭이 수신된 횟수를 계산합니다.                                     | {{< X >}}           | {{< X >}}        |
| Latest | 최신 메트릭 값을 반환합니다.                                                       |                     | {{< X >}}        |
| Max    | 최대 메트릭 값을 반환합니다.                                                      |                     | {{< X >}}        |
| Mean   | 평균 메트릭 값을 반환합니다.                                                         |                     | {{< X >}}        |
| Min    | 최소 메트릭 값을 반환합니다.                                                      |                     | {{< X >}}        |
