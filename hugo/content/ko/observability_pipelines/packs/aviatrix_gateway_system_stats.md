## 개요 {#overview}

{{< img src="observability_pipelines/packs/aviatrix_gateway_system_stats.png" alt="Aviatrix Gateway System Stats 팩" style="width:25%;" >}}

Aviatrix Gateway System Stats는 클라우드 게이트웨이별 CPU, 메모리 및 디스크 사용률을 제공합니다.

이 팩의 기능:

- CPU 사용률 추적
- 메모리 압박에 대한 경보 발생
- 디스크 사용량 모니터링
