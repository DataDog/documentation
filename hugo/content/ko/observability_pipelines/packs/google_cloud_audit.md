## 개요 {#overview}

{{< img src="observability_pipelines/packs/google_cloud_audit.png" alt="Google Cloud Audit 팩" style="width:25%;" >}}

Google Cloud Audit logs는 관리자 활동 및 정책 위반을 캡처합니다.

이 팩의 기능

- 주체, 호출자 IP, API 메서드 추출
- IAM, 비밀 및 방화벽 변경사항을 고위험으로 태그 지정
- 일상적인 읽기 전용 작업을 샘플링
