## 개요 {#overview}

{{< img src="observability_pipelines/packs/microsoft_dns.png" alt="Microsoft DNS 팩" style="width:25%;" >}}

이 팩은 클래식 Windows DNS 서버 디버그 텍스트 로그(dns.log)를 구문 분석하고 쿼리 이름과 응답 코드를 디코딩합니다.

이 팩의 기능

- 쿼리 이름 디코딩
- Snd/Rcv 및 RCODE 구문 분석
- 정상 응답 샘플링
