## 개요 {#overview}

{{< img src="observability_pipelines/packs/google_secops_aws_vpc.png" alt="Google SecOps - AWS VPC 팩" style="width:25%;" >}}

이 팩은 AWS VPC 흐름 레코드를 Google Security Operations의 UDM 스키마에 매핑합니다.

이 팩의 기능은 다음과 같습니다.

- VPC 흐름을 UDM에 매핑
- VPC 흐름 판정에서 액션 설정
- IP, 바이트 및 VPC 리소스 매핑
