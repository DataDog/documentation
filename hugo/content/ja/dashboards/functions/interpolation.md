## フィル{#fill}

| 関数 | 説明                                       | 例                                    |
| :----    | :-------                                          | :---------                                 |
| `fill()` | メトリクスに欠落しているメトリクス値を補間します。| `<METRIC_NAME>{*}.fill(<METHOD>, <LIMIT>)` |

`fill()` 関数には 2 つのパラメーターがあります。

* **`METHOD`**: 補間方法として使用する関数。以下から選択します。
    * `linear`: ギャップの最初から最後までを線形補間します。
    * `last`: ギャップの最後の値でギャップを埋めます。
    * `zero`: ゼロ値でギャップを埋めます。
    * `null`: 補間を無効にします。

* `LIMIT`[*任意*、*デフォルト*=**300**、*最大*=**600**]: 補間するギャップの最大サイズを表す補間上限 (秒単位)。

`.fill()` 関数とその補間への影響についての詳しい説明は、[補間とフィル修飾子][1]を参照してください。

## デフォルトゼロ {#default-zero}

| 関数         | 説明                             | 例                          |
| ---------------- | --------------------------------------- | -------------------------------- |
| `default_zero()` | 疎なメトリクスにデフォルト値を追加します。| `default_zero(system.load.1{*})` |

`default_zero()` 関数は、空の時間間隔を値 0 で、補間が有効な場合は補間を使用して埋めます。**注**: `GAUGE` 型のメトリクスの場合、補間はデフォルトで有効になっています。ほとんどの関数と同様に、`default_zero()` は[時間集計とスペース集計][2]の**後**に適用されます。

### ユースケース{#use-cases}

`default_zero()` 関数は、次のユースケースに対応するためのものです (他のユースケースにも対応する可能性があります)。

- 疎なメトリクスに対して算術演算を行う際にゲージを 0 に揃える (注: `COUNT` または `RATE` タイプのメトリクスは、`as_count()` または `as_rate()` としてクエリされると _常に_ 0 に揃えられます。したがって、`default_zero()` を使用しても揃え方は変わりません。影響を受けるのは `GAUGE` タイプのメトリクスのみです)。
- モニターがデータなし状態になる前にモニターのアラートを解消する。これはシンプルアラートとマルチアラートの両方で機能しますが、値 0 によってモニターがトリガーされないようにする必要があります。たとえば、`avg(last_10m):avg:system.cpu.idle{*} < 10` というクエリを使用するモニターの場合、このモニターは 0 と評価されたときに (解消ではなく) トリガーされてしまうため、機能しません。`as_count()` クエリを使用するエラー率モニターには、この関数を使用しないでください。詳細については、[モニター評価での as_count() ガイド][3]を参照してください。
- 視覚的な理由またはモニター評価で時系列の最小値・最大値・平均値に影響を与える目的で、データがまばらな時系列の空の間隔を埋める。
- 時系列ウィジェットで、データがない場合に値 0 を表示する。

### 例{#example}

`default_zero()` 関数の動作を示すために、[DogStatsD を使用して][4]カスタムメトリクス用に作成された次の単一のデータポイントを考えてみましょう。

```text
$ echo -n "custom_metric:1|g" | nc -4u -w0 127.0.0.1 8125
```

このメトリクスを過去 30 分間クエリすると、タイムスタンプは 1 つです。クエリのロールアップ間隔のうち、1 つにしかポイントがないためです。

```text
avg:custom_metric{*}

+---------------------+---------------+
| Timestamp           | custom_metric |
+---------------------+---------------+
| ---------           | ---------     |
| 2019-04-17 17:45:00 | 1             |
+---------------------+---------------+
```

`default_zero()` 関数は、このポイントを 5 分先まで (ゲージの補間上限のデフォルト値) 補間してから、残りの空の間隔を 0 で埋めます。

```text
default_zero(avg:custom_metric{*})

+---------------------+-----------------------------+
| Timestamp           | default_zero(custom_metric) |
+---------------------+-----------------------------+
| ---------           | ---------                   |
| 2019-04-17 17:30:00 | 0                           |
| 2019-04-17 17:31:00 | 0                           |
...
| 2019-04-17 17:44:00 | 0                           |
| 2019-04-17 17:45:00 | 1                           |
| 2019-04-17 17:46:00 | 1                           |
| 2019-04-17 17:47:00 | 1                           |
| 2019-04-17 17:48:00 | 1                           |
| 2019-04-17 17:49:00 | 1                           |
| 2019-04-17 17:50:00 | 1                           |
| 2019-04-17 17:51:00 | 0                           |
| 2019-04-17 17:52:00 | 0                           |
...
+---------------------+-----------------------------+
```
