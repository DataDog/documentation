## 概要{#overview}


Datadog の共有ダッシュボードを使用すると、外部ユーザーやログインを希望しないユーザーがダッシュボードを表示できます。複数の共有ダッシュボードを作成して、それぞれに独自の構成オプションを設定できます。

ダッシュボードを共有するには、ダッシュボードページの右上にある {{< ui >}}Share{{< /ui >}} をクリックし、次に {{< ui >}}Share dashboard{{< /ui >}} をクリックします。既存の共有ダッシュボードを表示または編集するには、{{< ui >}}Share{{< /ui >}} をクリックし、次に {{< ui >}}Manage shared dashboards{{< /ui >}} をクリックします。

{{< img src="/dashboards/sharing/shared_dashboards/manage_modal.png" alt="共有ダッシュボードモーダルの管理の例" style="width:90%;" >}}

組織内のすべての共有ダッシュボードとそのパブリックアクセス設定は、[共有ダッシュボードページ][2]に一覧表示されます。[パブリック共有設定ページ][3]では、特定の共有タイプの無効化や、招待の最大アクセス期間の設定など、追加のセキュリティ構成を追加することもできます。

**注**: 共有ダッシュボード機能が無効になっている場合、ダッシュボードはパブリックにアクセスができなくなります。ただし、その構成は引き続き表示および編集可能です。この機能は、個々のダッシュボードの {{< ui >}}Active{{< /ui >}} ステータスまたは {{< ui >}}Paused{{< /ui >}} ステータスとは独立して動作し、{{< ui >}}Active{{< /ui >}} 共有ダッシュボードであってもパブリックにアクセスができなくなります。

共有ダッシュボードは約 60 秒ごとに更新されます。この[更新間隔][1]をカスタマイズすることはできません。

共有ダッシュボードの閲覧者は、Dashboard に表示されるすべてのテレメトリデータを、[作成者の権限][4]に従って閲覧します。機密情報や秘密情報が公開されないよう、共有前にダッシュボードのコンテンツを確認してください。

## 共有状態 {#share-states}

共有ダッシュボードには、以下の 2 つの共有状態のうちいずれかを設定できます。

{{< ui >}}Active{{< /ui >}}
: 共有ダッシュボードに特定の URL が割り当てられ、ダッシュボードにアクセスするように構成された閲覧者が利用できるようになります。

{{< ui >}}Paused{{< /ui >}}
: 招待された場合でも、閲覧者は共有ダッシュボードにアクセスできません。ただし、共有ダッシュボードの URL はダッシュボードにリンクされたままとなり、ダッシュボードが {{< ui >}}Active{{< /ui >}} にリセットされると以前のアクセス権が復元されます。

**Unsharing** ダッシュボードで共有 URL が削除され、すべての共有構成設定が削除されるため、すべてのリンクが無効になります。ダッシュボードを再共有しても、以前の共有 URL や設定は保持されません。

## 招待制の共有ダッシュボード {#invite-only-shared-dashboards}

招待制のダッシュボードを使用すると、ダッシュボードを個別のメールアドレスや特定のメールドメインと共有できます。

2 つ以上のメールアドレスとダッシュボードを共有するには:

1. 共有するダッシュボードの右上隅にある {{< ui >}}Share{{< /ui >}} オプションをクリックします。
2. {{< ui >}}Share Dashboard{{< /ui >}} を選択します。
3. {{< ui >}}Invite only{{< /ui >}} を選択します。
4. 希望する時間、変数、および色のオプションを構成します。詳細については、[構成オプション](#configuration-options)を参照してください。
5. アクセス権を付与するメールアドレスまたはメールドメインを追加し、各招待の有効期限を設定します。ドメインを追加すると、パブリックアクセスを防ぎ、そのドメインアドレスを持つユーザーのみにダッシュボードへのアクセスを制限できます。
6. {{< ui >}}Share Dashboard{{< /ui >}} をクリックして共有 URL を生成し、特定の招待者にアクセスリンクをメールで送信します。メールは特定のメールアドレスにのみに送信されます。メールドメインの場合、メールは送信されないため、ダッシュボードのリンクを手動で配布する必要があります。

**注**: 招待されたメールアドレスは、有効期限日の午前 0 時 (現地時間) にアクセス権を失います。

デフォルトでは、招待に有効期限はありません。招待に一定期間経過後の有効期限を設けるには、組織管理者が[組織の設定 > パブリック共有][3]で最大アクセス期間を有効にします。この設定が有効になっている場合、招待が有効な最大日数を指定できます。

有効期限のない招待を許可するには、最大アクセス期間をオフにします。API を通じてこの設定を構成する場合は、値を `null` に設定してください。UI で最大アクセス期間を `0` に設定すると、設定がオフになり、値が `null` に設定されます。

**注**: 最大アクセス期間は、正確なタイムスタンプによって実行されます。たとえば、最大アクセス期間が 1 日の場合、1 月 1 日の午前 11 時に作成された招待は、1 月 2 日の午前 11 時に期限切れとなる必要があります。

### 招待制の共有ダッシュボードへのアクセス {#access-an-invite-only-shared-dashboard}

共有ダッシュボードへの招待者には、期限が設定されたアクセスリンクが記載されたメールが送信されます。メールの受信者は、共有ダッシュボードにアクセスするために 1 時間以内にリンクをクリックする必要があります。

{{< img src="/dashboards/sharing/shared_dashboards/invite_only_dashboard_link.png" alt="プライベートダッシュボードのアクセスリンクが記載されたメールによる招待の例" style="width:90%;" >}}

リンクをクリックした後、招待者は同じコンピュータとブラウザで 30 日間、共有ダッシュボードにアクセスできます。その後はアクセスを更新する必要があります。引き続き有効な受信者で、ダッシュボードがアクティブな状態である限り、アクセスを更新し続けることができます。

#### 新しいアクセスリンクの取得 {#get-a-new-access-link}

有効な受信者は、共有者の承認を必要とせず、いつでも新しいアクセスリンクをリクエストできます。アクティブなアクセス権がない状態で共有ダッシュボードにアクセスすると、新しいアクセスリンクを受け取るためにメールアドレスを入力するよう求められます。有効な受信者のみがこのメールを受信することができます。

### 招待制の共有ダッシュボードへのアクセスの取り消し {#revoke-access-to-an-invite-only-shared-dashboard}

共有ダッシュボードへのアクセスを取り消すには、受信者リストから該当するメールアドレスを削除し、変更を保存します。削除された受信者は、アクセス権や新しいアクセスリンクをリクエストする権限を失います。

**注**: 招待制ダッシュボードを共有するユーザーは、引き続き有効な受信者であり、削除することはできません。

## パブリック共有ダッシュボード {#public-shared-dashboards}

パブリックダッシュボードを使用すると、ユーザーはインターネット上のリンクを持っている人なら誰にでも共有ダッシュボードの利用を許可することができます。

パブリックダッシュボードを共有するには:

1. 共有するダッシュボードの右上隅にある {{< ui >}}Share{{< /ui >}} オプションをクリックします。
2. {{< ui >}}Share Dashboard{{< /ui >}} を選択します。
3. {{< ui >}}Select a Share Type{{< /ui >}} ステップで {{< ui >}}Public{{< /ui >}} オプションを選択し、リンクを持っている人なら誰でもダッシュボードにアクセスできることを理解した上で承認します。
4. {{< ui >}}Configure Dashboard{{< /ui >}} ステップで、希望する時間、変数、および色のオプションを構成します。
5. 共有 URL を作成するには、{{< ui >}}Share Dashboard{{< /ui >}} をクリックします。

デフォルトでは、パブリックダッシュボードは 1 年間アクセス可能で、その後期限切れとなり、{{< ui >}}Paused{{< /ui >}} 状態に切り替わります。{{< ui >}}Select a Share Type{{< /ui >}} ステップで、有効期限をオフにするか調整できます。

## 埋め込み共有ダッシュボード {#embedded-shared-dashboards}

共有ダッシュボードは、iFrame を使用して Web サイトに埋め込むことができます。埋め込みダッシュボードには、Basic と Secure の 2 種類があります。

### Basic 埋め込み{#basic-embed}

Basic 埋め込みダッシュボードは、許可リストに登録されたリクエストリファラーに基づいてアクセスを制限します。この機能は、Safari Web ブラウザではサポートされていません。

HTTP リクエストのリファラーヘッダーが、検証のために許可リストに登録されたエントリと照合されます。ほとんどの場合、ブラウザコンソールに `window.location.origin` と入力すると、予想されるリファラーが表示されます。ただし、ブラウザヘッダーで特別な操作 (ブラウザのプライバシー設定など) を行っている場合は、実際のネットワークリクエストを確認してください。

Basic 埋め込みダッシュボードを共有するには:

1. ダッシュボードの右上隅にある {{< ui >}}Share{{< /ui >}} をクリックします。
2. {{< ui >}}Share Dashboard{{< /ui >}} を選択します。
3. {{< ui >}}Select a Share Type{{< /ui >}} ステップで {{< ui >}}Embed{{< /ui >}} オプションを選択します。
4. {{< ui >}}Configure Dashboard{{< /ui >}} ステップで、希望する時間、変数、および色のオプションを構成します。
5. 許可リストに登録するリファラーを追加します。
6. 共有 URL を作成するには、{{< ui >}}Share Dashboard{{< /ui >}} をクリックします。

### セキュアな埋め込み{#secure-embed}

セキュアな埋め込みダッシュボードは、リファラー許可リストに依存する代わりに、バックエンドで生成されたトークンを使用して各ページの読み込みを認証します。アプリケーションサーバーが認証情報を保持し、セッションごとに一意の iFrame URL を生成するため、認証情報がブラウザに公開されることはありません。セキュアな埋め込みは、Safari を含むサードパーティクッキーをブロックするブラウザで機能します。

セットアップ手順については、[セキュアな埋め込みダッシュボード][6]を参照してください。

## 構成オプション {#configuration-options}

{{< img src="/dashboards/sharing/shared_dashboards/configure_shared_dashboard.png" alt="ダッシュボードを共有する構成セクションでは、デフォルトのタイムフレームを「過去 1 時間」と表示し、閲覧者はタイムフレームとデフォルトのライトテーマを変更することができます。" style="width:90%;" >}}

{{< ui >}}Configure Dashboard{{< /ui >}} ステップで共有ダッシュボードに変更を加えます。

**注**: 共有ダッシュボードへの構成変更がすべての閲覧者に反映されるまで、最大 5 分かかる場合があります。変更がすぐに反映されない場合は、数分待ってからダッシュボードを更新してください。

{{< ui >}}Published Name{{< /ui >}}
: 公開名は、共有ダッシュボード上のダッシュボードタイトルに置き換えられます。この名前は、共有ダッシュボードリストページで一覧表示される名前でもあります。

{{< ui >}}Default Timeframe{{< /ui >}}
: これで、共有ダッシュボードの閲覧者に対するデフォルトのタイムフレームが設定されます。「閲覧者によるタイムフレームの変更を許可する」がオフになっている場合、これが唯一利用可能なタイムフレームとなります。これをオンに切り替えると、閲覧者は固定されたタイムフレームオプションから選択できるようになりますが、カスタムタイムフレームやタイムフレームのスクラブはサポートされていません。

{{< ui >}}Variables{{< /ui >}}
: この設定により、ユーザーはダッシュボード上のどのテンプレート変数を閲覧者が利用できるかを指定できます。テンプレート変数に同じデフォルト値と利用可能な値を設定すると、閲覧者はそれを変更できなくなります。<br>**注**: これは、値がワイルドカードに設定されている場合であっても適用されます。<br><br>デフォルトでは、共有ダッシュボードは、共有者が現在使用している選択済みのおよび利用可能な値を継承します。

{{< ui >}}Default Theme{{< /ui >}}
: この設定により、ユーザーは共有ダッシュボードをデフォルトでライトモードとダークモードのどちらで表示するかを選択できます。閲覧者はいつでもこのオプションを上書きできます。

## 共有ダッシュボードに関する制限 {#restrictions-on-shared-dashboards}

### 無効化されたユーザーはダッシュボードを共有することはできません {#dashboards-cannot-be-shared-by-deactivated-users}

共有ダッシュボードは、組織内のアクティブなユーザーに共有される必要があります。共有者が無効化された場合、アクティブなユーザーが所有権を主張するまで、共有ダッシュボードには **データが表示されなくなります**。この状態の間も、共有ダッシュボードの URL と構成オプションは保持されます。

### すべてのウィジェットタイプが利用できるわけではありません {#not-all-widget-types-are-available}

共有ダッシュボードは、以下のテーブルにあるウィジェットタイプをサポートしています。その他のタイプのウィジェットでは、ダッシュボードが共有されるとデータが表示されません。

| カテゴリー | サポートされているウィジェット |
| -------- | ----------------- |
| 時系列およびディストリビューション | 時系列、棒グラフ、ディストリビューション、ヒートマップ、散布図、Sankey |
| 単一値およびサマリー | クエリ値、変更、トップリスト、アラート値、アラートグラフ、サービスサマリー |
| テーブルおよび階層 | テーブル、Treemap、円グラフ、ファネル、保存期間 |
| マップ | ジオマップ、ホストマップ |
| モニターおよび SLO | モニターサマリー、チェックステータス、SLO、SLO リスト |
| テキストおよびメディア | Notes & Links、フリーテキスト、画像、Iframe |
| その他 | イベントタイムライン、Wildcard |

サポートされていないウィジェットを含むダッシュボードを共有してもエラーは発生せず、ダッシュボード API もこれらのウィジェットを拒否しません。ウィジェットはデータなしで共有ダッシュボードに表示されます。

### 制限付きタイムフレームオプション {#limited-timeframe-options}

共有ダッシュボードは、制限付きタイムフレームオプションのみをサポートしており、タイムフレームのスクラブやカスタムタイムフレームは許可されていません。

### IP アドレス制限 {#ip-address-restrictions}

IP アドレスに基づいて、共有ダッシュボードへのアクセスを制限できます。IP アドレスの許可リストを有効にするには、[Datadog サポート][5]にメールでご連絡ください。有効にすると、管理者は[パブリック共有設定ページ][3]で IP 制限を管理できます。

## 共有ダッシュボードの編集 {#edit-shared-dashboards}

<div class="alert alert-danger">ダッシュボードのコンテンツやレイアウトへの変更は、共有されるバージョンに即座に反映されます。意図せず非公開データを共有しないよう、編集時には注意してください。</div>

共有ダッシュボードの共有タイプ、構成、または受信者を変更するには:

1. ダッシュボードの右上隅にある {{< ui >}}Share{{< /ui >}} オプションをクリックします。
2. {{< ui >}}Edit shared dashboard{{< /ui >}} を選択します。
3. 希望する設定を調整します。
4. 変更を有効にするには {{< ui >}}Save{{< /ui >}} をクリックします。

このメニューから、共有ダッシュボードへのアクセスを一時停止または再有効化できます。

## すべての共有ダッシュボードを表示 {#view-all-shared-dashboards}

[共有ダッシュボード][2]ページで、組織内のすべての共有ダッシュボードと設定を表示します。このページでは、共有タイプ、最終アクセス日時、共有者などでダッシュボードをクエリ、フィルタリング、並べ替えできます。所有者のいない共有ダッシュボードを見つけて、所有権を主張することもできます。
