時系列の可視化により、1 つまたは複数のメトリクス、ログイベント、またはインデックス化されたスパンの経時的な変化を表示できます。時間枠は、[タイムボード][1]または[スクリーンボード][2]での選択内容によって異なります。

{{< img src="dashboards/widgets/timeseries/timeseries.png" alt="ホストの平均 system.cpu.user を示す時系列ウィジェット" style="width:90%;" >}}

## セットアップ {#setup}

### 構成 {#configuration}

{{< img src="dashboards/widgets/timeseries/timeseries_setup.png" alt="時系列のセットアップ" style="width:90%;" >}}

1. グラフ化するデータを選択します。
   * メトリクス: メトリクスクエリの構成については、[クエリに関するドキュメント][3]を参照してください。
   * インデックス化されたスパン: インデックス化されたスパンクエリの構成については、[トレース検索に関するドキュメント][4]を参照してください。
   * ログイベント: ログイベントクエリの構成については、[ログ検索に関するドキュメント][5]を参照してください。

2. 利用可能な[オプション](#display-options)を使用してグラフをカスタマイズします。

## 表示オプション {#display-options}

グラフは、折れ線、面、棒として表示できます。Datadog のグラフは、1 時間ごとの合計など、[間隔][15]にわたってデータを集計します。デフォルトでは、時系列グラフの最後の不完全な時間間隔は網掛けされ、[partial data] というラベルが付けられます。

折れ線グラフには、追加のパラメーターがあります。

| パラメーター | オプション                  |
|-----------|--------------------------|
| スタイル     | 実線、破線、または点線 |
| 線の太さ    | 標準、細、または太   |

### 自動ラベル {#automatic-labels}

折れ線グラフは、ピークや谷などの注目すべきデータポイントにラベルを表示するため、グラフにカーソルを合わせなくても主要な値を読み取ることができます。自動ラベルはデフォルトでオンになっています。オフにするには、グラフエディターで {{< ui >}}Show labels{{< /ui >}} を切り替えます。

クエリがタグでグループ化されているか、[エイリアス](#metric-aliasing)がある場合、Datadog は各線の最後のポイントに、ピークや谷ではなく系列名でラベルを付けます。

グラフの読みやすさを維持するため、Datadog は系列ごとに最大 3 つのラベルを表示し、グラフに 7 つ以上の系列がある場合はラベルをまったく表示しません。

### 色 {#color}

すべてのグラフタイプについて、Datadog は同じグラフに表示される複数のメトリクスを区別するために、さまざまな色のオプションを提供しています。

| パレット     | 説明                                                                                                 |
|-------------|-------------------------------------------------------------------------------------------------------------|
| Classic | ライトブルー、ダークブルー、ライトパープル、パープル、ライトイエロー、イエローのシンプルな色 (色は繰り返されます)。   |
| Consistent | 16 色のセットを使用し、タググループごとに、すべてのウィジェットで各データ系列に一貫した色を適用します。|

折れ線グラフの場合、JSON でクエリを分離することで、異なるメトリクスに特定のパレットを割り当てることができます。詳細については、[グラフに適した色の選択][6]のガイドを参照してください。

### 並べ替え {#sorting}

{{< ui >}}Tags{{< /ui >}} または {{< ui >}}Values{{< /ui >}} でグラフを順序付けして、時系列の凡例と積み上げグラフを並べ替えます。これはグラフの視覚化のみを並べ替えるものであり、クエリには影響しません。{{< ui >}}Reverse{{< /ui >}} オプションを切り替えて、アルファベットの逆順または値の降順で並べ替えます。

### メトリクスのエイリアス設定 {#metric-aliasing}

各クエリまたは数式は、[フィルタリングタグ][7]とともにエイリアスを設定できます。エイリアスはグラフと凡例の表示を上書きします。これは、長いメトリクス名や長いフィルターリストに役立ちます。クエリまたは数式の末尾で、{{< ui >}}as...{{< /ui >}} をクリックしてメトリクスのエイリアスを入力します。

{{< img src="dashboards/widgets/timeseries/metric_alias.png" alt="時系列ウィジェットエディターで検索クエリにエイリアスを追加する" style="width:100%;" >}}

### イベントオーバーレイ {#event-overlay}

イベントオーバーレイはすべてのデータソースをサポートします。これにより、ビジネスイベントと Datadog のあらゆるサービスからのデータとの相関を容易にすることができます。

イベントオーバーレイを使用すると、組織内のアクションがアプリケーションやインフラストラクチャーのパフォーマンスにどのような影響を与えるかを確認できます。以下に、使用例をいくつか紹介します。
- デプロイイベントをオーバーレイした RUM エラー率
- CPU 使用率と追加サーバーのプロビジョニングに関連するイベントの相関関係
- 送信トラフィックと不審なログインアクティビティの相関関係
- Datadog に適切なアラートが設定されていることを確認するための、任意の時系列データとモニターアラートの相関関係

{{< img src="/dashboards/querying/event_overlay_example.png" alt="デプロイメントイベントを重ね合わせた RUM のエラーレートを表示する時系列ウィジェット" style="width:100%;" >}}

GitHub コミット、Jenkins デプロイ、Docker 作成イベントなど、関連システムのイベントを追加して、グラフにコンテキストを追加できます。{{< ui >}}Event Overlays{{< /ui >}} セクションの {{< ui >}}Add Event Overlay{{< /ui >}} をクリックし、クエリを入力してそれらのイベントを表示します。

[Event Explorer][8] と同じクエリ形式を使用します。たとえば、次のようになります。

| クエリ                       | 説明                                                |
|-----------------------------|------------------------------------------------------------|
| `sources:jenkins`           | Jenkins ソースからのすべてのイベントを表示します。                 |
| `tag:role:web`              | `role:web` タグが付いたすべてのイベントを表示します。                 |
| `tags:$<TEMPLATE_VARIABLE>` | 選択した[テンプレート変数][9]からのすべてのイベントを表示します。|

### マーカー {#markers}

追加のデータセットのマーカーを追加するには、{{< ui >}}Markers{{< /ui >}} セクションの {{< ui >}}Add Marker{{< /ui >}} をクリックします。

1. 線または範囲を選択し、値または値の範囲を入力します。
2. {{< ui >}}Show as{{< /ui >}} フィールドで、アラートのステータス/色を選択し、実線、太線、または破線の水平線から選択します。
3. 時系列ウィジェットの左下に表示されるラベルを追加するには、{{< ui >}}Label{{< /ui >}} チェックボックスをオンにして、y 軸の値を定義します。

### デュアル y 軸 {#dual-y-axis}

同じグラフ上に複数の y 軸を表示するには、**Add Graph** をクリックします。**Y-axis** ドロップダウンを使用して、リクエストのデータを左軸または右軸に関連付けます。各サイドに任意の数のリクエストを割り当てることができます。

{{< img src="dashboards/widgets/timeseries/dual_y_axis.png" alt="時系列ウィジェットには、左の y 軸に紫色で表示される system.uptime と、右の y 軸にオレンジ色で表示される system.disk.used の 2 つのメトリクスクエリが表示されます。" style="width:100%;" >}}

### y 軸コントロール {#y-axis-controls}

y 軸コントロールは、UI および JSON エディターで使用できます。y 軸の値とタイプは、以下のように設定できます。

* y 軸を特定の範囲にクリップします。
* 絶対値のしきい値に基づいて、y 軸の境界を自動的に変更します。このしきい値は、グラフの一端または両端 (下限および上限) に適用して、「外れ値」の系列を除去できます。
* y 軸のスケールを線形から log、pow、または sqrt に変更します。

以下の構成オプションが利用可能です。

| オプション                | 必須 | 説明                                                                                                                                                                                                               |
|-----------------------|----------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `Min`                 | いいえ       | y 軸に表示する最小値を指定します。デフォルト値として数値または `Auto` を指定できます。                                                                                                               |
| `Max`                 | いいえ       | y 軸に表示する最大値を指定します。デフォルト値として数値または `Auto` を指定できます。                                                                                                                       |
| `Scale`               | いいえ       | スケールのタイプを指定します。指定可能な値は以下のとおりです: <br>- *linear*: 線形スケール (デフォルト)。<br>- *log*: 対数スケール。<br>- *pow*: べき乗スケール (指数のデフォルトは 2。JSON で変更できます)。<br>- *sqrt*: 平方根スケール。|
| `Always include zero` | いいえ       | 常にゼロを含めるか、データ範囲に合わせて y 軸を調整します。デフォルトでは、常にゼロが含まれます。                                                                                                                             |
<div class="alert alert-info">数学的な対数関数は負の値を受け付けないため、Datadog の対数スケールは、値の符号がすべて同じ (すべて > 0、またはすべて < 0). Otherwise, Datadog returns an empty graph.</div>) である場合にのみ機能します。

### 凡例の設定 {#legend-configuration}

{{< ui >}}Legend{{< /ui >}} セクションの以下のオプションから選択することで、スクリーンボードに設定可能な凡例を追加できます。

* Automatic (デフォルト)
* Compact
* Expanded: 値、平均、合計、最小、最大の列を設定可能
* None

タイムボードでは、ダッシュボードが L または XL に設定されている場合、凡例が自動的に表示されます。

### コンテキストリンク {#context-links}

ダッシュボードウィジェット内をクリックしたときに表示されるドロップダウンメニューにコンテキストリンクを追加するには、{{< ui >}}Context Links{{< /ui >}} セクションの {{< ui >}}Add a Context Link{{< /ui >}} をクリックします。

コンテキストリンクの編集と削除の詳細については、[コンテキストリンク][10]を参照してください。

### 全画面 {#full-screen}

[標準の全画面オプション][11]に加えて、クイック関数の適用、y 軸スケールの調整、変更の保存、または新しいグラフとしての保存を行うことができます。

詳細については、[全画面グラフモードでデータを探索][12]を参照してください。

### 時間の比較 {#compare-time}

{{< ui >}}Compare Time{{< /ui >}} タブでは、現在のメトリクスのパフォーマンスを過去の期間と比較して、変化を一目で確認できます。これは、システム負荷の急増を調査する場合や、デプロイの影響を検証する場合に使用します。

{{< ui >}}Compare Time{{< /ui >}} タブを開くには、ウィジェットコントロールオプションの展開アイコンをクリックしてウィジェットをインスペクトモードで開き、{{< ui >}}Compare Time{{< /ui >}} をクリックします。

このタブには 2 つのグラフが表示されます。
- {{< ui >}}Current{{< /ui >}}: アクティブな時間枠のメトリクスデータ。時間範囲のドロップダウンと再生コントロールを使用して、時間枠を調整します。
- {{< ui >}}Previous{{< /ui >}}: 比較期間。オフセットを設定するには、{{< ui >}}Period{{< /ui >}}、{{< ui >}}Day{{< /ui >}}、{{< ui >}}Week{{< /ui >}}、{{< ui >}}Month{{< /ui >}}、または {{< ui >}}Custom{{< /ui >}} を選択します。

両方の期間を同じグラフで表示するには、{{< ui >}}Overlay{{< /ui >}} をクリックします。並列表示に戻るには、{{< ui >}}Grid{{< /ui >}} をクリックします。

### メトリクス情報 {#metrics-info}

メトリクスグラフ上でコンテキストメニュー (3 つの縦ドット) をクリックすると、[{{< ui >}}Metrics Info{{< /ui >}}] オプションが見つかります。これにより、メトリクスの説明が記載されたパネルが開きます。このパネルでメトリクス名をクリックすると、そのメトリクスが Metrics Catalog ページで開き、詳細な分析や編集を行うことができます。
