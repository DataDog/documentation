## 概要{#overview}

ウィジェット構成は、インフラストラクチャーやアプリケーションに関する有意義なインサイトを提供する効果的なダッシュボードを作成するために不可欠です。このガイドでは、ウィジェットを設定する際に理解しておくべき主要な構成オプションと考慮事項について説明します。


## 全画面 {#full-screen}

全画面モードでは、ウィジェットの表示および分析機能が強化されます。ほとんどのウィジェットをフルスクリーンモードで表示し、以下の操作を行うことができます。

* タイムフレームの変更
* 選択したタイムフレームだけ前後に移動する
* 現在の時間にグラフを一時停止するか、ライブグラフを表示する
* タイムフレームをリセットする
* ダッシュボードやノートブックにグラフをエクスポートしたり、クエリをコピーしたりする
* グラフを生成するデータを CSV 形式でダウンロードする

ウィジェットの概要に直接アクセスするには、ウィジェットの右上にあるフルスクリーンボタンをクリックします。

[時系列ウィジェット][1]では追加のオプションが利用可能です。

## データプレビュー {#data-preview}

グラフエディターで複数のデータソースを結合し、追加のコンテキストやメタデータで視覚化をエンリッチできます。データプレビューを使用すると、結合するデータの内容と、クエリが期待どおりに機能しているかを確認できます。この機能は、以下の目的で役立ちます。

- データ構造と列名を確認する
- 一致するキーを特定する
- クエリ全体を実行する前に結果を検証する

{{% collapse-content title="例" level="h3" expanded=false %}}
支払いログを製品詳細を含む参照テーブル (ルックアップテーブル) と結合して、トランザクションデータと並べて販売価格やリリース日を表示することができます。または、Salesforce や Snowflake などの外部ソースからの顧客情報と RUM セッションデータを結合して、顧客層ごとにユーザーをセグメント化することで、RUM セッションデータをエンリッチすることもできます。

結合がサポートされているデータソースには、以下が含まれます (ただし、これらに限定されません)。

- ログ
- メトリクス
- RUM
- Cloud Cost Recommendations
- Netflow
- APM スパン
- APM トレース
- プロファイル
- Synthetics CI バッチ
- Synthetics 実行
- 静的分析
- CI テスト
- Compliance 検出結果
- Product Analytics
- リファレンステーブル

結合とデータプレビューを使用すると、適切なフィールドを選択して関連する詳細情報でグラフをエンリッチしやすくなり、ダッシュボードの品質と有用性が向上します。

## カスタムリンク {#custom-links}

カスタムリンクは、ウィジェットのデータ値を Datadog ページや AWS コンソールなどの関連 URL に接続することで、データインタラクションを強化します。

一般的なウィジェットのインラインデータとのインタラクションをカスタマイズするには、「[コンテキストリンク][2]」を参照してください。

## ウィジェットの説明 {#widget-descriptions}

ウィジェットの説明を使用すると、ダッシュボードの任意のウィジェットにテキストの説明を追加できます。説明を使用して、メトリクスが何を表しているか、どのように解釈するか、どのようなアクションをとるべきかなど、メトリクスに関するコンテキストを提供します。

説明を追加するには、以下を行います。
1. ウィジェットのグラフエディターを開きます。
2. エディターの下部で [**Description**] を入力します。
3. [**Save**] をクリックします。

保存後、ウィジェットの左上隅にある説明アイコンにカーソルを合わせると、説明が表示されます。

## メトリクス情報 {#metrics-info}

メトリクスグラフ上でコンテキストメニュー (縦に並んだ 3 つの点) をクリックすると、{{< ui >}}Metrics Info{{< /ui >}} オプションが見つかります。これにより、メトリクスの説明が記載されたパネルが開きます。このパネルでメトリクス名をクリックすると、メトリクスの概要ページでメトリクスが開き、詳細な分析や編集を行うことができます。

## 単位のオーバーライド {#unit-override}

単位のオーバーライドは、ウィジェット上のデータ値の表示方法をカスタマイズし、データに意味のあるコンテキストを追加できる重要な表示オプションです。その他のユースケースや詳細については、「[単位のオーバーライドで視覚化をカスタマイズする][3]」を参照してください。
- {{< ui >}}Unit override{{< /ui >}}:「メモリ」系の単位で表示するよう選択すると、Datadog がデータに応じて適切なスケール (メガバイトやギガバイトなど) で表示します。
- {{< ui >}}Unit and scale override{{< /ui >}}: 単位を単一のスケールに固定します (値に関係なくデータをメガバイトで表示)。
- {{< ui >}}Define custom units{{< /ui >}}: 完全にカスタムの単位 (一般的なカウントの代わりに「テスト」など) を定義します。

これは、データに単位を割り当てるための代替手段ではありません。

## グローバルタイムセレクター {#global-time-selector}

グローバルタイムセレクターは、ダッシュボード上のすべてのウィジェットを同じ時間枠に同期させるための基本的な時間設定オプションです。グローバルタイムセレクターを使用するには、少なくとも 1 つの時間ベースのウィジェットを `Global Time` に設定する必要があります。ウィジェットエディターの {{< ui >}}Set display preferences{{< /ui >}} で選択するか、ウィジェットを追加します (デフォルトの時間設定はグローバルタイムです)。

グローバルタイムセレクターは、同じダッシュボード上で `Global Time` オプションを使用しているすべてのウィジェットに対して、同じ時間枠を設定します。過去の移動ウィンドウ (例: `Past 1 Hour` または `Past 1 Day`) を選択するか、`Select from calendar…` オプションを使用して固定期間を選択するか、[カスタム時間枠を入力][8]します。移動ウィンドウを選択した場合、ウィジェットは時間ウィンドウに合わせて更新されます。

グローバルタイムにリンクされていないウィジェットは、グローバルウィンドウを基準に適用されたローカル時間枠のデータを表示します。たとえば、グローバルタイムセレクターを 2019 年 1 月 1 日から 2019 年 1 月 2 日に設定した場合、ローカル時間枠を `Past 1 Minute` に設定したウィジェットには、2019 年 1 年 2 日の 23:59 からの最後の 1 分間のデータが表示されます。

## ウィジェットのコピーと貼り付け {#copy-and-paste-widgets}

コピーと貼り付け機能は、Datadog のさまざまなコンテキストや外部ツール間でウィジェットを再利用できるようにする、重要な共有およびコラボレーション機能です。

<div class="alert alert-info">Datadog の外部でリンクプレビュー付きのウィジェットを共有するには、管理者が組織設定で <a href="https://app.datadoghq.com/organization-settings/public-sharing/settings"><strong>Widget Share URLs</strong></a> を Public または Private に設定する必要があります。管理者はこの設定を無効にして、ユーザーがウィジェットの共有リンクやプレビューを生成できないようにすることができます。</div>

[[Dashboards][4]]、[[Notebooks][5]]、[[APM Service][6]] および [[APM resource][7]] ページでは、<kbd>Ctrl</kbd>/<kbd>Cmd</kbd> + <kbd>C</kbd> を使用するか、共有アイコンを選択して [Copy] を選ぶことで、ウィジェットをコピーできます。

コピーされたウィジェットは、次の場所で <kbd>Ctrl</kbd>/<kbd>Cmd</kbd> + <kbd>V</kbd> を使用して Datadog 内に貼り付けることができます。

* **Dashboards**: マウスカーソルの下に新しいウィジェットを追加します。
* **Notebooks**: ノートブックの最後に新しいセルを追加します。

リンクプレビューを表示するお気に入りのチャットプログラム (Slack や Microsoft Teams など) にウィジェットを貼り付けることもできます。組織の Widget Share URLs モードに応じて、グラフのパブリックプレビュー画像、または Slack 内のプライベートプレビュー画像が、ウィジェットへの直接リンクとともに表示されます。詳細については、「[Widget Share URLs][11]」を参照してください。

## ウィジェットのグループ {#groups-of-widgets}

Timeboard グループのウィジェットをコピーするには、グループウィジェット領域にカーソルを合わせて <kbd>Ctrl</kbd>/<kbd>Cmd</kbd> + <kbd>C</kbd> を使用するか、共有アイコンを選択して [Copy] を選択します。

**注**: グラフをスクリーンボードまたはノートブックに貼り付けると、Datadog はグループ内の各ウィジェットを個別に貼り付けます。

複数のスクリーンボードウィジェットをコピーするには (編集モードのみ)、<kbd>Shift</kbd> + クリックでウィジェットを選択し、<kbd>Ctrl</kbd>/<kbd>Cmd</kbd> + <kbd>C</kbd> を使用します。

**注**: これは Datadog 内で共有する場合にのみ機能します。プレビュー画像は生成されません。

## ウィジェットグラフメニュー {#widget-graph-menus}

ウィジェットグラフメニューには、重要なデータ操作オプションが用意されています。グラフにカーソルを合わせると、以下のメニューオプションにアクセスできます。

### 全画面で表示 {#view-in-full-screen}

グラフを[全画面モード](#full-screen)で表示します。

### エクスポート {#export}

ダッシュボードグラフのエクスポートアイコンをクリックすると、オプションメニューが開きます。

| オプション         | 説明                               |
|----------------|-------------------------------------------|
| Copy           | ダッシュボードグラフのコピーを作成します。    |
| Share snapshot | グラフのスナップショットを作成して送信します。|

#### Datadog 内で使用 {#use-within-datadog}

| オプション           | 説明                                        |
|------------------|----------------------------------------------------|
| Declare incident | グラフからインシデントを宣言します。               |
| Add to incident  | 既存のインシデントにグラフを追加します。            |
| Create case      | グラフからケースを作成します。                     |
| Save to notebook | グラフをノートブックに保存します。                     |
| Link to widget   | ウィジェットへのリンクを取得し、クリップボードにコピーします。|

#### 外部共有 {#share-externally}

| 形式          | 説明                        |
|-----------------|------------------------------------|
| Download as PNG | ウィジェットを PNG 形式でダウンロードします。|
| Download as SVG | ウィジェットを SVG 形式でダウンロードします。|
| Download as CSV | ウィジェットを CSV 形式でダウンロードします。「[ウィジェットデータを CSV にエクスポート](#export-widget-data-to-csv)」セクションを参照してください。|

### 編集 {#edit}

ダッシュボードグラフの鉛筆アイコンをクリックして編集します。

### その他のオプション {#additional-options}

ダッシュボードグラフのコンテキストメニュー (縦に並んだ 3 つのドット) をクリックすると、オプションメニューが開きます。

| オプション                            | 説明                                                                                                                |
|-----------------------------------|----------------------------------------------------------------------------------------------------------------------------|
| Edit                              | グラフを編集します。                                                                                                           |
| Clone                             | グラフを複製し、元のグラフの隣に配置します。                                                                                     |
| Split graph                       | [[split graph][10]] を作成します。                                                                                               |
| Create custom links               | [カスタムリンク](#custom-links)を作成します。                                                                                     |
| Create monitor                    | グラフのクエリで事前設定されたモニターを作成します。                                                                    |
| メトリクス情報 (メトリクスグラフのみ) | このグラフ内のメトリクスの説明を取得します。メトリクス名をクリックすると、[Metric Summary] ページで開くことができます。|
| Delete                            | グラフを削除します。                                                                                                         |

## ウィジェットデータを CSV にエクスポート {#export-widget-data-to-csv}

単一ウィジェットの背後にあるデータを CSV ファイルとしてダウンロードするには、ウィジェットのエクスポートアイコンをクリックして [{{< ui >}}Download as CSV{{< /ui >}}] を選択します。[全画面モード](#full-screen)でウィジェットを表示しているときにも、CSV データをダウンロードできます。

CSV エクスポートは、以下のウィジェットタイプで利用できます。

* 棒グラフ
* リスト
* 円グラフ
* 散布図
* テーブル
* 時系列
* トップリスト
* Treemap

**注**: CSV エクスポートは一度に 1 つのウィジェットに対して機能します。ダッシュボード上のすべてのウィジェットのデータを 1 つのファイルにエクスポートすることはできません。

CSV エクスポートはデフォルトで有効になっています。サポートされているウィジェットに [{{< ui >}}Download as CSV{{< /ui >}}] が表示されない場合、Datadog サポートが組織の CSV エクスポートを無効にしている可能性があります。この制限は組織内のすべてのユーザーに適用され、ダッシュボードウィジェットだけでなく、他の Datadog 製品の CSV エクスポートにも適用されます。この設定は Datadog UI から変更することはできません。CSV エクスポートを無効化または再有効化するには、[Datadog サポート][12]にお問い合わせください。
