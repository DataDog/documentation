ヒートグリッドウィジェットは、タグでグループ化された時系列データを表示します。各グループは独自の行として表示され、値は色でエンコードされます。これにより、グループの数が多い場合でも、変化を見つけたりグループを直接比較したりすることが容易になります。

## セットアップ {#setup}

### 構成 {#configuration}

1. クエリを設定し、行間で比較したいタグでグループ化します。クエリ結果の各グループは、グリッド内の独自の行として表示されます。
   {{< img src="dashboards/widgets/heatgrid/heatgrid_colors.png" alt="並べ替え、行ラベルの幅、凡例、および色のオプションを示すヒートグリッド設定パネル。" style="width:90%;">}}
1. {{< ui >}}Sort rows by{{< /ui >}}: 行を**平均値**、**最大値**、**最小値**、**値の合計**、または**ラベル**で、昇順または降順に並べ替えます。
1. {{< ui >}}Colors{{< /ui >}}: クエリの値をどのように行の色にマッピングするかを設定します。
   - {{< ui >}}Scheme{{< /ui >}}: プリセットの配色を選択するか、**ストップの書式設定**で個々のストップの色や位置を編集してカスタマイズします。
   - {{< ui >}}Apply as{{< /ui >}}: **連続グラデーション**を選択して値を滑らかなカラースケールにマッピングするか、**離散条件**を選択して値の範囲を特定の色にマッピングします。
   - カスタムグラデーションの場合は、スケールに沿ってストップを追加し、それぞれに色と位置（0〜100%）を設定します。
   - カスタム離散条件の場合は、各条件の色と値の範囲（下限と上限）を定義します。最初の条件には下限がなく、最後の条件には上限がないため、条件を合わせることで値の全範囲をカバーします。**注**: 最初のバケットの下限はデータ全体の最小値であり、最後のバケットの上限は最大値です。
   - 各グラデーションまたは離散条件のセットは、2〜6個のストップまたは条件をサポートしています。
1. {{< ui >}}Row label width{{< /ui >}}: プリセットサイズを使用して、行ラベル列の特定の幅を選択します。デフォルトでは、Datadogはラベルが表示されている幅に最も近いサイズを選択します。
1. {{< ui >}}Show legend label{{< /ui >}}: 凡例ラベルの表示・非表示を切り替えます。

### オプション {#options}

#### 単位のオーバーライド {#unit-override}

グリッドやツールチップに表示される単位を設定します。

#### コンテキストリンク {#context-links}

[Context links][1] はデフォルトで有効になっています。オン/オフを切り替えることができます。コンテキストリンクは、ダッシュボードウィジェットと他のページ（Datadog 内またはサードパーティ）を結び付けます。
