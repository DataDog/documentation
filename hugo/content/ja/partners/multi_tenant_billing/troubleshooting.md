## トライアル組織の作成に失敗する、またはエラーが返される {#trial-org-creation-fails-or-returns-an-error}

{{< ui >}}Trial Org Provisioning{{< /ui >}} フォームを再送信してください。エラーが解決しない場合は、失敗したトライアル組織の名前およびリージョンとともに [partner-support@datadoghq.com][1] までご連絡ください。

## 顧客組織が管理組織の下に表示されない {#a-customer-org-isnt-appearing-under-an-admin-org}

顧客組織の契約にパートナーシップが含まれており、かつ有効である場合、その顧客組織は自動的にパートナーの管理組織に接続されます。顧客の組織が見つからない場合は、[partner-support@datadoghq.com][1] までご連絡ください。

## トライアル組織のプロビジョニングが利用できない {#the-trial-org-provisioning-page-isnt-available}

この機能は管理組織で有効になっている必要があります。有効にするには、[partner-support@datadoghq.com][1] までご連絡ください。

## パートナーが新しい管理組織に招待されていない {#a-partner-isnt-invited-to-a-new-admin-org}

管理組織が作成された後もパートナーが招待されない場合は、[partner-support@datadoghq.com][1] までご連絡ください。

## 追加サポート {#further-help}

上記で説明されていない問題については、[partner-support@datadoghq.com][1] までご連絡ください。管理組織 ID または名前、該当する場合はトライアル組織 ID または顧客組織 ID を含めてください。

[1]: mailto:partner-support@datadoghq.com
