## 概要 {#overview}

検出結果により、[ログエクスプローラー][1] での調査中に重要なコンテキストをキャプチャ、整理、再利用できます。

検出結果を使用して証拠を収集し、結果を比較し、調査の進展に合わせてコンテキストを構築します。検出結果をチェックポイントとして保存することで、以前の状態に戻ったり、有用なクエリやログを再確認したりできます。検出結果を整理して調査経路を視覚化して記憶し、検出結果にメモを追加して観察した内容を記録します。また、検出結果をコンテキストとして使用して [Bits に質問][2] したり、[ノートブック][3] に検出結果を追加して他のユーザーと共有するレポートを作成したりすることもできます。

[**Add Finding**] (検出結果を追加) ボタンまたは **Cmd**/**Ctrl** + **S** キーボードショートカットを使用して、ログの行、視覚化、クエリを検出結果として保存します。ログエクスプローラーの検出結果に戻るには、**ダブルクリック**するか、または [**Open in Explorer**] (エクスプローラーで開く) を使用します。以前の観察結果や調査経路を把握した状態で、新しい質問に分岐します。

## [Findings] (検出結果) パネル {#findings-panel}

[Findings] (検出結果) は、ログエクスプローラーの左側のサイドパネルに表示されます。開くには、次のようにします。

1. [ログエクスプローラー][1] に移動します。
2. 左上の [**Findings**] (検出結果) タブをクリックします。

[Findings] (検出結果) パネルでは、検出結果を操作します。検出結果の整理、ログエクスプローラーでの再オープン、他の場所へ送信する検出結果の選択などを行います。このパネルに表示される検出結果とそのレイアウトは、検出結果が削除されるまで、ページのリロードやブラウザセッションをまたいで保持されます。

## 検出結果のキャプチャ{#capture-a-finding}

ログエクスプローラー内の任意の位置で **Cmd**/**Ctrl** + **S** を押すことで、検出結果を追加できます。これにより、クエリ、戻るページ、表示されていた絶対時間範囲がキャプチャされます。デフォルトのタイトルの名前を変更するには、[Findings] (検出結果) パネルの検出結果カードの右上隅にある [{{< ui >}}Edit{{< /ui >}}] (編集) をクリックします。各検出結果カードの下部にメモを追加することもできます。

### クエリと視覚化{#queries-and-visualizations}

結果の上にあるツールバーで [{{< ui >}}Add Finding{{< /ui >}}] (検出結果を追加) ボタンをクリックするか、**Cmd**/**Ctrl** + **S** を押します。[Findings] (検出結果) パネルの [{{< ui >}}Add current page as a finding{{< /ui >}}] (現在のページを検出結果として追加) をクリックすることもできます。

[**Add Finding**] (検出結果を追加) ボタンは、すべての視覚化で同じ場所に表示されます。

検出結果には、検索クエリ、時間範囲、および [視覚化][4] (構成したグループ化や集計など) が格納されます。

{{< img src="logs/explorer/findings/add_finding_timeseries_viz.png" alt="結果ツールバーの [Add Finding] (検出結果を追加) ボタン。キーボードショートカットを示すツールチップが表示されています。" style="width:80%;" >}}

### 個別のログイベント{#individual-log-events}

結果内のログイベントをクリックすると、[ログサイドパネル][5] が開きます。[**Log Message**] (ログメッセージ) セクションにカーソルを合わせ、[{{< ui >}}Add a finding{{< /ui >}}] (検出結果を追加) ボタンをクリックするか、**Cmd**/**Ctrl** + **S** を押します。これにより、後で戻ることができるようにログイベントサイドパネル全体がキャプチャされます。

ログイベントをキャプチャすると、そのログサイドパネルを生成したクエリもキャプチャされます。検出結果に戻ると、対応するクエリを背景に保持した状態でログサイドパネルが再度開きます。

{{< img src="logs/explorer/findings/add_finding_log_message.png" alt="ログサイドパネルの [Log Message] (ログメッセージ) セクションにある [Add Finding] (検出結果を追加) ボタン" style="width:80%;" >}}

### ログメッセージまたは属性内の特定のテキスト{#specific-text-in-a-log-message-or-attributes}

ログメッセージの一部をキャプチャするには、[**Log Message**] (ログメッセージ) セクションでテキストを選択し、**Cmd**/**Ctrl** + **S** を押します。選択したテキストに表示されるコンテキストメニューから [{{< ui >}}Add Finding{{< /ui >}}] (検出結果を追加) を選択することもできます。

属性値をキャプチャするには、テキストを選択して **Cmd**/**Ctrl** + **S** を押します。

どちらの場合も、選択したテキストが検出結果に保存されます。検出結果を使用してログイベントのサイドパネルに戻ることができます。

## 検出結果に戻る {#return-to-a-finding}

検出結果を**ダブルクリック**してログエクスプローラーのその検出結果に戻るか、検出結果にカーソルを合わせて [{{< ui >}}Open in Explorer{{< /ui >}}] (エクスプローラーで開く) をクリックします。ログエクスプローラーは、検出結果がキャプチャされたときのクエリ、時間範囲、および視覚化を再読み込みします。

各検出結果は、クエリと絶対時間範囲を保持します。ログエクスプローラーでは、必要に応じて何度でも検索を変更できます。クエリを再構築せずに、以前の検出結果に戻ることができます。

## Bits AI および Notebooks への検出結果の送信 {#send-findings-to-bits-ai-and-notebooks}

</div>
{{% /site-region %}}

一括で操作する 1 つ以上の検出結果を選択します。

- 検出結果について [Bits Chat][2] に質問するには、選択バーに質問を入力して [{{< ui >}}Ask Bits{{< /ui >}}] (Bits に質問) をクリックします。[Findings] (検出結果) パネルの下部にあるメニューの [{{< ui >}}Ask Bits{{< /ui >}}] (Bits に質問) をクリックすることもできます。選択した検出結果がコンテキストとして添付された状態で Bits Chat が開きます。
- 検出結果を [ノートブック][3] に追加するには、[{{< ui >}}Open in Notebooks{{< /ui >}}] (Notebooks で開く) をクリックします。新規または既存のノートブックを選択します。

質問に関連する検出結果のみを送信します。たとえば、パネルに表示されている 8 つの検出結果のうちの 3 つが、質問するエラーに関連している場合は、その 3 つを選択します。検出結果に関するメモも送信されます。

## 検出結果の整理 {#organize-your-findings}

検出結果を移動またはサイズ変更するには、検出結果ドラッグします。構築したレイアウトが Datadog により保存されため、次にパネルを開いたときも同じように整理された状態で表示されます。

整理した状態をリセットするには、自動整理オプションを使用します。これにより、検出結果がその生成元のクエリごとにグループ化されます。同じクエリから異なる視覚化を作成した場合や、そのクエリから特定のログ行を保存した場合は、それらの検出結果がグループ化されます。検出結果の移動、サイズ変更、または削除を行うと、背景の視覚的なグループ化表示が削除されます。

## 検出結果の削除 {#delete-findings}

1 つの検出結果を削除するには、その上にカーソルを合わせ、カードの右上隅にある削除ボタンをクリックします。検出結果を選択して **Delete** キーを押すこともできます。複数の検出結果を一括削除するには、検出結果を選択して **Delete** を押します。すべての検出結果を選択するには、**Cmd**/**Ctrl** + **A** を押します。

[Findings] (検出結果) パネルのすべてクリアボタンをクリックすると、すべての検出結果が削除されます。

削除した検出結果を復元するには、表示されるメッセージ内の [{{< ui >}}Undo{{< /ui >}}] (元に戻す) をクリックするか、**Cmd**/**Ctrl** + **Z** を押します。

## キーボードショートカット {#keyboard-shortcuts}

| 操作 | ショートカット |
| ------ | -------- |
| 検出結果を追加する | **Cmd**/**Ctrl** + **S** |
| すべての検出結果を選択する | **Cmd**/**Ctrl** + **A** |
| 選択した検出結果を削除する | **Delete** |
| 元に戻す | **Cmd**/**Ctrl** + **Z** |
| やり直す | **Cmd**/**Ctrl** + **Shift** + **Z** |
| パン | **Space** + **ドラッグ** |
| クエリごとに自動的に整理する | **Cmd**/**Ctrl** + **O** |
