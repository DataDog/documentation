## 概要{#overview}

サービスアカウントは、チーム間で共有されるアプリケーションキーやその他のリソースを所有するために使用できる非対話型アカウントです。サービスアカウントのアプリケーションキーは、キーを作成した本人のみ一度だけ表示できます。

たとえば、自社の従業員が個人のアプリケーションキーを使用して、Datadog API にリクエストを送信する自動スクリプトを設定したとします。その従業員が退職する際に従業員の Datadog アカウントを無効化すると、そのアプリケーションキーは機能しなくなります。自動スクリプトも、誰かが有効なアプリケーションキーで更新するまで機能を停止します。Datadog API への自動リクエストに個人のアプリケーションキーではなくサービスアカウントのアプリケーションキーを使用することで、この問題を回避できます。

## ナビゲーション {#navigation}

サービスアカウントは、[組織の設定][1]に存在します。

UI でサービスアカウントにアクセスするには、次のようにします。

1. アカウントメニューから [{{< ui >}}Organization Settings{{< /ui >}}] (組織設定) に移動します。
2. [{{< ui >}}Accounts{{< /ui >}}] (アカウント) で、[{{< ui >}}Service Accounts{{< /ui >}}] (サービスアカウント) を選択します。

[[Service Accounts] ページ][2]には、組織内のすべてのサービスアカウントが一覧表示されます。Datadog Admin ロールを持つユーザーを含め、Service Account Write 権限を持つユーザーは、サービスアカウントを作成できます。Service Account Write 権限がないユーザーには、読み取り専用のビューが表示されます。

### サービスアカウントを表示する {#view-service-accounts}

デフォルトでは、[Service Accounts] ページにはアクティブなサービスアカウントのみが表示されます。以下のリストに無効なサービスアカウントを含めるには、[{{< ui >}}Disabled{{< /ui >}}] (無効) を選択します。

ページの上部にある検索ボックスを使用して、サービスアカウントをフィルタリングします。このフィルターでは、名前、メールアドレス、およびロールのフィールドが検索されます。

アカウントをクリックすると、以下の情報を含む詳細なサイドパネルビューにアクセスできます。

- ステータス (有効または無効)
- 作成日および最終修正日
- ロール
- アプリケーションキー
- 権限

### サービスアカウントを作成する {#create-service-account}

サービスアカウントを作成するには、次の手順を実行します。

1. [{{< ui >}}New Service Account{{< /ui >}}] (新規サービスアカウント) をクリックします。ダイアログボックスが表示されます。
2. サービスアカウントの名前とメールアドレスを入力します。
3. [{{< ui >}}Assign Roles{{< /ui >}}] (ロールの割り当て) ドロップダウンメニューを使用して、サービスアカウントのロールを 1 つ以上選択します。
4. 保存するには、[{{< ui >}}Create Service Account{{< /ui >}}] (サービスアカウントの作成) をクリックします。

Datadog ユーザーのメールアドレスとは異なり、サービスアカウントのメールアドレスは、組織全体で一意である必要はありません。

### サービスアカウントを編集する {#edit-service-account}

サービスアカウントを変更するには、サービスアカウント一覧でクリックします。

1. サイドパネルで、サービスアカウント名の横にある [{{< ui >}}Edit{{< /ui >}}] (編集) をクリックします。ダイアログボックスが表示されます。
2. 変更するフィールドを更新します。名前、メールアドレス、ステータス、ロールを編集できます。
3. [{{< ui >}}Save{{< /ui >}}] (保存) をクリックします。

サービスアカウントを無効にするには、Service Account Write に加えて User Manage Access 権限が必要です。

サービスアカウントを無効にするには、前述の手順に従ってそのサービスアカウントを編集し、ステータスを [{{< ui >}}Disabled{{< /ui >}}] に設定します。

### サービスアクセストークン {#service-access-tokens}

[SAT (サービスアクセストークン)][4] は、サービスアカウントからの Datadog API 呼び出しを認証するための
推奨される方法です。SAT にはスコープが設定されており、必要に応じて長い有効期間を設定することができ、スタンドアロンです。API キーは必要ありません。

サービスアカウントの SAT を作成するには、次のようにします。

1. [[**Organization Settings**] > [**Service Accounts**]][2] に移動し、サービスアカウントをクリックします。詳細パネルが表示されます。
2. [**Access Tokens**] (アクセストークン) で、[{{< ui >}}\+ New Token{{< /ui >}}] (+ 新規トークン) をクリックします。
3. 「[サービスアクセストークンを作成する][5]」の手順に従います。

**注:** サービスアカウントごとに最大 500 個の SAT を作成できます。

### アプリケーションキーを作成するまたは失効させる {#create-or-revoke-application-keys}

サービスアカウントのアプリケーションキーを作成する、または失効させるには、サービスアカウントの一覧からアカウントを選択します。サービスアカウントのサイドパネルが表示されます。

アプリケーションキーを新規に作成する場合は、以下の手順で行います。

- [{{< ui >}}New Key{{< /ui >}}] (新規キー) をクリックします。ダイアログボックスが表示されます。
- キーにわかりやすい名前を付けます。
- [{{< ui >}}Create Key{{< /ui >}}] (キーの作成) をクリックします。

ダイアログボックスが更新され、キーが表示されます。キーをコピーして、目的の場所に貼り付けます。ダイアログボックスを閉じると、キーの値を取得できなくなります。

{{< site-region region="ap2,gov,gov2" >}}
<div class="alert alert-danger">サービスアカウントのアプリケーションキーは、一度のみ読み取り可能です。アプリケーションキーは、作成後すぐに、安全性が確保される方法で保管してください。キーのシークレットを後で取得することはできません。</div>
{{< /site-region >}}

アプリケーションキーを失効させるには、サービスアカウントの詳細ビューのサイドパネルでキーを見つけて、カーソルを合わせます。右側に鉛筆アイコンとゴミ箱アイコンが表示されます。ゴミ箱アイコンをクリックすると、キーを失効させることができます。キーが失効したら、[{{< ui >}}Confirm{{< /ui >}}] (確認) をクリックします。

Datadog API でサービスアカウントを利用する場合は、[サービスアカウント API リファレンス][3]を参照してください。

## サービスアカウントのアプリケーションキー {#service-account-application-keys}

サービスアカウントのアプリケーションキーは、作成直後に一度のみ表示することができます。アプリケーションキーへのアクセスを制限することで、他のユーザーがキーにアクセスした際に発生する可能性がある問題を防止できます。サービスアカウントのキーを紛失した場合、または忘れた場合は、そのキーを失効させてから新しいキーを作成してください。

## 権限 {#permissions}

サービスアカウントを作成すると、ユーザーの代わりに Datadog とやり取りするアクターが作成されます。[Service Accounts] ページで実行できる操作は、お持ちの Datadog のロールと権限によって異なります。

サービスアカウントを作成するには、Service Account Write 権限が必要です。Datadog Admin ロールには Service Account Write が含まれているため、Datadog Admin ロールを持つユーザーは誰でもサービスアカウントを作成できます。

サービスアカウントを作成する際、自身が持つロールと権限の任意のサブセットを付与できます。例外として、User Access Manage 権限を持っている場合は、実質上、Datadog であらゆる操作を実行できる管理者アクセス権が付与されます。User Access Manage 権限を持つ Datadog アカウントには、サービスアカウントに割り当てることができるロールや権限に対する制限はありません。


## 通知 {#notifications}

Datadog は、以下のアクションが発生すると、サービスアカウントに関連付けられたメールアドレスに通知を送信します。
- アプリケーションキーを作成する
- アプリケーションキーを失効させる
- サービスアカウントを無効にする
