## 概要 {#overview}

ダッシュボードの使用を開始する際は、まず定期的に確認したい事項について考えることが重要です。顧客がよく直面する問題は何でしょうか。問題解決のために知るべき項目は何でしょうか。

よいダッシュボードとは、これらの質問に対する答えを表面してくれるものです。また、1 つのダッシュボードにすべての項目を詰め込まないことも重要です。異なる問題には、それぞれ焦点の異なる別のダッシュボードを作成すると、素早く回答を導き出す上で役立ちます。

このガイドでは、ダッシュボードの作成方法をご説明します。これらの基本的なダッシュボードを使用して、チームはディスカッションをしながら速やかに問題を解決することができます。

## 前提条件 {#prerequisites}

[Datadog アカウント][1] をまだ作成していない場合は作成します。Agent とそのホストで実行しているプログラムのインテグレーションをホストにインストールします。

## プラン {#plan}

作成するダッシュボードの目的を決定します。ダッシュボードは、チームの全員が適切な作業に集中する上で役立ちます。_チームダッシュボード_を使うと、優先度の高い作業や、今取り掛かるべき作業、順調にいっている作業などを確認することができます。みんなが頻繁に詳細を確認する必要がある情報が明確になるようなチームダッシュボード (複数可) を作成しましょう。SLO および SLI の詳細を含むダッシュボードはよいチームダッシュボードと言えます。

ダッシュボードがリアルタイムデータに接続していると、マネージャーやエグゼクティブと明確で根拠に満ちた会話を進めることができます。よい_エグゼクティブダッシュボード_からは、作業の重要度やサービス実行のコスト、目標に対する進捗、SLO の達成率、効果測定などが明確にわかります。エグゼクティブダッシュボードは、これらの質問に対する答えを高度な基準で表示し、その答えを比較および分析するために相互接続されたときに最も効果的です。

ダッシュボードは、頻繁に発生する問題の追跡および修正にも役立ちます。_トラブルシューティングダッシュボード_は多くの場合、まずわかっている情報をメモし、そこから徐々にさまざまな発見を追加して情報を構築していく場所として機能します。たとえば、問題を表示する別のダッシュボードやビューからのグラフやウィジェットから始めます。そこから細かく問題を分析して解決方法を模索します。

## すぐに使えるダッシュボードを選ぶ {#explore-out-of-the-box-dashboards}

Datadog では、さまざまな機能やインテグレーションにすぐに使えるダッシュボードを多数提供しています。監視するインフラストラクチャーに合わせて、Datadog が提供するさまざまなダッシュボードから選べます。

1. Datadog の [Dashboards リストページ][2] で、追加したインテグレーション名を検索します。たとえば、`Redis` や `RUM` のような使用している機能です。
2. 検索結果から、{{< ui >}}Preset{{< /ui >}} というマークのあるダッシュボードを見つけ、求めている回答が表示されているグラフがあるかどうか確認します。
3. ダッシュボードのタイトルのドロップダウンメニューから、そのダッシュボードの活用方法を紹介したリンクを利用できます。

## 他のダッシュボードを再利用する {#start-by-reusing-other-dashboards}

ダッシュボードの最も一般的な開始方法は、すでに使用されている類似ダッシュボードを見つけ、自分のニーズに合わせて調整する方法です。求めている情報が表示されているダッシュボードを見つけたら、次の方法で再利用します。

1. ダッシュボードを開き、Configuration Actions メニュー (右側の {{< ui >}}Clone dashboard{{< /ui >}} ボタン) から {{< ui >}}Configure{{< /ui >}} を選択します。これにより、リンクされていないダッシュボードのコピーが作成されます。新しいコピーで行った変更は、ソースウィジェットには影響しません。
  {{< img src="getting_started/dashboards/configure_clone_dashboard.png" alt="Configuration Actions メニューのダッシュボード複製オプション" style="width:100%;" >}}
2. クローンを開いて {{< ui >}}Edit widgets{{< /ui >}} をクリックし、編集します。
3. ウィジェットの設定メニューで {{< ui >}}Delete{{< /ui >}} を選択し、必要のないウィジェットを削除します。
4. ニーズに合わせて表示場所などを調整します。ウィジェットは、個別にまたはまとめてドラッグアンドドロップして、ダッシュボードの希望する位置に移動できます。
5. 他のダッシュボードのウィジェットを利用する場合は、ウィジェットにカーソルを合わせて `Command + C` (Windows の場合は `Ctrl + C`) を押してコピーします。自分のダッシュボードを開いて `Command + V` (Windows の場合は `Ctrl + V`) を押してダッシュボードに貼り付けます。
5. 表示中のデータをエクスポートするには、Datadog の多くのビューで提供されている {{< ui >}}Export to Dashboard{{< /ui >}} オプションを使用します。たとえば、Log Explorer や Log Analytics ビューには、ログリストやメトリクスをダッシュボードにエクスポートする共有オプションがあります。

## メトリクスの詳細 {#learn-more-about-metrics}

Datadog では、インテグレーションの間にインフラストラクチャーおよびアプリケーションから [メトリクス][3] を収集します。収集されたメトリクスは、インテグレーションの README ファイルに記載されます。[Metrics Explorer][4] またはダッシュボードの作成時にメトリクスを発見し、そのメトリクスが何であるか知りたい場合は、インテグレーションドキュメントで探します。

たとえば、メトリクス `aws.s3.first_byte_latency` の時間グラフを見ているとします。Amazon S3 インテグレーションの README の [Data collected][5] セクションに移動して、その説明を確認します。`The average per-request time from the complete request being received by a bucket to when the response starts to be returned. Shown as millisecond.`

## ウィジェットを追加し、表示内容を調整する {#add-widgets-and-refine-what-they-show}

ダッシュボードに追加するメトリクスを選択したら、さまざまな [ウィジェットタイプ][6]、[クエリ][7]、[関数][8]、[集計方法][9] を試して、求めている情報が最も理想的な形で表示されるように調整します。

テンプレート変数を指定することで、さまざまなシナリオに対する質問に答えるダッシュボードを作成できます。たとえば、ユーザーがダッシュボードの変数ドロップダウンから選択したデータセンターの位置またはすべてをまとめて、レイテンシーメトリクスを表示する時間グラフを作成できます。詳しくは、[テンプレート変数][10] をご覧ください。

Y 軸の範囲、色、凡例を調整したり、マーカーやイベントオーバーレイを追加したりすることで、グラフを見やすくすることができます。[時系列][12] や [他のウィジェット][6] をカスタマイズおよび調整するすべての方法については、[ダッシュボードドキュメント][11] を参照してください。

オンラインコース [ダッシュボードのより効果的な活用][13] にサインアップすると、カスタマイズ方法の詳細や利用例をご覧いただけます。

## 他のウィジェットを試す {#try-out-other-widgets}

メトリクスの時系列グラフは便利ですが、ダッシュボードには、重要な情報を伝えるためいろいろなウィジェットを含めることができます。次を試してみてください。

 - **アラート値とチェックステータス**: 数字を大きな赤、黄色、緑で表示して成否を分かりやすくします。
 - **ヒートマップ**: 複数のタグにわたるメトリクスとインフラストラクチャーの複雑な関係を直感的な濃淡グラフで表します。
   {{< img src="getting_started/dashboards/heatmap_widget.png" alt="ヒートマップの例" >}}
 - **iFrames、フォーマット済みテキスト、画像**: ダッシュボードの内容を説明したりリソースを加えたりする際にウェブサイト並みの設定ができます。
 - **テーブル**: タグキーでグループ化されたメトリクスのリストを表示します。
 - **トップリスト**: たとえば、最も空き容量の少ないホスト、最も多くのエラーを発生させているサービス、または最も多 404 を返している URL などを表示します。
 - **ホストマップ**: インフラストラクチャーのホストを、たとえば、インテグレーションまたはサービスのステータスを色別で示すなど、図を使用して表示します。
 - **Service Level Objectives (SLO)**: SLO ウィジェットで目標に対するチームのパフォーマンスを示し、SLI メトリクスの詳細を示す追加のウィジェットとグループ化します。
 - **ディストリビューション**: コンテナ化された環境のさまざまなタイプのイベント数や、各サービスの重大なエラー数、ウェブサイトのフロー (2 ページ、3 ページ、4 ページを開くユーザー数)、レイテンシーのパーセンタイルバケットなどを図で示します。

以上のグラフのセットアップ例などを含む詳細は、[ウィジェット][6] でご確認ください。

## 整理、リンク、分析 {#organize-link-and-analyze}

ダッシュボードを利用して実行する作業や会話の流れに合わせてグラフを移動しましょう。ウィジェットは、ドラッグアンドドロップで配置できます。スクリーンボードでは、フリーテキストウィジェットを使用して見出しの下のセクションを整理します。タイムボードでは、複数のウィジェットを含むグループウィジェットを追加し、ダッシュボードを表示しているときに折りたたむことができます。

ダッシュボードが成長してきたら、タブを使用してウィジェットを名前付きのセクションに整理します。タブバーの {{< ui >}}\+{{< /ui >}} (または {{< ui >}}Add New Tab{{< /ui >}}) の横にあるドロップダウンの {{< ui >}}Add Widgets{{< /ui >}}) をクリックしてタブを追加し、各ウィジェットの共有メニュー (⋮) からタブ間でウィジェットを移動します。タブを使用すると、関連のないコンテンツをスクロールする必要がなくなり、単一のダッシュボードに集中しやすく、ナビゲーションも容易になります。詳しくは、[タブ][20] を参照してください。

ダッシュボードから任意のターゲット URL へのリンクを作成するには、以下の 2 つの方法があります。

 - リンクをはじめ、マークダウン書式設定のテキストを含められるノート & リンクウィジェットを追加します。ウィジェットエディタには、マークダウン書式設定のヒントが含まれています。
 - ウィジェットの設定 (ギア) メニューからカスタムリンクを作成します。カスタムリンクは変数およびテンプレート変数を補間するため、ユーザーが選択時に選択したコンテンツに応じてリンクが変わり、データを分析したり、修正措置を講じたりするために適切な場所へと移動させることができます。

## 次のステップ {#whats-next}

### Datadog サイト以外とダッシュボードを共有する {#share-your-dashboards-outside-of-the-datadog-site}

ダッシュボードのエクスポートメニューで {{< ui >}}Configure Public URL{{< /ui >}} をクリックして URL を作成すると、大画面または Datadog アカウントを持っていないユーザーと共有できます。詳細については、[ダッシュボードの共有][14] を参照してください。

[Slack インテグレーション][15] を使用してチームのコミュニケーションを統合すると、ダッシュボードをはじめとする Datadog の機能 (モニターやインシデントなど) を Slack チャンネルにインポートできます。

### 複数ダッシュボードをすばやく作成する {#create-multiple-dashboards-quickly}

すべてのダッシュボードには JSON 表現を使用しているため、設定メニューからコピーやエクスポートが可能です。ダッシュボードの各ウィジェットも JSON 定義を使用しており、ウィジェットエディタ (鉛筆アイコン) を開き {{< ui >}}Graph your data{{< /ui >}} の下の JSON タブをクリックすると表示して編集することができます。

すべてのウィジェットおよびダッシュボードは JSON として表現されるため、[ダッシュボード API][16] を使用してプログラムで生成することができます。これは、たとえばチームが新規プロジェクトを開始、またはインシデントに遭遇、あるいは SLO を正式化するたびにダッシュボードを生成する上で便利です。

### Datadog モバイルアプリからダッシュボードを表示する {#view-dashboards-from-the-datadog-mobile-app}

[Apple App Store][18] と [Google Play Store][19] で入手できる [Datadog モバイルアプリ][17] を使って、モバイルデバイスでダッシュボードを表示することができます。

モバイルアプリでは、Datadog 組織でアクセスできるすべてのダッシュボードを表示および検索し、Datadog ウェブアプリで使用されるのと同じテンプレート変数を使用してフィルタリングすることができます。
