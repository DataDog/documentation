デプロイゲートとルール評価を探索するには、[{{< ui >}}Software Delivery{{< /ui >}} > {{< ui >}}Deployment Gates{{< /ui >}} > {{< ui >}}Evaluations{{< /ui >}}][1] に移動します。

このページから、次のことができます。
* 最近完了したゲート評価と失敗理由を表示する
* 頻繁に失敗するルールとゲートの特定
* 一般的な失敗パターンの分析
* 時間の経過に伴う評価傾向の追跡
