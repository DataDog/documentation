## 概要 {#overview}

Cloud Cost Managementは、予期しないコスト変動が重大な問題になる前に、プロアクティブに検出して対応するのに役立ちます。これらのツールを使用して、AWS、Azure、Google Cloud全体で異常を自動的に特定し、カスタムアラートを設定し、ほぼリアルタイムでコストを追跡します。

## 主な特徴 {#key-features}

    {{< nextlink href="/cloud_cost_management/cost_changes/anomalies" >}}<u>異常</u>: 機械学習を使用して、異常なコストパターンを自動的に検出します。Watchdog Explainsを使用してコスト変動の要因に関する洞察を得て、チームとコンテキストを共有することで、より迅速な解決を実現します。{{< /nextlink >}}
    {{< nextlink href="/cloud_cost_management/cost_changes/monitors" >}}<u>モニター</u>: コストがしきい値を超えたり、予期せず変動したりした場合にカスタムアラートを作成します。これには、15分以内にアラートを送信するリアルタイムAI異常モニターが含まれます。特定の条件を定義し、プロバイダーやタグでフィルタリングし、電子メール、Slack、PagerDutyなどの通知チャネルと統合します。{{< /nextlink >}}
