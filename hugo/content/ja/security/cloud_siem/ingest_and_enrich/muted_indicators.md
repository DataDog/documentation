## 概要 {#overview}

脅威インテリジェンスフィードは、企業の VPN エグレス IP アドレス、承認されたクリプトマイニングプール、内部ツールのドメインなど、組織にとって無害なインジケーターにフラグを立てることがあります。インジケーターをミュートすると、Cloud SIEM はそれを組織にとって `benign` と評価するようになり、チームは同じ誤検知のトリアージを停止できます。

ミュートしても脅威インテリジェンスは削除されません。ミュートされたインジケーターはエンリッチメントを保持し、[IOC エクスプローラー][1]に引き続き表示されるため、検索してフラグが立てられた理由を確認できます。

インジケーターは以下の 2 つの方法でミュートできます。

- **Datadog 管理**: Datadog は、広く使用されているドメインなど、既知の無害なインジケーターのリストを保持し、すべての組織に対してそれらをミュートします。このリストは読み取り専用です。
- **組織によるミュート**: チームがミュートするインジケーター。これらのミュートは組織にのみ適用され、いつでもミュートを解除できます。

## ミュートの仕組み {#how-muting-works}

インジケーターがミュートされると、Cloud SIEM はそのインジケーターに一致する新しいログのエンリッチ方法を変更します。

- 各対象となる脅威インテリジェンス結果の[意図][2]が `benign` に変更されます。
- ログは、ソースやカテゴリーなどの残りの脅威インテリジェンスエンリッチメントを保持し、`has_been_muted: true` でマークされます。
- インジケーターの IOC スコアは変わりません。

ミュートは、ミュートが有効になった後に Cloud SIEM が処理するログに適用されます。すでに処理されたログは、元のエンリッチメントを保持します。

### ミュートまたはミュート解除が有効になるタイミング {#when-a-mute-or-unmute-takes-effect}

- **IOC エクスプローラー**: 新しいミュート状態を即座に表示します。
- **ログエンリッチメント**: 適用までに最大 1 時間かかる場合があります。その間、新しいログおよびそれらに基づく検出では、元の評価が引き続き使用される可能性があります。

### ミュートしても変更されない脅威インテリジェンス {#threat-intelligence-that-muting-does-not-change}

組織のインジケーターをミュートしても、以下の評価は変更されません。

- [リファレンステーブル][3]から独自に取り込んだ脅威インテリジェンス
- 脅威インテリジェンスプラットフォーム (TIP) インテグレーション: MISP、OpenCTI、および Anomali ThreatStream

## 前提条件 {#prerequisites}

- 組織が Cloud SIEM をサブスクライブしている必要があります
- 以下の[権限][4]が必要です。
  - ミュートされたインジケーターを表示する方法: `security_monitoring_signals_read`
  - インジケーターをミュートまたはミュート解除する方法: `security_monitoring_signals_write`

## 制限 {#limits}

| 制限 | 値 |
|---|---|
| 組織あたりのアクティブなミュート数 | 10,000 |
| ミュートまたはミュート解除アクションあたりのインジケーター数 | 100 |
| 理由の長さ | 100 文字 |
| サポートされているインジケータータイプ | IP アドレス、ドメイン、SHA-256 ファイルハッシュ |

組織のアクティブなミュート数が 10,000 に達した場合は、新しいインジケーターをミュートする前に、不要になったインジケーターのミュートを解除してください。

## インジケーターをミュートする {#mute-indicators}

IP アドレス、ドメイン、および SHA-256 ファイルハッシュをミュートできます。単一の値のみをミュートしてください。CIDR 範囲はミュートできないため、代わりに個々の IP アドレスをミュートしてください。

### インジケーターをミュートする {#mute-an-indicator}

1. {{< ui >}}Security{{< /ui >}} > {{< ui >}}Cloud SIEM{{< /ui >}} > {{< ui >}}Investigate{{< /ui >}} > [{{< ui >}}IOC Explorer{{< /ui >}}][5] に移動します。
1. インジケーターをクリックして、サイドパネルを開きます。
1. {{< ui >}}Mute This IoC{{< /ui >}} をクリックします。
1. 必要に応じて、`Corporate VPN egress` などのミュートの理由を入力します。理由は最大 100 文字まで入力でき、ミュートされたインジケーターページに表示されます。
1. {{< ui >}}Mute{{< /ui >}} をクリックします。

### 複数のインジケーターをミュートする {#mute-multiple-indicators}

1. {{< ui >}}Security{{< /ui >}} > {{< ui >}}Cloud SIEM{{< /ui >}} > {{< ui >}}Investigate{{< /ui >}} > [{{< ui >}}IOC Explorer{{< /ui >}}][5] に移動します。
1. ミュートするインジケーターの横にあるチェックボックスを選択します。一度に最大 100 個のインジケーターをミュートできます。
1. 一括アクションメニューで、{{< ui >}}Mute{{< /ui >}} をクリックします。
1. 必要に応じて、ミュートの理由を入力します。その理由は、選択されたすべてのインジケーターに適用されます。
1. アクションを確認します。

組織または Datadog によってすでにミュートされている選択済みのインジケーターは、2 回目のミュートアクションを実行しても変更されません。

## ミュートされたインジケーターを確認する {#review-muted-indicators}

ミュートされたインジケーターページには、Datadog および組織によるすべてのアクティブなミュートが一覧表示されます。これを開くには、次のいずれかの操作を行います。

- {{< ui >}}Security{{< /ui >}} > {{< ui >}}Settings{{< /ui >}} > {{< ui >}}Cloud SIEM{{< /ui >}} > [{{< ui >}}Muted Indicators{{< /ui >}}][6] に移動します。
- [IOC エクスプローラー][5]で、{{< ui >}}Muted Indicators{{< /ui >}} をクリックします。サイドパネルでリストが開きます。{{< ui >}}Open full page{{< /ui >}} をクリックして設定ページに移動します。

リストには、各インジケーターのインジケータータイプ、スコープ、理由が表示されます。Datadog 管理の行には、ソースフィードが表示されます。組織によってミュートされた行には、誰がいつそのインジケーターをミュートしたかが表示されます。検索バーを使用して、インジケーター、インジケータータイプ、スコープ (組織または Datadog 管理)、ソース、または理由でフィルタリングします。

### IOC エクスプローラーでミュートされたインジケーターを検索する {#find-muted-indicators-in-the-ioc-explorer}

[IOC エクスプローラー][5]では、{{< ui >}}Custom mute{{< /ui >}} 列に組織がミュートしたインジケーターの {{< ui >}}Muted{{< /ui >}} が表示されます。それらのインジケーターのみを表示するには、{{< ui >}}Muted{{< /ui >}} ファセットでフィルタリングします。

この列とファセットには、組織によるミュートのみが反映されます。Datadog によってのみミュートされたインジケーターは、この列やファセットではミュートとして表示されません。すべてのミュートを確認するには、[ミュートされたインジケーターページ](#review-muted-indicators)を使用します。

### ミュート履歴を表示する {#view-mute-history}

インジケーターのサイドパネルにある {{< ui >}}Conversation{{< /ui >}} タブには、すべてのミュートおよびミュート解除イベント、実行者、実行日時が一覧表示されます。これらのイベントは、インジケーターのコメントやトリアージの変更と並んで表示されます。

## インジケーターのミュートを解除する {#unmute-indicators}

組織がミュートしたインジケーターをミュート解除できます。Datadog 管理のミュートは読み取り専用です。

インジケーターのミュートを解除するには、次のいずれかの操作を行ってください。

- [IOC エクスプローラー][5]で、インジケーターのサイドパネルを開き、{{< ui >}}Un-mute This IoC{{< /ui >}} をクリックします。
- [ミュートされたインジケーターページ][6]で、インジケーターの行にある {{< ui >}}Un-mute{{< /ui >}} をクリックします。
- ミュートされたインジケーターページで、最大 100 個のインジケーターを選択し、{{< ui >}}Un-mute{{< /ui >}} をクリックします。

Datadog もそのインジケーターをミュートしている場合、ミュートを解除しても組織のミュートのみが解除されます。インジケーターは `benign` と評価されたままになります。
