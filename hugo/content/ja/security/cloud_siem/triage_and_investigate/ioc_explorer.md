## 概要 {#overview}

侵害指標 (IOC) は、IP アドレス、ファイルハッシュ、ドメインなどのエンティティに関連付けられたレピュテーションデータであり、対応者が攻撃や潜在的な侵害について情報に基づいた意思決定を行う上で役立ちます。[IOC エクスプローラー][1]は、侵害を分析、並べ替え、優先順位付けできる、検索およびフィルタリング可能な調査画面です。シグナルエクスプローラーやログエクスプローラーで関連する一致を表示することもできるため、潜在的な侵害をより詳細に調査できます。

{{< img src="security/security_monitoring/ioc_explorer_2.png" alt="侵害インジケーターとしてフラグが立てられた IP アドレスが表示されている IOC エクスプローラー" style="width:100%;" >}}

## 前提条件 {#prerequisites}

IOC エクスプローラーでデータを表示するには、以下のすべての条件を満たしている必要があります。
- 組織が Cloud SIEM をサブスクライブしている必要があります。
- 侵害インジケーターは、ログ取得時に Datadog が利用できた脅威フィードに含まれている必要があります。
  - IOC エクスプローラーがコンテンツを表示する脅威インテリジェンスフィードの詳細については、[脅威インテリジェンスソース][2]を参照してください。
- エクスプローラーの時間枠は、過去 30 日間に固定されています。ログはその時間枠内でなければなりません。組織が最近オンボーディングした場合は、オンボーディング時からのデータがエクスプローラーに表示されます。

## IOC エクスプローラーを使用する {#use-the-ioc-explorer}

Datadog で IOC エクスプローラーにアクセスするには、{{< ui >}}Security{{< /ui >}} > {{< ui >}}Cloud SIEM{{< /ui >}} > {{< ui >}}Investigate{{< /ui >}} > [{{< ui >}}IOC Explorer{{< /ui >}}][1] に移動します。

### 侵害インジケーターのクエリとフィルタリング {#query-and-filter-indicators-of-compromise}

カスタムクエリを作成したり、フィルターを適用したりして、エクスプローラーに表示する侵害インジケーターを決定できます。以下の項目でクエリやフィルタリングが可能です。
- 重大度スコア
- シグナル名
- [脅威インテリジェンスソース][2]
- タグ (スコアリングエンジンの出力を含む)
- インジケーター
- [インジケータータイプ][3]
- [脅威インテリジェンスカテゴリー][4]
- 自律システム (AS) タイプ
- [一致した OCSF フィールド](#understand-ocsf-matching)
- [ミュート状態](#mute-benign-indicators)

さらに、エクスプローラーの列見出しをクリックすると、その列の値で並べ替えることができます。

### OCSF マッチングについて理解する {#understand-ocsf-matching}

{{< ui >}}OCSF Matching{{< /ui >}} トグルをオンまたはオフに切り替えることで、Datadog が IOC 一致を識別する方法をより詳細に制御できます。
- 正規化されたセキュリティ属性に関連付けられた**信頼性の高い一致**が必要な場合は、トグルを**オン**にします。
  
  トグルがオンの場合、ソース IP、送信先 IP、クライアント IP などのマッピングされた OCSF フィールドに値が存在する場合にのみ IOC 一致がエクスプローラーに表示されます。これにより、単に未加工ログのどこかに IOC が存在するだけでなく、データが持つ構造的な意味を反映した一致であることを確認できます。
- イベントペイロード全体にわたって**より広範な脅威ハンティング**を行いたい場合は、トグルを**オフ**にします。
  
  トグルがオフの場合、メッセージ本文などの非構造化テキストやその他の自由形式フィールドを含め、イベント内のどこかに IOC が存在すれば、IOC の一致がエクスプローラーに表示されます。

#### 例 {#example}

アリスがボブに送信したメールのメッセージ本文に、IOC である IP アドレス `192.0.2.100` が記載されているとします。
- OCSF 一致のトグルが**オン**の場合、Datadog は、メールイベント内の正規化された送信元または送信先 IP アドレスフィールドなど、関連するマッピング済み OCSF フィールド内で見つかった IOC のみを照合します。`192.0.2.100` はメッセージ本文にのみ存在し、マッピングされた OCSF フィールドには存在しないため、IOC エクスプローラーには表示されません。
- OCSF 一致のトグルが**オフ**の場合、Datadog はメッセージ本文などの非構造化テキストを含むイベントペイロード全体を検索するため、`192.0.2.100` を照合します。その IOC が IOC エクスプローラーに表示されます。

### 侵害インジケーターに関する詳細情報を確認する {#get-more-context-on-an-indicator-of-compromise}

IOC エクスプローラーで侵害インジケーターをクリックすると、修復作業の優先順位付けに役立つ以下の追加情報を表示できます。
- インジケーターに割り当てられたカテゴリーと、そのインジケーターが掲載された脅威インテリジェンスフィード
- インジケーターに割り当てられた評価と、その評価に関連付けられた脅威インテリジェンスフィード
- インジケーターの重大度スコアの内訳
- インジケーターに関連付けられた環境 (関連するソースやサービスを含む)
- インジケーターが影響を及ぼす可能性のある関連アイテム
- 関連する調査画面へのリンク:
  - [シグナルエクスプローラー][6]で表示できるシグナル一致
  - [ログエクスプローラー][7]で表示できる関連ログ

### 良性インジケーターをミュートする {#mute-benign-indicators}

社内 VPN の送信元 IP アドレスなど、組織にとっての良性インジケーターは、サイドパネルで {{< ui >}}Mute This IoC{{< /ui >}} をクリックするか、複数のインジケーターを選択して一括でミュートできます。ミュートされたインジケーターはエクスプローラーに残り、脅威インテリジェンスによる評価は組織にとっての良性に変更されます。{{< ui >}}Custom mute{{< /ui >}} 列と {{< ui >}}Muted{{< /ui >}} ファセットには組織がミュートしたインジケーターが表示され、{{< ui >}}Muted Indicators{{< /ui >}} ボタンには有効なミュートがすべて一覧表示されます。詳細については、[ミュートされたインジケーター][8]を参照してください。

## 重大度スコアリングについて理解する {#understand-severity-scoring}

調査に適切な優先順位を付けるには、インジケーターの重大度スコアを判断するための適切なコンテキストが重要です。例えば、[IP アドレス][5]は変動しやすいため、頻繁な再評価が必要になる場合があります。

IOC エクスプローラーのサイドパネルでは、重大度スコアに寄与する要因を確認できます。重大度スコアは分類に基づく基本スコアから始まり、次の追加要因に応じて増減します。
- **分類**: インジケーターのカテゴリーと意図に関連付けられた基本スコア
- **裏付け**: インジケーターが複数の脅威インテリジェンスフィードに表示されているかどうか
- **持続性**: 脅威インテリジェンスフィードがそのインジケーターについて報告している期間
- **ホスティングタイプ**: IP およびドメインエンティティタイプに使用。ホスティングインフラストラクチャータイプが攻撃によく使用されるかどうかを評価します
- **シグナルアクティビティ**: インジケーターがシグナルで観測されたかどうか
