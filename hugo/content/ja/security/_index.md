## 概要 {#overview}

本番環境のセキュリティ運用にスピードとスケールをもたらします。Datadog Security は、アプリケーション、ホスト、コンテナ、クラウドインフラストラクチャー全体にわたるリアルタイムの脅威検出と継続的な構成監査を提供します。Datadog Security は、より広範な Datadog 可観測性プラットフォームと組み合わせることで、組織の共通目標に沿ったセキュリティと運用の間の前例のない統合を実現します。

Datadog Security には以下が含まれます:
- [Cloud SIEM](#cloud-siem)
- [Code Security](#code-security)
- [Cloud Security](#cloud-security)
- [App and API Protection](#app-and-api-protection)
- [AI Guard](#ai-guard)
- [Workload Protection](#workload-protection)
- [Sensitive Data Scanner](#sensitive-data-scanner)
 
詳細については、[30 秒間の製品ガイドツアー][14]をご覧ください。

## Cloud SIEM {#cloud-siem}

[Cloud SIEM][4] (Security Information and Event Management) は、標的型攻撃、脅威インテリジェンスリストと一致する IP によるシステムとの通信、安全でない構成など、アプリケーションやインフラストラクチャーに対するリアルタイムの脅威を検出します。Cloud SIEM は [Datadog Log Management][5] によって動作しています。これらの機能を組み合わせることで、[Datadog Cloud SIEM によって検出された脅威への対応を自動化][6]し、脅威対応ワークフローを迅速化できます。詳細については、専用の[ガイドツアー](https://www.datadoghq.com/guided-tour/security/cloud-siem/)をご覧ください。

## Code Security {#code-security}

[Code Security][20] は、リポジトリと実行中のサービスの両方で使用されるファーストパーティコードおよびオープンソースライブラリをスキャンし、開発から本番環境までのエンドツーエンドの可視性を提供します。以下の機能が含まれます。

- [Static Code Analysis (SAST)][27]: ファーストパーティコードのセキュリティおよび品質に関する問題を特定します
- [Software Composition Analysis (SCA)][28]: リポジトリとサービスの両方でオープンソースの依存関係を特定します
- [Runtime Code Analysis (IAST)][29]: サービス内のファーストパーティコードに存在する脆弱性を特定します。
- [Secret Scanning][30]: 漏洩したシークレットを特定して検証します (プレビュー版)

IDE との統合、プルリクエストのコメント、CI/CD ゲートを活用して、Code Security は組織全体で DevSecOps を実装できるようチームを支援します。
- **Developers:** 開発者にとっては、早期の脆弱性検出、コード品質の向上、デバッグやパッチ適用に費やす時間の短縮による、開発の迅速化を実現します。
- **Security Administrators:** セキュリティ管理者にとっては、セキュリティ体制の強化、早期の脆弱性アラートに対応したパッチ管理の改善、コンプライアンスの監視を実現します。
- **Site Reliability Engineers (SREs):** CI/CD ワークフロー全体における自動セキュリティチェック、セキュリティコンプライアンス、システムのレジリエンスを実現します。SAST は SRE の手作業による負担を軽減し、各リリースについて脆弱性の有無を徹底的にテストすることを保証します。

## Cloud Security {#cloud-security}

[Cloud Security][10] は、クラウドインフラストラクチャー全体にわたってリアルタイムの脅威検出と継続的な構成監査を行い、すべてを統合ビューで表示することで、シームレスなコラボレーションと迅速な修復を実現します。可観測性データを活用することで、セキュリティチームは攻撃フロー全体を追跡して脅威の影響を判断し、脆弱性がトリガーされたリソースの所有者を特定できます。

Cloud Security には、[Workload Protection][12]、[Misconfigurations][11]、[Identity Risks][15]、[Vulnerabilities][16] が含まれます。詳細については、専用の[ガイドツアー][13]をご覧ください。

{{< img src="security/csm/csm_overview_3.png" alt="Cloud Security の概要にある Security Inbox には、優先順位付けされたセキュリティ問題が一覧表示されます。" width="100%">}}

Datadog Security を使い始めるには、Datadog の [{{< ui >}}Security{{< /ui >}} > {{< ui >}}Setup{{< /ui >}}][9] ページに移動してください。このページには、単一構成または複数構成に関する詳細情報があります。または、以下のスタートガイドの各セクションを参照して、プラットフォームの各領域について詳しく学ぶことができます。

##  App and API Protection {#app-and-api-protection}

Datadog [App and API Protection (AAP)][1] は、Server-Side-Request-Forgery (SSRF)、SQL インジェクション、Log4Shell、Reflected Cross-Site-Scripting (XSS) など、コードレベルの脆弱性を悪用しようとするアプリケーションレベルの攻撃に対する可観測性を提供します。AAP は、[Datadog APM][2]、[Datadog Agent][3]、およびアプリ内の検出ルールを活用して、アプリケーション環境の脅威を検出します。製品の[ガイドツアー](https://www.datadoghq.com/guided-tour/security/application-security-management/)をご覧ください。

{{< img src="/security/application_security/app-sec-landing-page.png" alt="攻撃フローおよびフレームグラフが表示される Datadog のセキュリティシグナルパネル" width="75%">}}

## AI Guard {#ai-guard}

[AI Guard][35] は、AI の動作をリアルタイムで検査、ブロック、管理します。これは AI アプリやエージェントとインラインで動作し、Prompt Protection、Tool Protection、Sensitive Data Protection を使用して、プロンプトインジェクション、ジェイルブレイク、機密データの流出攻撃から保護します。これらの保護機能は、OpenAI、Anthropic、Bedrock、VertexAI、Azure を含む、あらゆるターゲット AI モデルで機能します。

{{< img src="security/ai_guard/ai_guard_detection_rules_1.png" alt="AI Guard 検出ルールエクスプローラー" width="100%">}}

## Workload Protection {#workload-protection}

[Workload Protection][26] は、環境全体のファイル、ネットワーク、プロセスのアクティビティを監視し、インフラストラクチャーに対するリアルタイムの脅威を検出します。Datadog プラットフォームの一部として、Workload Protection のリアルタイムの脅威検出をメトリクス、ログ、トレース、その他のテレメトリと組み合わせることで、ワークロードに対する潜在的な攻撃を取り巻く状況を包括的に把握できます。

- [Automated response][31] で脅威を未然にブロックします。
- すぐに使える[検出ルール][32]とカスタム検出ルールを管理します。
- リアルタイム[通知][33]を設定します。
- [セキュリティシグナル][34]を調査して対応します。

## Sensitive Data Scanner {#sensitive-data-scanner}

[Sensitive Data Scanner][24] を使用すると、機密データを検出、分類し、必要に応じてマスキングすることで、機密データの漏洩やコンプライアンス違反のリスクを抑えることができます。アプリケーションログ、APM スパン、RUM イベント、Event Management からのイベントなど、テレメトリデータ内の機密データをスキャンできます。クラウドストレージリソース内の機密情報をスキャンすることもできます。

[Sensitive Data Scanner を設定][25]した後、{{< ui >}}Findings{{< /ui >}} ページを使用して、特定された機密データの検出結果の詳細を確認し、トリアージ、調査、対応を行うことができます。
