## 概要{#overview}

メトリクスの単位は、時系列グラフ、クエリ値ウィジェット、トップリストなどに表示されます。

{{< img src="metrics/units/redis_dash_metrics_units.png" alt="Redis ダッシュボードのメトリクス単位" style="width:100%;">}}

時系列グラフでは、グラフの上にカーソルを合わせると関連する単位を確認できます。単位は手動で指定する必要がありますが、単位が設定されていない場合、桁数表記 (例: 千、百万、十億に対してそれぞれ k、M、G) が使用されます。単位が設定されている場合、生データは関連する桁数を使用して読み取り可能な表示単位に自動的に変換されます。

たとえば、3,000,000,000 であるデータポイントがある場合:

* このデータポイントの単位を指定していない場合、「3G」と表示されます。
* このデータポイントの単位をバイトに指定した場合、「3GB」と表示されます。

すぐに使えるインテグレーションによって提供されるメトリクスの場合、そのインテグレーションの「Data Collected」テーブルで
単位がすでに定義されているかどうかをチェックできます。
メトリクス名の後に *Shown as \<unit\>* と表示されているものは、
インテグレーションによってすでに単位が設定されています。この表記がないメトリクスにはデフォルトで単位が設定されていないため、
以下の手順に従って手動で設定する必要があります。

グラフの右上隅にある全画面表示ボタンをクリックすると、下部に単位が表示されます。

{{< img src="metrics/units/metrics_units.png" alt="全画面モードでのメトリクスグラフの単位" style="width:100%;">}}

メトリクスグラフ上でコンテキストメニュー (3 つの縦ドット) をクリックすると、[{{< ui >}}Metrics Info{{< /ui >}}] オプションが見つかります。これにより、メトリクスの説明が記載されたパネルが開きます。このパネルでメトリクス名をクリックすると、メトリクスの概要ページでメトリクスが開き、詳細な分析や編集を行うことができます。

{{< img src="metrics/units/metrics_info.png" alt="展開されたコンテキストメニュー (3 つの縦ドット) の [Metrics Info] オプション" style="width:100%;">}}

メトリクス単位を変更するには、[メトリクスの概要][1]ページに移動してメトリクスを選択してください。[{{< ui >}}Metadata{{< /ui >}}] の下にある [{{< ui >}}Edit{{< /ui >}}] をクリックし、ドロップダウンメニューから [`bit`] や [`byte`] などの単位を選択してください。

## 数値の書式 {#number-formatting}

### 単位のない書式 {#unitless-formatting}

単位のないメトリクスの場合、Datadog は [SI 接頭辞][2] `k`、`M`、`G`、および`T` を使用します。`T` を超えると、数値は指数表記に変換されます。指数表記は非常に小さな数値にも使用されます。デフォルトでは、Datadog は小数点以下第 2 位まで丸めます。指数表記の場合、デフォルトの小数点以下の桁数は 0 です。

#### 例 {#examples}

| 生の値              | 書式設定した値|
|------------------------|-----------|
| 1                      | 1         |
| 2.7182818284           | 2.72      |
| 1337                   | 1.34k     |
| 31536000               | 31.54M    |
| 4294967296             | 4.29G     |
| 18446744073709552000   | 2e19      |
| 0.001                  | 1e-3      |
| 2.3283064365386963e-10 | 2e-10     |
| 無効                | N/A       |

### 単位処理{#unit-handling}

単位は、読みやすくするためにグラフ上で自動的に書式設定されます。単位のラベル付けをカスタマイズする方法については、「[単位のオーバーライドを使用して視覚化をカスタマイズする][3]」を参照してください。

#### 例 {#examples-1}

| 単位       | ファミリー    | 生の値            | 書式設定した値    |
|------------|-----------|----------------------|--------------|
| バイト       | バイト     | 1                    | 1 B          |
| キビバイト   | バイト     | 1234235              | 1.18 GiB     |
| キビバイト   | バイト     | 45457878236741230000 | 40374.71 EiB |
| ヘルツ      | 周波数 | 6345223              | 6.35 MHz     |
| セント       | 通貨     | 1337                 | 13.37 $      |
| ナノ秒 | 時間 | 0 | 0秒 |
| 秒     | 時間      | 0.03212              | 32.12ms      |

### 時間の書式設定{#time-formatting}

1 分から 1 年までの時間単位は、人間が読みやすいように複数の単位に分割されます。次の規則が適用されます。

- 短い時間は 10 進形式で書式設定されます。
- 最小の時間単位はナノ秒です。
- 長い時間は 10 進形式の日数として書式設定されます。


#### 例 {#examples-2}

| 生の秒数 | 書式設定された値 |
|-------------|-------------------------|
| 0.00123 | 1.23ms |
| 0.00012345 | 123.45 μs (マイクロ秒) |
| 1.2345e-9   | 1.23ns                  |
| 95          | 1 分 35 秒                  |
| 3671        | 1 時間 1 分                   |
| 86390       | 1 日                      |
| 96400       | 1 日 3 時間                   |
| 52596400    | 608.75 日             |
