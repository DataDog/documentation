## 概要 {#overview}

Aggregate プロセッサーは、選択された集計モードに基づいて、同じタグ値を持つ複数のメトリクスを単一のサンプルに結合します。メトリクスを集計することで、メトリクスのボリュームとコストを削減できます。

## セットアップ {#setup}

Aggregate プロセッサーをセットアップするには、

1. フィルタークエリを定義します。クエリの作成方法については、[メトリクス検索構文][1]を参照してください。
    - フィルタークエリに一致しないメトリクスは、パイプラインの次のステップに送信されます。
    - クエリに一致するメトリクスは集計され、集計されたメトリクスがパイプラインの次のステップに送信されます。
1. **Mode** ドロップダウンメニューで、使用する集計関数を選択します。詳細は「[モード](#modes)」セクションを参照してください。
1. **Interval** フィールドに、メトリクスを集計する時間枠を秒単位で入力します。最大値は 60 秒です。

## モード {#modes}

Aggregate プロセッサーは、以下のモードに基づいてメトリクスを単一のメトリクスに結合できます。一部のモードは、特定の [metric kinds][2] (インクリメンタルまたはアブソリュート) でのみ使用できます。

| モード   | 説明                                                                            | インクリメンタルメトリクス | アブソリュートメトリクス |
| ------ | -------------------------------------------------------------------------------------- | :-----------------: | :--------------: |
| Auto   | デフォルトモード。インクリメンタルメトリクスを合計し、アブソリュートメトリクスには最新の値を使用します。| {{< X >}}           | {{< X >}}        |
| Sum    | メトリクス値を合計します。                                                               | {{< X >}}           |                  |
| Count  | メトリクスが受信された回数をカウントします。                                    | {{< X >}}           | {{< X >}}        |
| Latest | 最新のメトリクス値を返します。                                                      |                     | {{< X >}}        |
| Max    | 最大のメトリクス値を返します。                                                     |                     | {{< X >}}        |
| Mean   | 平均のメトリクス値を返します。                                                        |                     | {{< X >}}        |
| Min    | 最小のメトリクス値を返します。                                                     |                     | {{< X >}}        |
