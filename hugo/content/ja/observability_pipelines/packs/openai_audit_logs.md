## 概要 {#overview}

{{< img src="observability_pipelines/packs/openai_audit_logs.png" alt="OpenAI - 監査ログパック" style="width:25%;" >}}

このパックは、OpenAI 組織の監査ログから、ログイン失敗、新しい API キー、権限の変更をフラグ付けします。

このパックの機能:

- ログイン失敗にフラグを立てる
- 新しい API キーにフラグを立てる
- ロールの変更にフラグを立てる
