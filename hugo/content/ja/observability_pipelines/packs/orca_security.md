## 概要{#overview}

{{< img src="observability_pipelines/packs/orca_security.png" alt="Orca Security パック" style="width:25%;" >}}

このパックは、Orca Security クラウドの検出結果を、SIEM およびデータレイクルーティング用に正規化します。

このパックの機能:

- 情報レベルの検出結果の除外
- 重大度の低い検出結果の 10% サンプリング
- 重大度、アセット、およびクラウドのフィールドの正規化
