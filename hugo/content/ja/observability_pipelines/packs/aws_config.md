## 概要 {#overview}

{{< img src="observability_pipelines/packs/aws_config.png" alt="AWS Config パック" style="width:25%;" >}}

AWS Config は、リソース構成の変更を監視して記録します。

このパックの機能:

- コンプライアンス変更イベントのみを保持
- 構成スナップショットの配信をドロップ
- コンプライアンスに準拠していないリソースにタグを設定
