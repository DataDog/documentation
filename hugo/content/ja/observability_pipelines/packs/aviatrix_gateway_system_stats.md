## 概要{#overview}

{{< img src="observability_pipelines/packs/aviatrix_gateway_system_stats.png" alt="Aviatrix Gateway System Stats パック" style="width:25%;" >}}

Aviatrix Gateway System Stats は、さまざまなクラウドゲートウェイを通じた各ゲートウェイの CPU、メモリ、およびディスクの利用率を算出します。

このパックの機能:

- CPU 使用率の追跡
- メモリ負荷についてのアラート
- ディスク使用量の監視
