## 概要 {#overview}

{{< img src="observability_pipelines/packs/microsoft_dns.png" alt="Microsoft DNS パック" style="width:25%;" >}}

このパックは、従来の Windows DNS サーバーのデバッグテキストログ (dns.log) を解析し、クエリ名と応答コードをデコードします。

このパックの機能:

- クエリ名をデコード
- Snd/Rcv および RCODE を解析
- クリーンな応答をサンプリング
