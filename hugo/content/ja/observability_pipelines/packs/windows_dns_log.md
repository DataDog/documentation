## 概要 {#overview}

{{< img src="observability_pipelines/packs/windows_dns_log.png" alt="Windows DNS ログパック" style="width:25%;" >}}

Windows DNS サーバー分析ログは、クエリ、ゾーン転送、および動的な更新を対象としています。

このパックの機能:

- クエリフィールドを解析する
- ゾーン転送にフラグを立てる
- ルーチンクエリをサンプリングする
