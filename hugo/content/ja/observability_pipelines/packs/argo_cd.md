## 概要 {#overview}

{{< img src="observability_pipelines/packs/argo_cd.png" alt="Argo CD パック" style="width:25%;" >}}

このパックは、アプリケーションコントローラーおよび API サーバーによる Argo CD の同期イベント、正常性イベント、RBAC イベントを処理します。

このパックの機能:

- 同期ステータスを解析
- RBAC 拒否を抽出
- 正常な同期のノイズをドロップ
