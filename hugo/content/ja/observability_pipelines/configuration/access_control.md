## 概要 {#overview}

Datadog のアクセス管理システムでは、ロールベースのアクセス制御 (RBAC) が使用されます。これにより、ユーザーがさまざまな Datadog リソースに対して持つアクセスレベルを定義できます。ユーザーには、読み取り可能なデータや変更可能なアカウント管理アセットなど、アカウント管理の権限を定義するロールが割り当てられます。ロールに[権限](#permissions)が付与されると、そのロールに関連付けられているすべてのユーザーがその権限を受け取ります。詳細については、[ロールベースのアクセス制御][1]を参照してください。

[きめ細かなアクセス制御](#granular-access-control)を使用すると、ロール、[Teams][2]、またはユーザー単位で個々のリソースへのアクセスを制限できます。Observability Pipelines では、[パイプラインへのアクセスを制限](#restrict-access-to-a-pipeline)したり、[パイプラインの Live Capture へのアクセスを制限](#restrict-access-to-live-capture-for-a-pipeline)したりできます。

## 権限 {#permissions}

Observability Pipelines のアセットに対する[権限のリスト][3]および Datadog のデフォルトロールに含まれる権限レベルを参照してください。

## きめ細かなアクセス制御 {#granular-access-control}

[きめ細かなアクセス制御][4]はリソースへのアクセスを制限することしかできず、権限を昇格させることは**ありません**。たとえば、ユーザーが **Datadog 読み取り専用ロール**を持っており、きめ細かなアクセス制御を使用して特定のパイプラインへの {{< ui >}}Editor{{< /ui >}} アクセス権が付与された場合でも、そのユーザーはそのパイプラインに対して読み取り専用のアクセス権しか持たず、編集することはできません。そのユーザーがこのパイプラインや他のパイプラインに変更を加えられるようにしたい場合は、ロールをパイプラインの編集が可能なものに更新する必要があります。

### パイプラインへのアクセスを制限する {#restrict-access-to-a-pipeline}

以下のロールオプションを使用して、特定のパイプラインへのアクセスを制限できます。

| ロール | パイプラインの表示 | パイプラインの編集 | パイプラインのデプロイ | パイプラインの削除 | パイプラインへのアクセスを制限可能 |
|:----:|:-------------:|:-------------:|:---------------:|:---------------:|:--------------------------:|
| エディター | {{< X >}} | {{< X >}} | {{< X >}} | {{< X >}} | {{< X >}} |
| ランナー | {{< X >}} | {{< X >}} | {{< X >}} |  |  |
| コントリビューター* | {{< X >}} | {{< X >}} |  |  |  |
| ビューワー | {{< X >}} |  |  |  |  |
| アクセス権なし |  |  |  |  |  |

*Contributor は、パイプラインがドラフトモードであり、まだデプロイされていない場合にのみ、パイプライン構成を編集できます。

**注**:

- パイプラインに対するエディターアクセス権を付与されているユーザーが少なくとも 1 人存在しない場合、詳細なアクセス設定を保存することはできません。
- 自分で作成したパイプラインであっても、アクセスできなくなる可能性があります。パイプラインアクセスの詳細なアクセス制限を編集する際に、引き続きそのパイプラインに対するエディターアクセス権を保持したい場合は、自分自身がエディター権限を持つユーザー、Teams、またはロールに含まれていることを確認してください。

{{< img src="observability_pipelines/access_control/pipeline_modal.png" alt="制限オプションが表示されているパイプラインアクセスコントロールモーダル" style="width:60%;" >}}

きめ細かなアクセス制御を使用して特定のパイプラインへのアクセスを制限するには、以下を実行します。

1. [Pipelines][5] ページに移動します。
1. アクセスを制限するパイプラインを選択します。
1. ページ右上の歯車アイコンをクリックします。
1. {{< ui >}}Edit Access{{< /ui >}} > {{< ui >}}Pipeline Access{{< /ui >}} をクリックします。
1. {{< ui >}}Restrict Access{{< /ui >}} をクリックします。
1. {{< ui >}}Organization access{{< /ui >}} セクションには、組織のメンバーがデフォルトで {{< ui >}}Viewer{{< /ui >}} アクセス権を付与されていることが表示されます。ドロップダウンメニューを使用して、付与するアクセス権の種類を選択します。
1. {{< ui >}}Restricted{{< /ui >}} セクションのドロップダウンメニューをクリックして、Teams、ロール、ユーザー、またはサービスアカウントのアクセスレベルを設定します。
1. このパイプラインへのアクセス権を付与しているユーザーにパイプラインのリンクを提供したい場合は、{{< ui >}}Copy Link{{< /ui >}} をクリックします。
1. {{< ui >}}Save{{< /ui >}} をクリックします。

パイプラインへのフルアクセス権を復元するには、以下を実行します。

1. パイプラインページの右上の歯車アイコンをクリックします。
1. {{< ui >}}Edit Access{{< /ui >}} > {{< ui >}}Pipeline Access{{< /ui >}} をクリックします。
1. {{< ui >}}Restore Full Access{{< /ui >}} をクリックします。
1. {{< ui >}}Save{{< /ui >}} をクリックします。

### パイプラインの Live Capture へのアクセスを制限する {#restrict-access-to-live-capture-for-a-pipeline}

[Live Capture][6] を使用すると、次のことができます。

- ソースがパイプラインに送信するデータを確認します。
- プロセッサーが受信するデータを確認します。
- プロセッサーが送信先に送信するデータを確認します。

以下のオプションを使用して、**特定のパイプラインに対する** Live Capture へのアクセスを制限できます。

| ロール | キャプチャされたイベントを表示する | 新しいキャプチャを実行する | Live Capture へのアクセスを制限する |
|:----:|:--------------------:|:----------------:|:-------------------------------:|
| エディター | {{< X >}} | {{< X >}} | {{< X >}} |
| ビューワー | {{< X >}} |  |  |
| アクセス権なし |  |  |  |

**注**:

- Live Capture に対する {{< ui >}}Editor{{< /ui >}} アクセス権を付与されているユーザーが少なくとも 1 人存在しない場合、詳細なアクセス設定を保存することはできません。
- パイプラインを作成した本人であっても、特定のパイプラインに対する Live Capture へのアクセス権を自分自身でロックアウトすることができます。Live Capture アクセスの詳細なアクセス制限を編集する際に、その Live Capture に対するエディターアクセス権を保持したい場合は、自分自身がエディター権限を持つユーザー、Teams、またはロールに含まれていることを確認してください。

{{< img src="observability_pipelines/access_control/live_capture_modal.png" alt="制限オプションが表示されているパイプラインアクセスコントロールモーダル" style="width:60%;" >}}

きめ細かなアクセス制御を使用して特定のパイプラインに対する Live Capture へのアクセスを制限するには、以下を実行します。

1. [Pipelines][6] ページに移動します。
1. アクセスを制限するパイプラインを選択します。
1. ページ右上の歯車アイコンをクリックします。
1. {{< ui >}}Edit Access{{< /ui >}} > {{< ui >}}Live Capture Access{{< /ui >}} をクリックします。
1. {{< ui >}}Restrict Access{{< /ui >}} をクリックします。
1. {{< ui >}}Organization access{{< /ui >}} セクションには、組織のメンバーがデフォルトで {{< ui >}}Viewer{{< /ui >}} アクセス権を付与されていることが表示されます。ドロップダウンメニューを使用して、付与するアクセス権の種類を選択します。
1. {{< ui >}}Restricted{{< /ui >}} セクションのドロップダウンメニューをクリックし、ユースケースに基づいて Teams、ロール、ユーザー、またはサービスアカウントのアクセスレベルを設定します。
1. {{< ui >}}Save{{< /ui >}} をクリックします。

パイプラインの Live Capture へのフルアクセスを復元するには、以下を実行します。

1. パイプラインページの右上の歯車アイコンをクリックします。
1. {{< ui >}}Edit Access{{< /ui >}} > {{< ui >}}Live Capture Access{{< /ui >}} をクリックします。
1. {{< ui >}}Restore Full Access{{< /ui >}} をクリックします。
1. {{< ui >}}Save{{< /ui >}} をクリックします。
