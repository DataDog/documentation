## 概要 {#overview}

ファセットとは、パイプラインからユーザーが定義したタグや属性のことです。これらは、[定性的](#qualitative-facets)および[定量的](#quantitative-measures)なデータ分析の両方に役立ちます。ファセットによって、[CI パイプラインモニター][1]、および [ダッシュボード][2] や [ノートブック][3] に表示される検索クエリでパイプラインを操作できるようになります。

[ファセットの作成](#creating-facets)は、[パイプライン実行の検索][5] には**必須ではありません**。オートコンプリート機能は既存のファセットを使用しますが、入力されたパイプライン実行と一致する入力も適用されます。

## 一般的なファセット {#common-facets}

[**Software Delivery** > **CI Visibility** > **Executions**][7] に移動して、パイプライン実行リストの左側に表示されるファセットリストにアクセスします。

{{< img src="/continuous_integration/facets-pipelines.png" text="Facets list on the Pipeline Executions page of the CI Visibility Explorer" style="width:100%" >}}

[CI Visibility Explorer][4] には、すぐに使える以下のファセットが含まれています。

| ノードラベル | パイプライン、ステージ、またはジョブを実行した CI ノードに関連付けられたラベル。|

| パイプライン ID | パイプラインの ID。|
| パイプライン番号 | CI プロバイダーによって提供される CI パイプラインの実行番号。これは、パイプラインを部分的に再試行する際に増加します。|
| ジョブ URL | ジョブ実行のプロバイダー URL。|
| ステージ名 | CI ステージの名前。|
| ジョブ名 | CI ジョブの名前。|
| Kubernetes ネームスペース | Kubernetes Pod が実行されているネームスペース。|

| イメージタグ | Kubernetes コンテナイメージのタグ。|

| コンテナ ID | Kubernetes コンテナ ID。|
| Kubernetes コンテナ名 | Kubernetes コンテナの名前。|
| Kubernetes デプロイメント | Pod が属する Kubernetes デプロイメント。|
| Kubernetes Stateful Set | Pod が属する Kubernetes StatefulSet。|
| リポジトリ URL | Git リポジトリの URL。|
| リポジトリ ID | Git リポジトリを一意に識別する ID。|
| コミット SHA | Git コミット SHA。|
| ブランチ | Git ブランチ。|
| タグ | Git タグ。|
| 作成者メールアドレス | Git 作成者メールアドレス。|
| コミッターメールアドレス | Git コミッターメールアドレス。|
| コミッター日付 | Git コミッター日付。|
| 作成者日付 | Git 作成者日付。|
| 環境 | CI パイプラインが実行されている環境。|
| リソース | CI パイプラインで使用されているリソース。|

CI Visibility Explorer でファセットを使用して、以下の操作を行うことができます。

- [パイプライン実行を検索およびフィルターする][5]
- パイプライン分析を実行する
- パイプラインが完了したら、トラブルシューティングを開始する


### 定性的ファセット {#qualitative-facets}

次が必要な場合は、定性的ファセットを使用します。

- **値に関する相対的なインサイトを取得**します。
- **一意の値をカウント**します。
- 特定の値に対してパイプライン実行を**フィルタリング**します。たとえば、環境タグのファセットを作成して、トラブルシューティングのスコープを開発、ステージング、または本番環境にまで絞り込みます。<br>

**注:** タグのフィルタリングにファセットは必須ではありませんが、調査中に頻繁に使用するタグのファセットを定義すると、解決までの時間を短縮する上で役立ちます。

### 定量的メジャー {#quantitative-measures}

次が必要な場合は、定量的メジャーを使用します。

- **集計**: 複数のパイプライン実行から値を集計します。
- **範囲フィルター**: パイプライン実行を範囲フィルターします。
- **ソート**: パイプライン実行をその値に対してソートします。

#### タイプ {#types}

メジャーには、同等の機能のために、長整数またはダブル値があります。

#### 単位 {#units}

メジャーは、クエリ時間と表示時間の桁数を処理するための単位 (秒単位の**時間**またはバイト単位の**サイズ**) をサポートします。単位は、フィールドではなく、メジャー自体のプロパティです。

たとえば、ナノ秒単位の `duration` メジャーを検討します。`service:A` からのパイプライン実行に `duration:10000000` があると仮定します。これは `10 milliseconds` を意味します。`service:B` からのパイプライン実行に `duration:5000000` があると仮定します。これは `5 milliseconds` を意味します。`duration:>2ms` を使用して、両方のサービスから一度に一貫してパイプライン実行タグをクエリします。検索クエリの詳細については、[検索構文][6] を参照してください。

## ファセットパネル {#facet-panel}

検索バーを使うと、包括的かつインタラクティブにデータをフィルタリングしグループ化することができます。ただし、多くの場合、ファセットパネルを使ったほうがわかりやすくデータに移動できます。ファセットを開くと、現在のクエリのスコープのコンテンツのサマリーが表示されます。

検索バーと URL には、ファセットパネルで選択した内容が自動的に反映されます。

- **ファセット (定性的)** には、一意の値の上位リストと、それぞれに一致するパイプライン実行の数が用意されています。
- **メジャー (定量的)** には、最小値と最大値を示すスライダーが付いています。スライダーを使用するか、数値を入力して、検索クエリを別の範囲に絞り込みます。


### ファセットのグループ化 {#grouping-facets}

ファセットは、ファセットリストで意味のあるテーマにグループ化されます。ファセットのグループの割り当てや再割り当ては、ファセットリストにのみ影響し、検索や分析には影響しません。

### ファセットのフィルタリング {#filtering-facets}

ファセットパネルの検索ファセットボックスを使用して、ファセットリスト全体のスコープを設定し、操作が必要なファセットに移動できます。検索ファセットは、ファセットの表示名とフィールド名を使用して結果のスコープを設定します。

## ファセットの作成 {#creating-facets}

パイプライン実行の属性やタグにファセットを作成することは、パイプライン実行を検索するための必須ステップではありません。ファセットは、特定のパイプライン実行属性に意味のある説明を追加したい場合や、属性値をファセットリストに表示したい場合に便利です。

### Pipeline Executions サイドパネルからのファセットの作成 {#creating-facets-from-the-pipeline-executions-side-panels}

ファセットを作成する最も簡単な方法は、ファセットの詳細の大部分が事前に入力されるように、Pipeline Executions サイドパネルから追加することです。

{{< img src="continuous_integration/create_facet.png" alt="CI Pipeline Execution サイドパネルからファセットを作成する" style="width:100%;">}}

1. [CI Visibility Explorer][4] で、ファセットを作成するフィールドを含む対象のパイプライン実行に移動します。
2. リストからパイプライン実行を選択して、Pipeline Executions サイドパネルを開きます。
3. 必要なフィールド (パイプライン実行のスパンの場合は **Info** タブ) をクリックし、そこからファセットを作成します。

   - フィールドに数値がある場合、ファセットまたはメジャーのいずれかを作成できます。
   - フィールドに文字列値がある場合、ファセットの作成のみが可能です。

### ファセットリストからのファセット作成 {#creating-facets-from-the-facet-list}

目的のフィールドを持つパイプライン実行を見つけることができない場合は、{{< ui >}}\+ Add{{< /ui >}} をクリックして、ファセットパネルから直接ファセットを作成します。

{{< img src="continuous_integration/add_facet.png" alt="ファセットサイドパネルからファセットを追加する" style="width:30%;">}}

このファセットの基底のフィールド (キー) 名を定義します。

- インフラストラクチャータグにタグキーを使用します。
- プレフィックス `@` がある、パイプライン実行属性の属性パスを使用します。

現在のビューのパイプライン実行の内容に基づいてオートコンプリート機能が働くため、適切なフィールド名を定義しやすくなっています。ただしここでは、特に Datadog で一致するパイプライン実行がまだ受信されていない場合は、ほぼどんな値でも使用できます。
