リテンションチャートは、ユーザーがページやアクションにどれくらいの頻度で戻ってくるかを可視化し、製品や機能の継続的な価値を評価するのに役立ちます。

{{< img src="/product_analytics/retention/retention_chart.png" alt="リテンション分析チャートの例。" style="width:90%;" >}}

ユーザーリテンションは*コホート*内で測定されます。コホートとは、指定されたリンクをクリックするなど、定義された開始イベントを実行したユーザーのグループです。コホート内のユーザーは、その後、同じリンクを再度クリックしたり、支払いに進んだりするなど、指定された戻りイベントを完了した場合に、*リテンション*されたとみなされます。

イベントとして機能できるのは、表示するものとアクションのみです。

## 前提条件 {#prerequisites}

リテンションデータを生成するには、SDK で `usr.id` 属性を設定します。[一意のユーザー属性を送信するための手順][1] を参照してください。

## リテンションイベントの計算 {#calculating-retention-events}

リテンション値は加重平均コホートとして計算されます。これは、コホートのサイズを考慮することで、コホート全体の行動を要約するものです。コホートの規模が大きいほど最終的な値への影響が大きくなるため、単純平均よりも代表性の高い結果が得られます。Datadog は、すべての可視化タイプにこの計算を適用します。たとえば、リテンショングリッドでは、加重平均が各時間間隔のサマリーセルに反映されます。

リテンショングリッドの 1 週目など、特定の期間の値を計算するには、各コホートの値にそのサイズを乗算します。結果を合計し、コホートの合計サイズで除算します。

```
Weighted Average = (Σ (cohort_value × cohort_size)) / (Σ cohort_size)
```

たとえば、1 週間後の加重平均リテンション率 91% は次のように計算されます。

```
(99 * 1.8k + 92 * 2.35k + 81 * 1.75k) / (1.8k + 2.35k + 1.75k)
```

各コホートのリテンション率は、全体的なメトリクスに寄与する前に、そのユーザー数によってスケーリングされます。

{{< img src="/product_analytics/retention/pana_retention_weighed_avg.png" alt="加重平均リテンション率を示すリテンション分析グラフの例。" style="width:90%;" >}}

<div class="alert alert-info">リテンションチャートは、データが部分的または不完全な場合に無効な値を表示します。これは、期間が進行中であり、リテンション率をまだ完全に計算できない場合に発生します。</div>

## リテンションチャートを作成する {#create-a-retention-chart}

1. [{{< ui >}}Product Analytics{{< /ui >}}] で、[{{< ui >}}Create New{{< /ui >}}] > [{{< ui >}}Retention{{< /ui >}}] を選択します。

1. リテンションを把握したい開始ステップとリターンステップを定義します。

1. (オプション) {{< ui >}}Filter by{{< /ui >}} または {{< ui >}}Compare by{{< /ui >}} を使用して、国やデバイスタイプなどのプロパティに基づいてグラフの結果をフィルタリングまたはグループ化します。

## リテンションチャートを分析する {#analyze-a-retention-chart}

リテンションチャートを作成すると、各コホートのリテンションがパーセンテージまたはカウントで表示され、定義したリターン期間ごとに内訳が表示されます。

{{< img src="/product_analytics/retention/retention_analysis.png" alt="リテンションチャートに、高度なオプションのリターン設定、表示およびグループ化コントロール、チャートタイプセレクター、期間セレクター、コホートセルのツールチップのための番号付きの吹き出しが含まれています。" style="width:90%;" >}}

1. {{< ui >}}Advanced options{{< /ui >}} を使用して、どのリターンイベントをリテンションとして算入するかについて、スコープを指定します。

   - {{< ui >}}Returned on{{< /ui >}}: 特定のリターン期間中にリターンイベントをトリガーしたユーザーの割合を計算します。これを使用して、開始イベントから一定期間 (日や週など) 後にユーザーがリターンイベントを完了する確率を確認します。これは、機能や製品全体のリテンションを評価するのに役立ちます。
   - {{< ui >}}Returned on or after{{< /ui >}}: 特定の期間またはそれ以降の期間にリターンイベントをトリガーしたユーザーの割合を計算します。これを使用して、製品から完全に離脱したユーザーや、主要機能の使用を停止したユーザーを確認します。これは、オンボーディング体験の有効性を評価するのに役立ちます。

2. {{< ui >}}Viewing{{< /ui >}} 行を使用して、表示内容を制御します。

   - {{< ui >}}All Cohorts{{< /ui >}}、{{< ui >}}Weighted Average{{< /ui >}}、または特定のコホート: プロットするコホートを選択します。加重平均の計算方法については、「[リテンションイベントの計算](#calculating-retention-events)」を参照してください。
   - {{< ui >}}Unique users{{< /ui >}} または {{< ui >}}Unique accounts{{< /ui >}}: リテンションを `@usr.id` (ユーザーが Cookie を消去したりデバイスを切り替えたりするとリセットされる可能性がある) で測定するか、`@account.id` (長期間にわたって同じサインインアカウントを追跡する) で測定するかを選択します。
   - {{< ui >}}Rate{{< /ui >}} または {{< ui >}}Count{{< /ui >}}: リテンションをパーセンテージで表示するか、絶対数で表示するかを選択します。
   - {{< ui >}}Each day{{< /ui >}}、{{< ui >}}Each week{{< /ui >}}、または {{< ui >}}Each month{{< /ui >}}: リターンイベントをグループ化する期間を選択します。日次リテンションは最大 1 か月、週次リテンションは最大 1 年、月次リテンションは最大 16 か月まで適用できます。

3. チャートタイプセレクターを使用して、チャートタイプを切り替えます。

   - {{< ui >}}Retention{{< /ui >}}: 指定したコホートのリテンションの変化を示すリテンション曲線と、全期間にわたるコホートに関する詳細データを示すリテンショングリッドの両方が含まれます。
   - {{< ui >}}Timeseries{{< /ui >}}: 特定のコホートに焦点を当てることなく、選択した単一のリターン期間におけるカレンダー時間経過に伴うリテンションを表示します。
   - {{< ui >}}Query value{{< /ui >}}: 選択したコホート (コホート全体の加重平均、または特定の 1 つのコホート) を使用して、選択した単一のリターン期間に対する単一の数値 (率またはカウント) を表示します。
   - {{< ui >}}Top list{{< /ui >}}: {{< ui >}}Compare{{< /ui >}} プロパティが指定されている場合、指定された期間のリテンション率またはカウント別にグループ化された結果の順位を表示します。

4. 時間範囲セレクターを使用して、チャートが分析するデータの期間を変更します。

5. セルにカーソルを合わせると、その期間中に戻ってきたユーザーの正確な数、リターン率、およびそれが前の期間からどのように変化したかを確認できます。セルをクリックすると、ユーザーを一覧表示し、そのリストを CSV としてエクスポートできます。

### 一致するイベントと異なるイベントの使用 {#using-matching-vs-differing-events}

リテンションチャートは、開始イベントとリターンイベントを同じにするか、異なるものにするかを構成できます。

イベントが一致する場合、Week 0 は常に 100% になります。これは、初期イベントを完了したすべてのユーザーを表しているためです。他のすべてのセルは、その週の閲覧者を Week 0 と比較し、元のコホートのうちその週にイベントを再度完了したユーザーの割合を表示します。

{{< img src="/product_analytics/retention/retention_matching_events.png" alt="一致するイベントのリテンショングラフ。" style="width:90%;" >}}

上のグラフの **Aug 17 2026** の行を左から右に読むと:
- その週にイベントを完了した 10,430 人のユーザーのうち 23% が、1 週間後に戻ってきて再度完了しました。
- それらのユーザーのうち 21% が、2 週間後に戻ってきて再度完了しました。
- それらのユーザーのうち 11% が、3 週間後に戻ってきて再度完了しました。

イベントが異なる場合、Week 0 は初期イベントとリターンイベントの両方を完了したユーザーを表します。それ以降のすべてのセルは、元のコホートのうち、その週にリターンイベントを完了したユーザーの割合を表示します。

{{< img src="/product_analytics/retention/retention_differing_events.png" alt="異なるイベントのリテンショングラフ。" style="width:90%;" >}}

上のグラフの **Aug 17 2026** の行を左から右に読むと:
- 10,430 人のユーザーがその週に開始イベントを完了しました。
- それらのユーザーのうち 41% が、同じ週内にリターンイベントも完了しました。
- 23% が 1 週間後に、20% が 2 週間後に、11% が 3 週間後にリターンイベントを完了しました。
