ユーザーおよび製品の分析をサポートするために、必要に応じてProduct Analyticsチャートを作成、保存、共有します。

## チャートの作成 {#create-a-chart}

ゼロからチャートを作成するか、構築済みのテンプレートから開始して、ユーザーの行動を調査したり、製品メトリクスを可視化したりします。

ゼロからチャートを作成するには、Product Analyticsサイドバーで{{< ui >}}Create New{{< /ui >}}を選択し、チャートタイプを選択します。

{{< img src="product_analytics/chart_basics/chart_basics_create.png" alt="「新規作成」ボタンと選択可能なチャートタイプを一覧表示するProduct Analyticsサイドバー。" style="width:50%;" >}}

テンプレートからチャートを作成するには、Product Analyticsの{{< ui >}}Charts{{< /ui >}}ページから{{< ui >}}Explore all templates{{< /ui >}}をクリックします。

{{< img src="product_analytics/chart_basics/chart_basics_template.png" alt="「チャートテンプレートから開始」セクションと「すべてのテンプレートを探索」リンクが表示されたチャートページ。" style="width:100%;" >}}

## チャートの保存または共有 {#save-or-share-a-chart}

チャートを保存して主要な製品メトリクスを長期的に追跡したり、チームで同じインサイトに基づいて行動できるように共有したりします。

{{< img src="product_analytics/chart_basics/chart_basics.png" alt="チャート名フィールドと「共有」および「保存」ボタンの番号付き吹き出しが表示されたチャートエディター。" style="width:100%;" >}}

1. チャート名をクリックして、名前を変更してください。

2. を{{< ui >}}Save{{< /ui >}}クリックして、チャートを{{< ui >}}Charts{{< /ui >}}ページに保存してください。ドロップダウンを使用して、チャートをダッシュボードまたはノートブックに保存してください。

   {{< ui >}}Share{{< /ui >}}をクリックして、チャートをクリップボードにコピーしてください。ドロップダウンを使用してチャートをPNGとしてエクスポートするか、利用可能な場合はチャートデータをCSVとしてエクスポートしてください。
