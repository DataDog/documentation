title: ジャーニーパス

ジャーニーパスは、選択したイベント間でユーザーがたどる最も一般的なパスを表示します。

ジャーニーパスを使用して、以下のことを行います。
- ユーザーが主要なジャーニーをどのように移動し、ワークフローを完了するかを確認します。
- ユーザーが効率的にコンバージョンしているか、予期しない回り道をしているかを把握します。
- ユーザーがどこで、なぜ離脱しているかを調査します。

## ジャーニーパスチャートを作成する{#create-a-journey-paths-chart}

1. {{< ui >}}Product Analytics{{< /ui >}}で、{{< ui >}}Create New{{< /ui >}} > {{< ui >}}Journey Paths{{< /ui >}}を選択します。

2. 分析したいパスのイベントを少なくとも2つ選択して、{{< ui >}}User steps{{< /ui >}}を定義します。

   特定のステップについて、{{< ui >}}or...{{< /ui >}}をクリックして複数のイベントを指定するか、フィルターアイコンをクリックして指定したプロパティでステップを絞り込みます。

3. （オプション）{{< ui >}}Filter by{{< /ui >}}条件を使用して、国やデバイスの種類などのプロパティに基づいてチャートの結果を絞り込みます。

## ジャーニーパスチャートを分析する{#analyze-a-journey-paths-chart}

ジャーニー内のステップを定義すると、ユーザーがそれらの間をたどった最も一般的なパスがチャートに表示されます。

各パスには、そのパスをたどったセッションの割合と数、およびそのパスに費やされた平均時間が表示されます。イベントが記載されていないパスは、途中で中間の表示するやアクションを経由せず、開始イベントから終了イベントへ直接移動したセッションを表します。

{{< img src="product_analytics/journeys/journey_paths/pana_journey_paths_customization.png" alt="コンバージョン/離脱セレクター、ステップセレクター、期間、イベントタイプ切り替え、[詳細を表示]、パスオプションメニュー、および[パスを増やす]/[パスを減らす]コントロールの番号付き吹き出しが表示されたジャーニーパスチャート。" style="width:100%;" >}}

ジャーニーパスチャートをさまざまな方法で絞り込み、分析したいパスに焦点を合わせることができます。

1. {{< ui >}}Converted{{< /ui >}} / {{< ui >}}Dropped{{< /ui >}}セレクターを使用して、最終ステップに到達したパスと離脱したパスを切り替えます。ドロップオフパスには終了ノードがありません。

2. 複数のステップを含むジャーニーでは、ステップセレクターを使用して、パスを分析するステップのペアを選択します。 

3. 期間セレクターを使用して、チャートが分析するデータの期間を変更します。

4. {{< ui >}}Views{{< /ui >}}と{{< ui >}}Actions{{< /ui >}}の切り替えを使用して、どのイベントタイプをパスノードとして表示するかを制御します。表示する、アクション、カスタムアクションは、ダイアグラム内でそれぞれ異なる色とアイコンで表示されるため、パスの各ステップでイベントのタイプを識別できます。

5. 切り捨てられたパスについては、{{< ui >}}View more{{< /ui >}}をクリックして、そのパス内の次のイベントを表示します。{{< ui >}}View less{{< /ui >}}をクリックすると、再度折りたたまれます。

6. イベントをクリックすると、そのパスに関連付けられたセッションリプレイやユーザーを表示するオプションを含むメニューが開きます。または、**Option**（macOS）または**Alt**（Windows/Linux）を押しながらイベントをクリックすると、ダイアグラムから非表示にできます。

7. {{< ui >}}More Paths{{< /ui >}}と{{< ui >}}Fewer Paths{{< /ui >}}を使用して、表示するパスの数を調整します。
