### Arguments

#### Query Strings

| Field       | Type    | Description                                                                            |
| ----------- | ------- | -------------------------------------------------------------------------------------- |
| sort        | string  | The sort order for the results (e.g., `name,asc` or `name,desc`). Default: `name,asc`. |
| facets_only | boolean | If true, return only facets instead of full test details. Default: `false`.            |
| start       | integer | The offset from which to start returning results. Default: `0`.                        |
