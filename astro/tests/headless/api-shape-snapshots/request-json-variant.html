Request

Body Data (required)
Field
Type
Description
series [required]
[object]

A list of distribution points series to submit to Datadog.

host
string

The name of the host that produced the distribution point metric.

metric [required]
string

The name of the distribution points metric.

{
  "series": [
    {
      "host": "test.example.com",
      "metric": "system.load.1"
    }
  ]
}
Submit distribution points
# Set your Datadog site and credentials
export DD_SITE="datadoghq.com"
export DD_API_KEY="<DD_API_KEY>"
export DD_APP_KEY="<DD_APP_KEY>"

curl -X POST "https://api.${DD_SITE}/api/v1/distribution_points" \
-H "Accept: application/json" \
-H "Content-Type: application/json" \
-H "DD-API-KEY: ${DD_API_KEY}" \
-H "DD-APPLICATION-KEY: ${DD_APP_KEY}" \
-d @- << EOF
{
  "series": [
    {
      "host": "test.example.com",
      "metric": "system.load.1"
    }
  ]
}
EOF
